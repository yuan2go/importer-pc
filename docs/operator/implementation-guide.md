# 实施与维护手册

适用：IE01候选，SM 1.0.1。本文为离线文案源，20页打印版、原生截图及新人旅程尚未验收。当前实现与待实施项以[进度](../runtime/industrial-engineering-01.md)为准；本手册不为缺少的功能提供虚构入口。

## 准备

取得获准分发的同源完整介质、版本/源身份/哈希、D盘容量和Windows管理权限；明确目标OS、网络、相机IP/物理序列号/编码、仓ID/生产线ID/供包台编号及RCS合同。全部开发缓存和测试数据使用D盘。受保护根读取管理员配置，不以链接或新空目录绕权。

当前SM使用内置MVS采图、进程内识别及内置RCS，无PLC；不要准备TCP读码端口、MvCodeReader或外置扩展信任。现场SDK字节、ABI、物理设备及分发许可仍须核验。各次托盘放置仅发一次RCS请求；识别/保存/请求接受/物理完成分别记录。

## 安装与更新

1. 完全停止原软件，保留当前记录及未决包裹；核对安装介质来源与目标版本。
2. 打开安装器，核对程序/数据目录和操作种类。新SM默认程序`D:\CainiaoSupplyStation`、数据`D:\ProgramData\ImporterPc\data`；已有站保留原登记路径。
3. 明确安装并完成Windows授权，等待真实阶段和完成回执。原责任或资源检查失败时保留原件处理。
4. 以普通用户打开，完成或核对配置生效；安装完成不等于相机/RCS就绪。
5. 结果待确认时只核对该次安装，已提交但入口失败只修复原系统入口，不创建新操作覆盖。

普通路径拒绝降级、缺少恢复安全代次和同版本异字节介质。仅现有获准的特定数据升级路径可执行，格式/结构不明时写入前拒绝。未决安装记录会阻止新安装；不得手动修改其状态。

静默参数为候选功能，必须在已提权的部署上下文执行；不弹产品窗口、不自动启动设备、不自动重启。示例路径需由实施人员检查权限和归属：

```text
Ipc.Installer.exe /quiet /norestart /log="D:\deploy\station-01.json" /dataRoot="D:\ProgramData\ImporterPc\data"
Ipc.Installer.exe /quiet /repair /norestart /log="D:\deploy\repair-01.json"
```

日志只写新文件，不能覆盖上次记录。高级逐站计划仍使用原`--deployment-plan`协议及其原退出码；不能与简化EXE退出码混用。静默安装/真实系统往返尚未完成隔离VM验收。

## 首配与日常设置

1. 沿独立五步首配填写真实站点字段，不将示例值、模拟响应或另一站身份复制进生产默认。
2. 每台相机填写实际IP、物理序列号和唯一编码；取格口与心跳共用映射。未使用相机的IP/序列号同时留空。
3. RCS空地址为待配置，有地址必须完整；缺RCS不能取格口。人工键盘/PDA是独立来源，不要求相机已配置，但仍受RCS、容量及原责任守卫。
4. 核对保存结果；纯条码规则在符合条件时可直接生效，混合修改需重新打开。重连只用正在使用的配置，不会替代新配置生效。
5. 按[作业卡](quick-guide.md)核对首件，真实采图、识别、RCS传输、业务结果分层记录。

场景模板、配置旁连接检查及完成能力清单尚在P03实施，不把本手册当作已新增这些控件的声明。四类参数仍编辑同一完整候选；发生并发修改时重新核对，不覆盖其他窗口。

## 管理模式与忘记密码

管理模式与操作员身份、Windows安装权限分别管理。普通模式仅作业/记录，管理模式开放设置/日志/调试。会话15分钟，最后两分钟可从菜单续用15分钟；到期、退出、改密或重置撤销原授权，未保存草稿保留但受限。

忘记管理密码：打开“忘记管理密码？”→输入并确认新密码→Windows管理员授权→核对本站标识并确认重置→使用新密码重新进入。没有共享根密码，也不把Windows管理员身份当成日常管理模式。服务缺失/损坏先修复同源安装，不能删除凭据文件当作首次设置。

重置报错后先“核对上次重置”；如果尚未完成且确认仍有效，等待后再核对。只有服务确认旧请求已完成或旧确认已失效，才能结束原次处理或重新发起。重置不改操作员、相机配置或原请求责任。

## 卸载与残件

1. 完全关闭业务实例，从Windows应用列表进入本产品维护。
2. 核对原部署和备份位置；完整备份默认开启。若不备份，明确接受恢复风险；备份失败不会自动改成不备份。
3. Windows管理员授权卸载。程序移除，配置、业务记录、设备身份与未决责任保留，不需要业务密码。
4. 核对“程序已移除/数据保留/残件/需重启”的实际结果；独立维护缓存和原库存支持继续清理，不依赖原安装包。
5. 没有明确重启清理计划时不一律重启。清理失败保留原回执，不手动递归删除任意目录。

旧部署没有新维护缓存时需要受信修复路径，不能猜删。永久删除及版本清理仍在P02后续实现，当前不提供“一键彻底删除”操作步骤。未知/未交接责任即使能卸载程序，也不能因此永久删除。

## 程序回退

1. 完全关闭业务软件，从Windows应用列表打开维护，展开“版本回退”。
2. 选择D盘完整备份目录，点击“检查回退条件”。无兼容声明、存在未决请求或程序仍在运行时，先按原因处理；不要删除记录绕过检查。
3. 核对当前/上一版本和备份位置，明确确认“备份并回退到上一版本”。Windows管理员授权后，等待完整备份和原次切换结果。
4. 结果未确认时点击“核对上次回退”；若登记已切换而入口未完成，只点“修复上次回退的入口”，不要再次回退。
5. 完成后关闭维护窗口，从开始菜单以普通用户重新打开。回退只切换程序，业务数据保持当前状态，不会还原旧数据库或重发原请求。

此入口为IE01候选实现，最终安装包/系统矩阵尚未验收。历史版本缺少新兼容声明时禁用是预期行为；需旧数据才能运行的版本不能直接回退。

## 完整备份与恢复

备份包含数据库及同名`.recovery`配套恢复目录，以`COMPLETED.json`及完整文件集合/哈希为准。单个数据库文件不是完整恢复集；不得复制正在使用的db、删WAL或改格式号。

恢复使用现有维护入口和新隔离目录，核对原机退役、机器身份、RCS范围及实体交接后才按原政策启用。备份不能撤销已发送的外部效果。程序回退不能把旧数据库覆盖到当前根；数据不兼容时保留原件并联系实施人员。

新站日志/已结历史默认7天；保存保留策略不等于已执行清理。只处理符合条件的已结历史，未决和永久请求身份仍保留；不能用清理未知记录释放“容量”。

## 故障与交接

按[故障目录](fault-codes.md)处理；主句说明发生什么，下一步必须说明包裹怎样安置。记录版本、带时区时间、本位、原作业/操作ID、已知及未知事实，按现场批准渠道交接。当前RCS没有权威结果查询，不用替代POST假装查询，不盲重发。

日志需管理模式，查询/导出范围固定。维护中心及诊断页已有“导出诊断包”入口：进入管理模式，选择D盘上程序/配置/数据目录之外的新ZIP路径，导出后核对文件。诊断包仅含白名单摘要，不是备份，不包含原始日志正文、业务库、条码、图片、凭据或原报文；当前包的manifest标为Partial，说明24小时日志覆盖不能证明完整，安装事务回执未完整收集。技术支持按清单缺项继续核查，不能把“没有摘要”当作“没有异常”。取消、失权或校验失败不发布完成文件。轻量帮助仍待实施；实际版本/验证边界见进度记录。

## 验收与支持

构建、合成端口、Windows原生、系统安装、真实SDK/客户RCS、目标IPC及现场分别记证。正式发布者/证书、系统矩阵和真实设备/接口材料不足时保留未完成状态。支持联系人由实际获准资料提供，本手册不填虚构电话或邮箱。
