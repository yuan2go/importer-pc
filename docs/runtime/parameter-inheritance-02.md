# 参数归属与生效

本文说明当前 SM 首配和日常设置。规则见 [AGENTS.md](../../AGENTS.md)，权限见 [管理模式](management-mode-01.md)，原请求见 [RCS 参数与冻结责任](../design/rcs-parameter-description-compatibility.md)。历史参数迁移表及旧版实施记录留在 archive，不是当前格式转换或功能支持声明。

## 一份候选与一份配置账

系统、业务、驱动和组件共用完整候选及配置账；首配和日常表单使用相同字段定义。读取、导入、草稿和保存均核对当前管理授权。保存以加载时的修订做 CAS，不因后台刷新更新旧草稿的并发基线；冲突保留输入。完整加密编辑草稿仍按当前格式校验，缺少必需字段时拒绝并保留原件，不补造旧草稿字段。

条码规则、相机和 RCS 连接参数在执行、回执及设备责任收口后可以热生效，只重新连接实际修改的连接；受阻时保留 Pending。其他参数及混合修改保存后重启生效。新相机地址先按IP枚举并取得有效序列号才允许保存；此后重连失败可以保留已生效配置，但须明确离线和自动恢复。原请求保留原期限、参数、编号、目标和报文，不随新配置变化。

保存回执与界面提示分开：PendingRestart、Effective、Conflict、Unknown 等由 Application 核对原提交得出。保存结果未确认时保留草稿并禁止再次提交；只能核对原次结果，不能凭超时或提示文字推断未写入。无差异不新增修订。

## 参数职责

- 系统参数负责站点身份、记录、备份和存储预算。
- 业务参数负责条码筛选、放置及输入规则。
- 驱动参数负责每台相机的 IP、物理序列号、识码方式与采集设置。
- 组件参数负责共享 RCS 地址、相机编码、心跳、格口策略及请求超时。

SM 只提供内置相机与 RCS，不新增称重、PLC、登录或上传入口。共享模型中仍有真实消费者的字段及已有原配置绑定不能按名称删除；暂停开发的其他业务保留原实现，不把其字段宣称为 SM 的功能。

## 条码与放置

允许与排除规则均为整串匹配，不猜测小车码或预置客户规则。先统一筛选全部候选，再判断有效候选和多码；只有排除码时正式候选为空，不能据此判断空盘或上件。物理在位独立于识码，使用显式校准的会话内Mono8参考；重连、重启和尺寸变化后重新校准。未知图像不能当空盘；真实移出须连续至少三帧且800ms，详见[轮次设计](../design/sm-parcel-rounds.md)。原始识别候选完整保留。

筛选样例复用 Application 的有界匹配机制，不创建作业或外呼。非法正则、超时、不完整候选和多码继续拒绝；两处真实同码不能按文字去重。未设置可选筛选规则是当前允许的配置，不是旧格式兼容。已冻结规则的序列化和原请求身份不能因编辑当前配置而被改写。

## 日常显示与记录

SM效率显示、窗口方式和提示音共用草稿、底部“保存设置”与关闭保护，按当前Windows用户持久化；试听不保存。首配使用同样的偏好草稿。只改偏好不创建业务修订、不重连设备。业务和偏好分属不同存储，分别记录成功/失败；成功的业务候选不因偏好失败重复CAS提交，失败偏好保留输入供重试。共享基座其他业务显示字段仍保留。

## 期限、维护与字段清单

新取格口默认1000ms，可配100～30000ms；权威解析、schema、模板和页面一致。连接、发送、正文读取共用创建时冻结的一次期限；超时不自动重发。内部输入交付预算独立，不把短RCS期限当作合法输入的排队过期预算。自动识读默认1000ms，可配100～60000ms，包含放稳消耗，两个期限独立；放稳时间接近或超过识读期限时明确提示调整，不能隐藏错误或延长期限。

| 类别 | SM用途及呈现 |
|---|---|
| 常用 | 本站/RCS编号与地址、左右IP及RCS相机编码、识读规则与期限、格口策略 |
| 高级 | RCS期限/心跳、明确选择的识码方式及对应有效相机选项、真实存储/维护预算 |
| 只读 | 按IP取得的序列号、实际连接、配置生效状态、目录及自动维护执行结果 |
| 内部 | 实际输入交付、执行及原图资源保护；不以历史作业数量限制SM新件 |
| 删除SM编辑/依赖 | 无效登录及会话、Disabled称重选项、作业数量对归档阈值的耦合；其他业务消费者保留 |

“运行记录归档阈值”表示达到阈值后将可归档详情移到记录存储，记录仍可查询；“日志最长保留时间”不保证至少保留该天数，容量轮替可更早发生；“已结记录清理期限”只在明确启用且满足备份/责任围栏时清理安全详情；“备份份数上限”到达后停止新增，不自动删旧份。维护设置集中提供自动清理开关、期限和执行状态，关闭须明确未启用；保留手动清理及完整备份、未结责任、永久编号和存储保护。

历史、诊断日志、图片及业务原件分别按现有责任和预算管理。日志保留不删除数据库、回执或恢复集；磁盘不足阻断新准入并保留原件。备份计划辅助状态故障停止该计划并告警，真实业务存储故障仍执行原守卫。完整备份和恢复见 [长稳与备份说明](win11-24x7-stability-remediation-01.md)。

`--parameter-refactor` 已包含参数继承专项；同一次验证不必再运行 `--parameter-inheritance`。验证保留完整候选、CAS、未确认不重提、旧格式原件不变及原请求不重发断言；真实 SDK、客户 RCS、Windows 原生及现场结果独立记录。

## 当前SM默认、范围与生效

| 参数 | 新站默认 / 合法范围 | 条件与保存生效 |
|---|---|---|
| 自动识读期限 | 1000毫秒 / 100～60000 | 左右共用；条码策略变化可热生效，当前轮次保留冻结规则和原期限 |
| 取格口请求超时 | 1000毫秒 / 100～30000 | RCS连接高级设置；新请求冻结，连接、发送、正文一次总期限 |
| 心跳间隔 | 1000毫秒 / 100～3600000 | 启用位；共享RCS连接参数，原取格口请求不改写 |
| 放稳后再识别 | 每相机200毫秒 / 0～2000 | 相机高级设置；0每帧交付。放稳消耗识读期限；相同或更长时警告，不擅自改变期限 |
| 原生识码 | MVID | 每相机高级设置独立选择。原生不显示/校验未消费的软件码制及反色值；显式选择软件时这些值重新参与校验，草稿原值不被悄悄覆盖 |
| 软件码制 / 反色 | All / true | 仅MVS＋ZXing消费；未指定引擎的原软件含义不变，已有显式方式不改动 |
| 运行记录归档阈值 | 200条 / 1～10000 | 与SM MaximumOperations无关；保存后重启，归档不删除可查询详情 |
| 磁盘预留 | 512 MiB / 1～1048576 | 新站及开发模板；已有显式值保留，保存后重启。依据为两笔各32 MiB原图写入、64 MiB WAL告警量及七笔各256 KiB响应等同时保全所需的工程余量，非容量承诺；其余实际写入/备份预算仍独立检查 |
| 日志最长保留时间 | 7天 / 1～3650，可空 | 空值仅容量轮替；重启生效，不保证最少保留天数 |
| 已结记录清理期限 | 7天 / 7～30，可空 | 空值不按天清理；启用自动清理必须有期限，重启生效 |
| 自动清理 | 关闭 / 本地时区3时 / 最多7份清理前备份 | 时刻0～23、份数1～100；沿原OperationsPolicy、完整CAS及责任围栏。当前执行状态单独显示，保存不声称已执行 |
| 计划备份 | 关闭 / 60分钟 / 最多10份 | 周期15～10080、份数1～1000，启用时须合法绝对目录；上限停止新增，不删旧份，重启生效 |
| 效率 / 打开方式 / 音量 | 显示 / 窗口 / 0% | 当前Windows用户；音量0～100。统一底部保存、差异、关闭保护，试听不保存，独立分项持久化 |

队列容量和共享外部服务预算仍有真实消费者，SM编辑保留原值、不提供现场排队/积压数量设置，也不因隐藏字段的无关草稿文本阻止保存。共享 MaximumOperations、SessionLifetimeMs 和Disabled重量字段不再作为SM编辑的解析依赖；其他业务真实消费者与原绑定完整保留，不删除共享能力。

当前加密编辑草稿同时携带三个本机偏好的原始选择和Windows用户身份；只允许原用户继续。通用站点模板不导出这些用户草稿。草稿保留不等于配置Pending或偏好生效；缺少当前必要字段的草稿保留原件，拒绝套用，不补造兼容值。
