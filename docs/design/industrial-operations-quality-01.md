# 操作、诊断、文档与质量

本文记录当前 SM 的交互与验证入口。历史目标及各次结果见 Git 历史和[原实施记录](../runtime/industrial-engineering-01.md)，不能据其通过项推断当前提交已通过。生命周期见[当前设计](industrial-lifecycle-01.md)，权限见[管理安全](industrial-security-recovery-01.md)。

## 首配与作业

首配按“本站与 RCS、左右相机、识读规则、检查与完成”四步，不提供计划来源或场景选择。根据实际 IP 枚举唯一设备并保存序列号，不打开相机；序列号只读。新站默认海康原生识码，既有选择保留。网络检查与采图、识读、心跳、取格口结果分别说明，不能由网络成功推断可供包。

完整候选共用配置账、CAS 和 Pending/Effective，Windows 用户显示偏好独立保存。管理授权每次执行复核。设备连接与各位输入共用原应用实例；切页不重建连接。当前按可信小车到位分轮，同次到位仅一次生产提交，不能靠换码、空盘、重连或页面复位解锁。

作业卡状态按[作业卡契约](work-card-states.md)和[WPF 规范](wpf-ui-review.md)展示当前件、原因和下一步。相机离线只影响自动来源，人工输入另走本位编码、到位及 RCS 守卫；软件暂停不是急停。无码本身不证明空盘，未知结果不重发。普通导航为作业、记录；本版本隐藏帮助、异常处理和统计与班次入口。

## 维护与交付

在线完整备份入口位于设置及设备与诊断，完成后按原守卫明确恢复供包。完整备份核验、交付与保管使用同一应用契约；在线、离线和计划备份都是数据库、同名恢复目录、完成清单及完整哈希组成的一份完整集。孤立数据库和残缺集明确拒绝恢复，不提示手工拼装。交付保留原名及逻辑身份，取消/失败不发布完成。删除仅沿所选冻结清单，引用、占用与未知文件保留。

离线维护提供恢复、回滚、旧构建清理及原操作历史结果。原提交、恢复责任确认、曾启用事实、当前暂停和删除余项分别投影权威记录。卸载页面仅提供保留/删除数据及原卸载动作；Unknown 时原按钮只核对，不额外提交。完整安装器和维护页可复制构建身份，区分实际宿主、当前登记程序及目标介质；不增加在线更新检查。

整窗操作位于固定右对齐底栏，内容独立滚动。技术细节按需展开，可选择复制；取消和关闭按真实提交/释放阶段执行。原生验证须检查低高度、焦点、长中文、授权到期、取消/重试及异步状态，截图记录源提交、客户区与实际 DPI。HTML 或回调注入不能替代系统安装验收。

## 诊断与文档

管理人员可导出白名单诊断摘要，诊断包不是备份，默认 Partial 并如实列未收集项；不包含数据库、图片、条码、凭据或原报文，不自动上传或发送。日志正文、完整配置和机器安全根不通过扩大导出范围补入。原请求证据仍在所属业务记录中保管，不能把诊断缺项解释为没有异常。

现场入口为作业卡、部署卡、实施手册及故障目录；故障代码和链接由 `scripts/verify-industrial-docs.py` 核对。打印稿生成和实际排版核查独立记录。历史结果保留原提交和结论；INDEX 只导航当前说明，不把旧工作包当当前规则。

## 质量与发布边界

PR/main 使用 `industrial-core.yml`，标准 MSTest 入口在 `tests/Ipc.Core.Tests`，控制台验证保留可复现选择器。测试应核对实际实现、拒绝及原件不变，未知选择器失败。子进程覆盖、WPF 和真实系统安装分别记录，不用适配器代码覆盖率替代产品覆盖。

构建保持锁文件、确定性、Nullable、警告作错误及现有分析器，不吞错误或削弱现行断言。只补改动相关的风险验证，不以用例数量或覆盖率目标恢复废弃行为。

SM 业务版本固定 1.0.0，来源提交、库存及独立输出区分构建，同版本不同内容不覆盖已交付安装包。正式发布还需真实发布者、签名、最终字节、SDK 分发资格、同源手册与现场矩阵；本地构建或其他提交的 PASS 不提供这些资格。软件不提供在线更新、自动下载或后台安装。MSI/MSIX 等另按明确任务评估。
