# 本机持续输入与故障模拟

`Program.cs` 原样保留审查阶段的7组模拟。每种驱动各100次启停/旧注册围栏，MVS断线/改IP/获取异常及显式恢复，读码器阻塞/过载计数，最后执行双路17Hz、30秒输入。

帧只是元数据，借用指针是不会解引用的合成标记，没有6MP像素传输、解码器或真实原生调用。读码结果也是合成输入。510次/路计数与每触发2帧验证不能证明真实图像吞吐、真实触发实体、24小时长稳或物理格口。

先构建本工作树的Platform及两个SDK驱动，再用Release/RestoreLockedMode构建本项目，执行输出的 `Ipc.Drivers.Hikrobot.Probe.dll`。独立审查回归的失败不能因本项目通过而豁免；两个入口均加入当前SDK CI。
