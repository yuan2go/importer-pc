# 工作站状态与运维日志

工作站按本位展示车号、扫码资格、本件结果及设备连接。相机采集、RCS 有效心跳、取格口确认分别记录。连接断开或状态过期时撤下实时值，原请求和已取得的结果仍可按记录查询。[作业卡状态](../design/work-card-states.md)

运维工具的“日志中心”支持查看本部署的运行日志。完整在线查询经本连接授权后交给工作站执行，可按时间和来源筛选、查看上下文、复制或导出。核对问题时保留运行实例、投递位、观察或原请求身份及实际时间。[运行日志字段与证据](../design/runtime-state-logging.md)

切换列表和终端只影响呈现。固定范围查询使用同一范围和分页；实时跟随读取新记录，暂停显示期间后台继续记录。轮替或超出容量可能使部分上下文缺失，按提示核对留存原件。[调试与实时终端](debug-log-live-01.md)

工作站离线时仅可读取本部署和本用户权限范围内已落盘的运行日志。当前设备状态、原请求与业务库仍由工作站持有，不从旧日志推断已恢复连接、已经停机或业务已完成。[IPC、离线读取与维护](../design/sm-readonly-operations.md)
