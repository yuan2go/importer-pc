## 准备与启动

Windows 11 build26100+ x64；解压包到新的发布目录，使用新模拟数据根，先核对SHA256SUMS。运行 `./station.ps1 -Action Fixture`，另一窗口 `./station.ps1 -Action Init` / `./station.ps1 -Action Run -View workstation -Layout standard`。布局/页面优先级：启动参数→数据根用户偏好→发布默认。默认不需要SDK/字体文件，Production缺能力应拒绝业务。

每个屏幕/缩放组分别运行1920×1080及1366×768、100/125/150%，记录OS build、实际客户区DIP、DPI、SourceCommit/发布指纹、数据根实例ID（不公开路径）、动作和结果。跨屏拖动也检查PerMonitorV2表现。窗口首次应适合WorkArea；不足800×420 DIP显示明确阻断，后台不重启。

## 同版本独立证据

1. 工程控制页选择模拟维护员；工作台输入箱码，确认箱波次/来源与唯一接受量。工程页对左通道入场/读码（000123/包装1）；工作台核对SKU、Item波次、任务、格口、单位和入场箱快照。供包→接受，未离场不能入下一件。离场/复位后再入同码新实体，ID不同。
2. 右通道业务拒绝（下个请求Reject），保留原因/下一步、当前箱和任务来源。正常界面不用固定警告色；颜色必须有文字/图标。
3. Drop/Delay生成待核对，页面/第二窗口导航不重启设备/发送器；原请求查询入口保留ID/哈希/合同/目标版本。无权威结果不能本地取消/盲重发。结构化记录展示每次Attempt、Response和Audit，关闭专属详情可达。
4. 另起合成需求小的配置经草稿→验证→待激活→重启，演练拆包：有效保留身份去重、计数满后供包、显式清空纠正；数量与主操作不被长内容挤走。不要修改生产规则。
5. 表单修改manual/replay、端点版本/超时/队列/低水位及合成参数；查看差异、错误字段和生效时机。活动箱/未决请求拒绝激活；无效回放文件启动ActivationFailed保旧，下次原配置能启动。原请求仍固定原端点，不对新目标重投。
6. H04：已保存Prepared且暂停/过载时，维护员按原非交付证据受控终结；显示已本地终结/实体待处置，无释放预留或新实体授权。新过载使旧版本确认失效；活动报警不被历史页遮蔽，已读不等于恢复。
7. 两窗口记录RuntimeId相同；分别编辑箱码/保留件/配置草稿，切页/布局/刷新后草稿、选区、焦点、详情和滚动稳定。关闭副窗口只取消其读取，不停发送器。真实扫码器使用Enter/Tab终止符；仅安全输入框处理，不触发其他按钮。关键确认初始取消，扫码不能确认；鼠标/键盘明确确认仍能工作。
8. 慢盘/存储失败期间UI能继续绘制/滚动，超过3秒旧投影明确未就绪、命令禁用；恢复新投影后重新复核。退出失败保留故障并停止来源/发送器，原未决请求不伪装成功。
