# 当前 Windows 安装与维护

当前规则见[AGENTS](../../AGENTS.md)，具体操作见[生命周期指南](lifecycle-ux-current-guidance-01.md)和[实施手册](../operator/implementation-guide.md)。仅支持配置 schema3、DB14；非当前格式在写入前拒绝并保留原件，不提供格式迁移或离线接续。原历史介质及验证只说明其来源提交。

## 安装与运行

使用当前同源原生安装包，选择 D 盘程序、数据目录及快捷方式，按三步向导完成 Windows 授权。机级受保护根、路径及 ACL 由安装管理员核验。安装指定日常账户以普通权限运行业务，不因拥有 Windows 管理员身份而跳过 Application 或管理密码守卫。Windows x64 客户端仍按[功能门禁](windows-client-compatibility-01.md)核验，不把本机编译等同目标机通过。

SM 业务版本固定1.0.0，来源提交及独立输出目录区分测试构建。同版本允许覆盖安装，核验供包台真正关闭并释放所有权、介质完整、权限和安装事务；不要求作业已完成或完整业务备份。原账户、配置、数据和请求保留。登记缺失或启动种子丢失时，沿原配置账重建启动种子，不提升Pending、不读写业务库；没有原配置账时只准备符合原目录身份的首配种子。安装续办按受保护原记录区分未提交、已提交修复及待核实，不以新编号掩盖原结果。

安装后从原运行入口打开，未首配时进入独立首次配置；保存成功自动启动。四类参数共用完整候选、CAS与Pending/Effective；停止未完成不能创建第二个实例。首次设密、修复和离线维护使用当前登记绑定的受保护同版维护缓存。

SM Windows构建发布一个供包应用 `desktop/Ipc.Desktop.exe`，无参数启动工作站，单独传入 `--operations` 启动运维进程。运维工具独立启动，提供运行总览、日志中心、设备调试、专业参数和维护中心；打开、查看、登录和切页不暂停生产，控制由原Application执行，不创建业务实例；工作站未运行时可合法查看落盘日志，不读数据库。桌面只建立工作站入口；勾选开始菜单则建立工作站和运维工具两项，不勾选均不建立，两个角色仍可从已安装应用启动。安装完成默认启动工作站。只删除本产品受保护原登记可证明拥有、目标和参数未被用户改写的被替代入口。修复/安装维护继续从完整安装器、Maintenance.cmd和启动故障入口进入；运维维护中心可转交原受保护同版维护缓存，先退出工具再核验实际工作站所有权；IPC断连不证明已停机。测试构建使用同一 Ipc.Desktop.Test.exe 的两个入口，独立安装身份和IPC目标，不能混装。运维打开时共享持有本部署程序文件使用权，涉及这些文件的维护要求先关闭工具；异常退出后仍核验实际锁/进程，不借用生产业务锁。权限及分层验收见[IPC与维护边界](../design/sm-readonly-operations.md)。

## 回滚、清理与卸载

系统入口按当前登记库存声明投影。合法回滚目标未声明运维程序时，只保留其真实主程序入口，清除原部署拥有的运维链接；不从其他构建拼入EXE。返回当前双程序部署时恢复两项菜单。库存声明有运维程序但文件损坏或缺失，仍沿原完整性检查处理，不能按文件缺失降级为单程序。旧双 EXE 部署按其受保护库存投影旧入口；当前部署两个快捷方式指向同一应用 EXE。

离线上一部署回滚只切程序，目标须为登记保留、程序和库存完整且能读取当前格式的上一部署；不还原数据库、配置账或重发请求。同为1.0.0不同来源允许。旧构建清理按受保护部署关系及固定清单保留当前、合法回滚候选、实际责任和证据不足项。历史原结果按原操作、原部署可查，重新安装不隐藏旧余项。

卸载默认保留本站数据；明确选择同时删除时，按原冻结清单删除本站配置、记录、图片、日志及本站管理密码/授权锚。安装、回滚、恢复和卸载均保留真实所有权、引用及文件守卫。正在执行的缓存保持完整并报告余项，退出后沿原清单续办，不登记重启删除或把待清理冒充已删除。

## 备份、恢复与诊断

完整备份为一份集合，一致快照、原数据库名称、恢复目录及完成清单共同核验。交付使用独立文件夹并最后发布；删除只处理明确选择、可归属且冻结的有限清单，未知文件、活动恢复引用及实际占用保留。不能复制运行中的数据库或删除WAL代替完整备份。

恢复接受当前格式完整集合，可先读取备份的原站点和配置并恢复到隔离目录，无需先建空库。按原恢复标记、交接、部署登记、清理回执及机器安全状态重建责任；复制完成不等于启用。原请求、Unknown、永久防重与编号高水位保留，按同机身份、实物及RCS外部效果明确核对后才可启用。不提供虚构的RCS原请求远端查询。

诊断包、完整备份和运维日志只读查询有各自权限与白名单；不公开凭据、生产数据或厂商SDK。发布身份取自ASSEMBLY.json、application-release.json及SHA256SUMS。软件暂停不是安全急停。静态检查、本机构建、Windows跨进程/原生界面、真实SDK、客户RCS、完整安装生命周期和现场验收分别记录，不相互替代。
