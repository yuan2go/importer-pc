# SM 扫码、调试与采集诊断

操作页面使用中文字段、状态与纠正动作。代码参数键、异常类型和 SDK 原始错误进日志及诊断导出。

## 正常供包

作业卡片只展示 CurrentRoundId 的正式候选、条码、图片和结果，连续观察不闪动边框。所有候选先经过允许、排除及合法性规则；多码和非法码可在同轮自动识读期限内调整纠正。期限默认1000毫秒，不因帧、候选或放稳刷新；到期停止自动提交，可原位PDA补录。没有可信上件且无正式码时保持等待，不制造超时包裹。

点击左右投递卡片的标题、背景即可选中本位并接收键盘/PDA条码；点击图片、详情和只读值保留原功能。直接开始输入会转到本位条码框，回车沿用守卫。连续两次完整PDA输入分别处理，不拼接；普通键盘、粘贴和编辑标记为MANUAL。其他页面和独立窗口不抢焦点。

每轮最多一次首次RCS调用，相机/PDA/键盘共用提交权。可信移出立即结束本轮，不等待旧回包；准备但未开始尝试的旧请求不外呼，已开始的原调用继续收尾。新轮同码允许，不依赖RCS远端业务去重；晚到结果只入原记录。左右位独立运行，一侧外呼或人工输入不占另一位Busy。

无码、Scene、候选变化和重连不能单独证明离位。相机采集、视频和识别继续运行，未经现场核验的在位证据按未知降级。纯手动或视觉不可靠时，有效格口确认后3000毫秒恢复等待，持续原包自动读码仍受抑制；新的完整人工提交允许。当前手动失败或视觉降级异常已要求人工确认时，必须点击本轮“已取下包裹”，后来空盘不替代点击。未提交识读异常在视觉失效时也能人工结束。Unknown 在可靠离位且调用与回执收口后进入历史保管，可从“记录”核对。内置RCS不提供结果查询，原请求只发送一次。格口分配不代表物理投递完成。
新站默认海康原生识码。软件识别路线仍可选择码制，升级时保留已有站点码制和识别方式。

## 扫码与实际 RCS 调试

管理中心打开时暂停自动供包和识码，保留相机连接和视频。选择相机点击“触发扫码”才读取本轮条码并锁定对应原图；RCS离线时仍可触发调试读取。手工输入或本轮扫码准备独立调试请求后，只有点击“发送请求”才调用当前生效配置中的实际RCS服务。已在途的生产请求照原流程收口，调试采样不计为生产包裹。

再次扫码、离页、取消和授权到期只清理所属采集或从未发送的意图。已发调试请求保留原身份、配置、目标、报文和回包，执行及回执责任收口后转入历史保管。调试读取或发送仍在进行时按配置生效守卫保留待生效设置。关闭管理中心后按原启停、暂停及当前连接状态恢复自动供包。

## 采集诊断

同一倾斜条码的多轮搜索可能返回局部厚带和完整带，原先只有中心线互含或贯通像素相关的合并会漏掉部分重叠候选，导致单个标签被报为多码。现在线性码在方向、完整编码区间重合守卫之后，额外检查原图实际四边形的近完整包含（5×17 采样点至少80点），并验证相邻原图扫描线的连续图案；既避免累计相位偏移误拆同一标签，也拒绝跨过两张标签间的空白。矩阵码和两处独立同码的原规则不变。不按文字去重，不放宽业务多码拒绝。公开回归使用独立合成 EAN13 和双标签图；现场原图及离线复现留在本机，不加入仓库。

RCS 离线时保留相机连接和预览，自动识码暂停。恢复以实际远端确认为准。明确调试读取和请求发送各有准入检查。

体检通过 `ICameraAcquisitionDiagnostics.ReadCameraAcquisitionAsync` 读取原采集所有者的被动事实，不申请预览缩略图，不触发取帧、读码、设备重连或RCS请求。当前连接周期、最近有效帧、帧时效、解码状态及历史异常帧分开呈现。预览缩略图按需生成，其暂时不存在不代表相机没有取到帧；历史丢帧不会否定后来取得的有效帧。连接确认过期与仍有新帧也分别说明，视频与计数只提供采集证据。SDK原始错误继续留在原诊断/导出，页面给出中文处置提示。

## 验证边界

验证轮次一次提交、两位独立运行、可信移出与人工确认、原请求字节、在途与回执收口。合成验证、本机原生窗口、受保护安装、真实 SDK、客户 RCS 及现场分别记证。早期策略和验收见[历史工作包](../archive/work-packages/WP-IPC-SM-SAME-PLACEMENT-29.md)。
