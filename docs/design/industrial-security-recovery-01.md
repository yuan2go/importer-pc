# 本站管理密码与机器维护权限

当前实现使用 LocalManagementMode、ManagementModeBroker、WindowsManagementRecovery 和安装登记绑定的受保护维护缓存；不是待实施的目标设计。现场步骤见[维护手册](../operator/implementation-guide.md)，临时授权见[管理模式](../runtime/management-mode-01.md)。历史安全验证仍只对应原提交。

普通管理窗口每次验证本站管理密码，授权到期、退出、改密和重置撤销会话；真正执行命令时重新检查。Windows 管理员拥有安装、修复、卸载与本站密码重置的机器权限，不因此获得日常管理会话，不解除恢复隔离或未确认请求。

密码恢复由受保护服务发出两分钟挑战，绑定数据根、凭据修订、发起进程及启动时间、Windows 会话和随机数。提权维护程序核验真实管理员及同一会话，明确确认本站重置；提交时在原凭据锁内复核挑战和代次，原子保存新凭据并撤销旧会话与委托。结果丢失只核对原操作，不自动再次重置。旧共享恢复口令入口直接拒绝，无验证器或本地回退。沿用既有 PBKDF2 参数和密码长度，不为本任务增加密码政策。

首次设密、重置和修复使用当前安装绑定的同版缓存及完整清单；服务不可用先修复，不能删除凭据文件当作未配置。机级安全下限与发布完整性独立核验；安装与回滚不允许不理解当前维护协议的旧读取者。当前格式及生命周期协议见[版本规则](../runtime/version-compatibility-01.md)。

保留本站数据卸载保留管理密码。明确删除数据按原冻结清单删除该数据根的凭据、已配置标记和授权锚；其他安装共享引用仍拒绝。机器部署、审计和安全政策按现有规则保留，既不等同本站密码，也不随完整备份打包。恢复保留必要机器来源材料并核验同机责任，不降低机器安全下限、不复活已删除的本站密码和旧会话。跨机器补盖身份、供应商令牌和随机恢复码不在当前支持范围。

软件不能独立抵御恶意 Windows 管理员替换整个系统或清除安全政策。源码移除旧入口也不能撤回已安装旧服务或旧介质；部署覆盖、UAC 取消、真实服务、权限和重启需要各自环境验收，不由单次合成通过推断。
