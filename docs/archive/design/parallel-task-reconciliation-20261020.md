## 原计划的 UI 实现边界（后续收窄，未实施）

UI 仍调用同一 IParcelApplication。设备健康来源、位置当前观察、保留原作业、历史摘要分别命名；新失败观察不复用旧有效格口。最近摘要只读当前快照，非全量历史；选中详情仍按原 ID 查询。重刷不重建应用、设备、草稿、焦点或选择。

以原生 WPF 的 Auto/Star 栅格和局部滚动恢复比例；800×420 DIP 保护、暂停/恢复、未决原请求动作与关闭排空继续沿用。小窗收缩辅助摘要，关键状态与完整动作仍可达。Impeccable Operate critique/layout/clarify/polish 与独立 WPF 查询仅辅助，不用网页/CDP 验收。

最终组合复用冻结介质的核心、首配/辅助页和完整视觉旅程。新增验证仅覆盖阻断/登录直接可达、恢复后的信息层级/来源、最小空间、选择稳定与原责任。SDK/设备/实体触发、真实合同、跨账户/提权/重启安装和现场性能分别保留未验条件。
