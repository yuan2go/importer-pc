# BARCODE-PRODUCER-01 · TCP 条码生产者统一接入

目标相机 MV-PD010003-06M-12C 是 GigE 工业相机及光源套件，自身不解码。生产条码由 PC 侧海康读码平台（plain）或自研读码服务（sequenced）产生，供包台作为 TCP 客户端接收。两个生产者不能同时占用同一相机。

## 范围与职责

复用 TCP 分帧、Observation/DeviceHealth、Application 准入、唯一配置账、机级资源租约、原请求和受控恢复机制。两档协议共用 UTF-8/LF 和 4096 字节正文围栏。MVS 扩展只保留独立诊断用途，不发布业务 Ready。MvCodeReader 模块、其资格说明和测试只适用于智能读码器，不能用于本型号。

唯一设计来源：[协议 v1](../protocols/barcode-producer-v1.md)、[实现设计](../design/barcode-producer-01.md)；[黄金对话](../protocols/barcode-producer-v1.golden.json)由两侧共用。运行说明引用规格，不复制协议。

## 交付条件

- 版本化 plain/sequenced 规格和双方共用黄金对话，包括握手、物理及配置身份、启动标识、序号、触发、心跳、断线和恢复语义。
- 同一 TCP 提供者支持两档。握手/序号/存活错误封锁连接，旧 Epoch 拒收，不自动重连或重放。
- 保存时校验 profile/实体模式/证据、物理互斥和期望身份；切换须暂停、处置在途原件、停止原生产者、确认释放、保存候选、受控启用。
- 默认 observe-only；条码不能作为实体身份。健康、握手、连续性和配置有效均是业务准入条件。
- 提供无条码原文及物理序列号的状态、计数和失败原因。
- 必要风险测试、完整构建、运行文档及 main PR。未执行真机/真实读码/RCS验证不得声明通过。

读码服务实现、读码平台现场配置、生产资格与签名流程在本包范围外。已有资格、授权、Unknown、存储和原请求守卫继续有效。原 D/RV、原始要求和历史验收回执保留原身份。
