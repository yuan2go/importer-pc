# Codex / Agent 工作约束

1. 先读 `docs/INDEX.md`、`docs/baseline/PUBLICATION.md`、`docs/baseline/MISSING.md`、`docs/reviews/STATUS.md`。main当前仅为公开部分基线；未入库的客户原件不可用想象补齐。
2. 本包只归档资料，不开发或重构业务代码。没有核验既有C#工程、SDK、真实WCS合同或Windows部署环境；不得虚构构建/测试命令。
3. 原始要求、HTML模拟行为、工程建议、未决规则和历史验证分别解释。保留REQ/BR/CAPI/D/RV编号；不把设计作者的建议转成客户批准，不把归档当问题关闭。
4. `docs/reviews/issues.json` 是上一轮独立评审完整技术问题表；所有RV-01～RV-17仍OPEN。报告中的“本次”指历史评审，不是当前归档执行；外部后果为条件风险时继续保留条件。
5. `docs/ui/tokens/` 为v1.1原样设计变量，含未验收的布局假设；只可参考，不构成Windows DPI、触控、相机/WCS或连续作业验收。
6. 技术基线优先核验并继承已有C#程序；HTML只是交互载体，不默认Web、WPF、指定.NET版本或其他语言迁移。无依据不增加微服务、PLC直控或云端图片服务。
7. 分清设备触发、读码观察、供包作业、业务请求与发送尝试；识别、保存、发送、业务接受、物理完成不能互相替代。相同条码不等于相同作业。未知结果不得盲目重发；软件恢复不能绕过其他阻断原因，软件暂停不是安全急停。
8. 改动前核验最新main，普通提交或遵守保护规则的PR；不强推。保留历史证据；只有经批准的修订才进入当前规格，并附变更记录和验证依据。
9. 公开仓库不提交客户资料、私密访问链接、凭据、生产数据、SDK二进制或字体文件。脱敏不等于获得公开许可。补齐完整资料前先落实授权范围或获授权的私有归档位置；不自行改变仓库可见性。
