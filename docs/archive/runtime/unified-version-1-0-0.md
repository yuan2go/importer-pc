# 1.0.0首次安装测试交付

工作包：[UNIFIED-VERSION-1-0-0](../work-packages/WP-IPC-UNIFIED-VERSION-1-0-0.md)。2026-10-27起，自有基座、公共契约、SM业务、驱动、集成及组件当前发布版本统一为1.0.0；共同引用的其他业务同步归一。程序集、组合清单、精确提供者声明和安装包从同一固定源码构建，具体身份仍读取SourceCommit及文件SHA256。

安装包输出到D盘，由用户自行安装。卸载/清理前的配置、管理凭据和业务数据保留在本地受保护备份中；它们不作为新站初始配置。海康软件、SDK及共享运行库保留，新安装程序仍按需检测实际能力；保留SDK不代表真实型号和现场读码已经验收。

构建、脚本及原生合成验证与完整首次安装分别记录；实际安装、真实设备/RCS与现场资格由对应测试确认。
