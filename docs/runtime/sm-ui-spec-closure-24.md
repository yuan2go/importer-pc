## 已实施的语义

- 连续预览只读，不创建隔离、作业或请求。既有手动/相机按轮调试仍走原自动按轮生命周期，不恢复旧说明输入/隔离面板。新增连续20个**解码帧**试扫是独立的全局持久隔离流程，两位都停止生产受理；限30秒/1分钟会话/64MiB/1000记录，停止采样后保留隔离，清场结束仅解除该会话隔离，仍软件暂停。无原请求重放或自动恢复。20帧不等于20件。
- UI审阅与Application共用完整候选判断：SM、无Pending、候选只改变条码规则才有资格屏障排空后直接生效；混合修改全部待重启。保存执行时继续核验最新修订、权限与原责任，失败不假称生效。必填审计原因保留，增加预设。
- 作业页“取得格口次数”来自持久统计，不由回调递增；观察按观察时刻，请求与结果按原准备时刻归属班次。相同条码独立识别仍交RCS去重。近10分钟按分钟桶，当前分钟含已提交事实；不代表实体件数或落格完成，读取失败/过期显示破折号。
- 相机指标分开有效帧、解码帧、有码解码帧和条码候选。最多60个单调分钟桶，显示实际覆盖；连接代次重置，不称包裹漏读率，不使用无依据95%告警。RCS耗时最多保留4096个近10分钟真实生产发送样本，显示覆盖、中位/P95和本次运行容量淘汰数；不包含调试，也不等同HTTP接受或物理完成。
- 内置RCS没有结果查询合同；Unknown/Conflict看原请求证据与交接，不发送替代POST。其他明确支持查询的组件继续使用原请求身份。确认未送达时新扫描的独立请求与重发原请求严格区分。

## 页面闭环与原机制

|范围|最终行为|
|---|---|
|P03–05|标准/紧凑作业显示本班/近10分钟与分位次数，共享Application的有界只读缓存；当前Windows用户可隐藏/恢复。小窗口保留触摸按钮高度。|
|P06|直接完整条码回车查询、可见同快照汇总、状态筛选、时间预设、原详情/图片/动作及日志互跳；SM同固定上界加载更早记录，最多1000可见条目，缩小范围继续查。归档列明确只读事实。|
|P09|可见相机对象行、最近错误/窗口分母、设置/调试定位，RCS确认与耗时，存储/备份；保留受控重连与原证据。详细日志从日志页移入诊断，由Runtime30分钟自动关闭，切页不影响。|
|P10–11|按本站接入/相机/分拣规则/系统维护/高级导航，字段仍属原系统/业务/驱动/组件。统一站点与RCS，包含两端X..Y投影原base/count，错误输入不能保存旧有效值。双相机并排/窄窗纵排、小只读预览、唯一编码只读引用、原物理身份及码制。|
|P12|差异表逐行显示本次完整候选的真实生效方式，预设审计原因、原CAS/Pending/Effective、失败保留输入。继承原常驻待重启入口。|
|P13|关键事件/时间预设、多选级别/来源、更多筛选、固定快照单一导出入口；作业ID取结构化原字段，禁止用自由文本GUID或同码扩大互跳范围。实时/文件查询共用匹配。切换作业取消排空旧查询并核页面代次。|
|P14|首屏发送卡、既有左右切换、只读现场预览与按轮证据、隔离范围明确；连续试扫见上方独立合同。|
|P15–16|维护场景响应式布局和真实待办；管理服务端续期仅原有效会话最后2分钟可用、15分钟新到期，保留身份/首次认证时刻、原授权票据和原维护/调试期限。免登录仍隐藏操作员入口。|
|P17–18|五个可见步骤按钮、当前高亮/已检查标记、前进校验/后退保留、缺项摘要、四类实际候选汇总可返回修改；退出未完成窗口显示实际字段问题。保存/启动仍分开，未确认保存不能重试。默认备份路径在D盘。|
|P19–21|离线场景不显示原五页签；完整操作进专家入口，保留恢复到新根/换机/源版本与权限守卫。安装实际阶段归六组、失败显示实际阶段/下一步，未知结果不盲回滚重试。卸载仅有残留才显示继续清理，原记录可展开。|

任务导航不迁移数据库字段，数据库格式仍11。一个Application服务多页，复用原相机采集/发送所有者；没有新增物理驱动、SDK调用或直接SQL查询。预览资源、Timer、订阅、查询取消均随原窗口生命周期退出；隐藏显示偏好不改业务配置。公开通用代码与合成数据未更改现场根、服务或设备。

记录读取新增短事务批量契约：单次页面、汇总及位置列表来自同一个SQLite读取事务，读取完即释放，不跨页面长期持有WAL快照。固定上界仅排除后来的新作业；已有作业状态会继续变化，已加载行保留当时快照，下一批汇总反映本次读取，详情实时读取，导出在自己的短事务中重新读取同一边界。UI和说明不声称跨页/导出是冻结历史状态。旧组件无批量能力时保留原固定上界读取，不扩大其证据。
