# 可编辑原型源文件

这些文件是离线 HTML/CSS/JavaScript 交互规格，不是已经移植到 C# / WPF 的生产客户端。无需更换 importer-pc 技术栈；开发应把对象模型、状态机、绑定和视觉规格落实到现有桌面客户端。

## 文件

- `styles.css`：颜色、中文字号、栅格、控件、固定状态和紧凑尺寸规则。
- `app.js`：作业、记录、对象参数、保存/应用、诊断和未保存离开的模拟状态。
- `aux.js`：首次配置、安装维护、模板、备份恢复、帮助支持及兼容维护。
- `scenarios.js`：45个可定位的命名场景及纯模拟初始状态。
- `scenes-manifest.json`：逐图目的与场景名称。
- `contract.md`：实现分工和交互对象约定。
- `assets`：Noto Sans CJK 字体子集及许可。

运行 `python build_prototype.py`，将在上级目录生成 `Sportmaster-Prototype-Rebuilt.html`。无需 npm 或第三方 Python 依赖。直接编辑主 HTML 也可调阅。

字体子集覆盖本次设计文字；新增字符由 Windows 的微软雅黑等后备字体显示。如果跨平台字体缺字，应替换为有许可的完整字体或重新生成子集。

原型不连接设备、WCS 或其他生产服务。保存、应用、安装、恢复和连接结果为模拟状态；下载得到的JSON/CSV也明确标为示例。刷新或重开原型会重置模拟状态，不会持久写入真实配置。演示控制和故障注入入口不属于正式作业界面。

未知真实驱动字段、参数范围、默认值、协议副作用、设备重连能力与运行版本读回均见开发交接说明。生产实现不得把演示的成功延时或数据当作真实设备行为。
