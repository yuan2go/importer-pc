# SM 管理中心与自动供包

## 退出供包台

整站退出先显示约580×340 DIP的紧凑确认窗，白底细边框，标题“确认退出供包台？”。本次可见作业、结果未知阶段、状态读取和待生效配置用两列普通文本展示，不使用警告图标、数字卡片或黄色提示条；读取失效明确标注，未披露的待生效状态显示“待确认”。已发送请求及未确认结果继续保留，下一步逐窗处理未保存设置，停止失败保留当前窗口；急停说明单独使用灰色文字。

“取消”默认聚焦并作为默认按钮，Esc、右上角×及关闭确认窗均取消本次退出。右侧“继续退出”使用主题深灰色和44 DIP高的紧凑按钮，确认后沿用原来的草稿保护、停止和实际释放流程；失败可再次确认重试。应用已保存配置时使用同一布局，标题和动作改为“重启”。小工作区只允许正文滚动，底部动作始终可见。原生验证入口为`--station-exit-dialog`，合成状态覆盖未知结果、待生效配置、读取失效、取消和停止失败重试。

## 管理窗口

管理中心每次打开验证一次管理密码。窗口打开后，Application 按原窗口身份暂停普通扫码、人工供包和新的自动派发；保留原暂停状态、左右投递位启用状态和已发请求。离线或未配置相机不阻止管理中心打开；重连和配置替换后的相机仍遵循窗口的暂停状态。相机连接及预览保留，自动识码暂停，明确触发调试才读码；海康原生路线在暂停期间只读取原图，不调用原生识码。

RCS 离线或连接确认过期时，同样暂停自动识码并保留相机预览；恢复有效连接后自动继续。读码控制在推迟连接之前登记，保证启动时已停用、配置替换时仍停用的相机后来启用时，第一帧就受当前 RCS 状态控制。管理中心的明确读码不依赖 RCS，发送请求仍核验真实 RCS。关闭管理中心恢复的是当前连接条件下的自动识码状态，不能在 RCS 仍离线时恢复；原请求和当前放置结果不改写。

密码窗口明确区分验证成功和取消。进入流程等待最新授权观察已应用到界面后再继续，不因后台刷新抢先发起另一轮观察而提前返回。暂停供包成功后，即使进入途中的授权状态改变，也打开由原窗口持有的锁定管理窗口，允许重新验证或关闭恢复；不能静默丢掉窗口而留下暂停。

管理窗口切页不重新验证密码。授权到期锁定管理页面并保留草稿，自动供包保持暂停。关闭原窗口无需仍有效的管理授权：先取消并等待未发送的调试读码轮次结束、恢复采集路径后，再撤下自动供包围栏；不等待扫到条码或读码超时。失败时保留围栏和原窗口以供重试。软件本来已暂停或投递位本来已停用的，不因关闭管理窗口而自动启用。

调试会话创建时即登记所属管理窗口，不等到触发扫码才登记。已排队的旧调试授权回收须核对原管理会话；窗口已关闭并恢复供包后，不再重置相机缓冲或打断恢复后的采集。

授权服务短暂通信失败时，当前读取不能授权命令，但不把通信失败当作撤销回执，不丢弃原令牌。后续确认恢复且原授权尚未到期时继续使用该授权；旧令牌的迟到状态不得撤销新授权。服务明确拒绝当前令牌时仍立即撤销。

诊断页按左相机、右相机、RCS、存储排成两列两行，详情保留折叠。管理入口使用齿轮图标。未配置相机始终显示待配置，独立于投递位启停状态；已配置相机的实际释放失败仍显示待确认。

调试页面不把过期的界面连接确认直接说成相机离线，也不据此封死触发入口。已配置且未停用的相机允许重新核对；实际触发由 Application 使用当前连接、配置和会话守卫判断，失效状态不能绕过守卫。

投递位停用中拒绝新条码，保留当前相机及已校准的在位证据。不同条码、无码、固定时间及旧请求回包都不单独证明离位；可信移出或本轮人工取下确认结束放置后完成停用，不等待旧 RCS 结果。未校准或视觉失效时按人工降级处理，不算全自动验收。

首次配置的打开方式随首次配置一起保存，跨配置步骤保留选择；首次进入作业窗口即读取已保存方式。全屏时 Esc、F11 和系统还原不返回窗口；右上提供最小化到任务栏及“×”退出软件，最小化恢复时仍为全屏。退出沿用原有停止与释放流程，失败保留窗口、说明原因并可重试。打开方式仍由管理中心的保存设置控制。

首页顶部右侧并排显示本机时间、全屏最小化按钮及退出“×”，不设品牌标识。左侧菜单采用图标在上、文字在下的窄栏，右边缘中部的拉手在展开时向左、收起时向右。供包状态、操作说明、班次统计及 RCS 在同一行；操作反馈单列于下方窄栏，无内容时该行高度为零。

待机、RCS 离线和已停用共用居中的浅灰状态区域，标题依次为深绿色“等待投包”、深红色“暂不能投包”、灰色“已停用”。离线保留输入条码、禁用提交，提示检查 RCS 连接后提交；没有“重新扫描”或“开始”动作。真实拒绝、处理中、未确认请求及有效格口仍显示原结果。收起侧栏为 52 DIP，图标 18 DIP、选中与点击区域至少 44 DIP；边缘拉手视觉为 18×36 DIP，点击范围保持 44×44 DIP。

左右卡片底部将输入提示、操作按钮、设备信息分为三条共享高度行。只有一侧出现提示或提示换行时，另一侧仍为同一提示行让出高度，提交与详情按钮以及相机信息保持对齐；提示清空后共同收回高度。

作业页的软件暂停不遮住本次多码拒绝、业务拒绝或未确认责任。单码已读到但准入受阻时，明确显示尚未受理、未请求格口；当前相机观察按身份保留一张完整原图，每位至多一张，后续观察替换、停止或新班次后释放，不生成作业、请求或持久化图片账。拒绝放置仍沿用原拒绝原图。顶部仅在软件暂停时提供“恢复供包”，沿用 Application 的恢复守卫；不能恢复时提示到设备与诊断检查。恢复本身不重放受阻输入，也不重发原请求。
