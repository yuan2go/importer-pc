# 菜鸟供包台：安装与首次配置 UI 实施规范

版本：2026-10-22 · 范围：安装选项、安装确认、安装中、安装完成、安装结果待确认、首次配置入口及管理密码对话框。

## 1. 依据与实施边界

本设计依据用户提供的 `image(1).png` 至 `image(6).png`，以及用户认可的前两页简洁分组方案。**未读取执行时最新仓库，未验证实际安装、鉴权或设备行为。** 随包预览是界面参考，示例值不是生产配置；演示按钮和状态不等于后端能力。

原图可见：程序与数据目录被其他选项隔开；进度页把复制、校验、登记和快捷方式合成一句；成功页出现较大的空白；首次配置窗口同时显示“未开启或已到期”及首次设密码弹窗，背景主体为空、底部按钮全部禁用。这些是截图表现，不能据此断言源码必然存在对应缺陷。

实施前查明安装器及首次配置窗口的真实技术栈、所属项目、入口、状态来源和权限服务。继续使用现有 Windows 原生框架；HTML 不作为引入 WebView 或重写安装器的理由。本轮调整布局、文案、交互状态及必要绑定，不改变协议、配置含义、安装事务、密码策略或权限边界。

## 2. 统一视觉规则

白色内容区、浅色侧栏、深色正文、灰色辅助文字，蓝色只强调当前步骤和主要操作。信息按阅读顺序排列，避免大图标、连续卡片、粗外框、装饰性渐变及大段技术说明。

| 项目 | 参考值与要求 |
| --- | --- |
| 页面标题 | 24 DIP，语义明确：安装选项／确认安装／正在安装／安装完成 |
| 分组标题、正文、辅助文字 | 15／14／13 DIP；随系统缩放，不能靠缩小字体塞内容 |
| 间距 | 内容边距 28–32 DIP；分组间距 24–28 DIP；字段间距 10–12 DIP |
| 对齐 | 标签宽约 76–88 DIP；输入框等高；浏览按钮同宽；路径字段可复制 |
| 控件 | 输入框和常规按钮约 38–40 DIP；圆角 4 DIP；保留键盘焦点反馈 |
| 操作栏 | 当前页面通常只有一个主要操作；次要操作使用普通样式 |
| 尺寸适配 | 窗口不超过工作区；不足时优先减侧栏和边距，再允许内容区纵向滚动，主要操作保持可达 |

尺寸是设计参考，不是必须逐像素硬编码的约束。以实际原生控件、字体度量及 DPI 为准。侧栏作为进度指示，未经状态允许不能点击跳步；安装中可归在“确认并安装”步骤，无须增加操作步骤。

沿用仓库现有软件图标及原生窗口标题栏，不为复刻预览重写系统窗口装饰。HTML 顶部设计工具栏、演示反馈，以及 SVG/PNG 标题栏中的“UI 设计稿”标注均属于交接说明，不得实现到产品中。

## 3. 安装页面

### 安装选项与确认

沿用已认可的两组结构。**安装位置**连续展示程序目录、数据目录；**安装设置**展示使用范围、快捷方式。保留“所有 Windows 用户／仅当前 Windows 用户”两个选项及两个独立快捷方式开关。切换范围是否联动路径由现有规则决定；不得凭设计稿覆盖用户输入。

确认页展示同一份选项数据，标签和值对齐，长路径完整换行。“使用用途”改为“安装用途”；仅在确有需要核对的用途差异时显示。上下页往返保留选择。升级说明仅在识别到旧版本时出现，备份范围和失败处理按实际能力描述，不承诺“全部数据不变”或“自动回滚”。

### 正在安装

标题为“正在安装”，辅助说明“请稍候，安装完成后将显示结果”。主体只保留当前阶段、进度和可选详情。阶段文案例如“正在复制程序文件”，必须由真实状态驱动，不把多个阶段写成一条长期不变的句子。

有可信总量时显示实际进度；无法计量时使用不确定进度，不显示编造的百分比、剩余时间或自动计时成功。等待 UAC 时才显示授权提示，获得授权后移除。不要始终保留“请在 Windows 授权窗口确认”。

不展示三个无意义的禁用按钮。是否提供“取消安装”以安装事务是否支持安全取消为准；取消请求不等于已取消。窗口关闭、失败、权限拒绝和异常退出按原有事务边界处理。失败页显示原因和实际可用操作；不得无条件提供“重试”或宣称原版本已恢复。日志详情入口仅在有真实来源时提供。

### 安装完成

标题为“安装完成”，正文“菜鸟供包台已安装”。首次配置确实未完成时显示一个紧凑的“首次使用”分组：“首次打开后，请完成设备与服务配置，再按检查结果启动。”仅当包能力确为 Sportmaster 时具体提示相机及 RCS，不能将其硬编码到其他业务包。

保留“完成后打开供包台”与“完成”；“打开”只表示启动应用或首次配置入口，不表示自动启动设备作业。升级且配置有效时不再要求重复首次配置。安装成功由实际终态判定，不能因进度动画结束而判定。

### 安装结果待确认（第 9 页）

新增截图标题为“安装未完成”，但正文同时说明“未取得可信维护终态”“安装可能已提交”。截图反映的是**最终结果未确认**，不足以判定安装已失败、尚未提交、仍在执行或已经成功。实际代码应把结果未知与已确认的成功、失败、取消及仍在进行区分开；不要只根据某条旧进度消息推导当前状态。

本页标题统一为“安装结果待确认”，正文为“未能确认本次安装的最终结果。”及“请先查看本次安装记录，再决定后续操作。”；用浅琥珀色提示条突出“确认前，请勿重复安装。”。不使用整段红色或失败图标，也不将左侧“安装完成”标成已完成。

“安装详情”默认收起。展开后分别显示历史消息及诊断结果，示例“等待 Windows 授权”必须标为历史消息，不继续要求用户在授权窗口确认。原始日志应保持原样供核对；摘要与原始记录明确区分，有真实时间戳才展示时间。摘要中的“未取得可信维护终态”可保留在技术详情，不能继续占据页面主标题或主要说明。

底部只有主要操作“打开安装记录目录”和次要操作“关闭”。目录入口绑定本次安装事务已有的真实记录路径；打不开或记录缺失时提供明确反馈，不伪造路径、记录或最终结论。窗口关闭不等于取消安装：先核对与后台安装/授权进程的生命周期，保留既有事务保护；不能为简化 UI 直接杀进程或未经依据宣称关闭不会影响安装。

本状态不添加“重试”“重新安装”“回滚”或无依据的“重新检查”按钮。只有后端已有可靠的只读结果核对能力时，才可进一步接入结果刷新，并确保不会重放安装事务。本轮原型不模拟这项未验证能力。

## 4. 首次配置与管理权限

首次配置入口先给出明确动作，避免空白背景与成排禁用按钮。未设置管理密码时展示标题“首次配置”、说明“配置前，请先设置管理密码”，主要操作为“设置管理密码”；已有密码但未授权时改为“进入管理模式”。后台恢复会话失败与首次初始化不能共用模糊文案。

| 状态 | 界面与允许操作 |
| --- | --- |
| 尚未设置管理密码 | 打开“设置管理密码”；两个密码框；设置成功且真实授权后才进入配置 |
| 已设置、未授权 | 点击“进入管理模式”，打开“验证管理密码”；只要求现有密码，不再出现确认密码框 |
| 授权有效 | 显示真实管理状态；开启被授权的配置操作 |
| 配置中权限到期 | 提示“管理权限已到期，请重新验证后继续”；停止保存和应用变更 |
| 密码验证失败 | 在密码框附近显示失败反馈，保持当前流程；不得静默降级或绕过验证 |
| 用户关闭授权对话框 | 返回明确的待授权入口；可重新进入或退出配置，不落入无说明的空白页面 |

首次设置对话框标题用“设置管理密码”，说明“用于保护参数设置，请妥善保管”。标签用“管理密码”“确认密码”；规则放在输入框附近；主要操作“设置并继续”，次要操作“取消”。对话框随内容收紧，去掉包住全文的巨型外框。密码可粘贴；显隐由明确按钮控制，不写入日志、分析事件、浏览器存储或预览文件。

截图规则为 **12–256 个字符，至少包含 5 个不同字符**。“不同字符”不等于“五种字符类别”，不能误改为必须同时包含大小写、数字等五类。真实长度计数、空格和 Unicode 规则、错误反馈、失败次数限制及密码存储由现有实现决定，先核实再绑定，不在 UI 层另造策略。

会话过期时只可保留当前进程中的未保存输入，且必须再次通过真实鉴权才能提交。不能据此承诺已有持久化草稿，也不能绕过服务层权限检查。设置密码、会话到期及取消时清空密码输入。应用管理权限、操作员业务账号与 Windows UAC 是三种不同状态，界面名称和授权判断不能混用。

本次没有首次配置内页截图，不扩写相机、RCS、称重等参数页；完成入口与授权衔接，保留后续现有配置流程。

## 5. 交付与必要验收

实施者记录基线 SHA，给出设计状态到实际窗口、控件、ViewModel／事件处理和服务的映射。冲突文档先裁决，过期内容归档或标明被替代，并更新入口；历史证据不要直接删除。

必要验证包括：两页数据一致及往返保留；真实安装状态与失败/拒绝授权；结果未知时不误报成功/失败、不提供重复安装入口，历史授权消息不冒充当前状态，记录目录对应本次事务，关闭不破坏原有事务保护；首次设密、已有密码验证、会话到期与取消；失权时禁止实际提交；密码不外泄。只覆盖本次变更风险，不增加镜像实现的测试或无关全量测试。

在可用 Windows 环境核验 1024×768、1366×768 及 100%／125%／150% 缩放下的关键组合，检查截断、重叠、长路径、键盘顺序、焦点与操作可达。截图只能证明相应环境的视觉结果；不能把浏览器预览当作 Windows 原生验收。交付修改清单、真实截图、必要测试结果与未验证事项。
