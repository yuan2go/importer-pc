# SM 双程序阶段与剩余迁移

本文件记录双程序的阶段边界。第一阶段为“独立只读运维与设置入口”，实现、权限/暂停矩阵及分层证据见[当前实现](sm-readonly-operations.md)；下列第二阶段内容是待实现方案，不作为已经开放的功能或当前作业规则。范围只包括 SM 及必要共享基座。

## 第一阶段

| 能力 | 实际分工 |
|---|---|
| 业务运行 | 工作站持有唯一 Application、相机SDK、RCS、业务数据库及原请求。运维工具不装配第二个业务实例。 |
| 工作站导航 | 作业、记录、设置；默认作业页。原管理中心的诊断、完整设置、调试、日志与受保护维护入口保留。 |
| 独立运维 | 运行总览、日志只读查询。当前受保护安装、同账户/会话、实际进程、协议版本、权限和运行实例核验。断线/过期撤下实时值，“未连接”不代表“已停机”。 |
| 离线 | 只读当前安装范围已脱敏的运行日志，不读业务库或认证日志，不自动启动工作站或设备。 |
| 设置 | 非模态窗口，默认只读摘要；每次编辑验证管理密码。返回作业保留草稿，主窗人工/PDA继续走原控件及提交路径。切窗按原规则清除工位选择，重新选位，不暗中转投条码。 |
| 配置与授权 | 一份完整候选、原修订CAS、Effective/Pending/Unknown。查看、登录和编辑不申请管理暂停。关闭只结束本窗原会话，不撤销后来授权；到期/替换/未确认锁定编辑并保留输入。 |
| 安装入口 | 一份同源完整介质安装两个 EXE。桌面仅工作站；选开始菜单则建立工作站与运维工具两项，未选均不建立；安装完成默认启动工作站。只清理受保护原部署可证明拥有且目标/参数未被用户改写的旧入口。修复和维护从现有安装器、Maintenance.cmd及启动故障入口进入。 |
| 文件使用 | 运维共享持有本部署程序文件使用权，安装/修复/回滚/清理/卸载对实际相关范围独占；不取得生产业务租约，不阻止其他部署的文件维护。异常退出由OS释放，维护仍重新核验实际句柄/进程和原冻结清单。 |
| 测试安装 | #275 的测试身份是另一套安装登记，不是同一部署的运维进程。每个身份各自包含两个同源EXE、目录、密码、偏好、入口和IPC目标。不能混装正式运维工具和测试工作站。 |
| 共享资源 | `Ipc.Presentation.Wpf/Themes/Workstation.xaml` 是两宿主的实际公共字典，Desktop路径仅合并。#277 的底栏、暂停状态、可复制消息样式在此定义；SM作业卡仍归自身主题，不引入Web组件或第二套视觉规范。 |

原业务状态机、同轮一次提交、防重、Unknown、远端发送围栏、编号及请求期限均沿原契约。可信空盘和有效换车并行分轮；已确认原请求的包裹可信取下后，同车下一件可独立提交。上一件回看只按原条件短暂展示，不占提交权、不开放旧图片/操作，不靠三秒显示期证明物理边界。

第一阶段不开放运维写命令、不取消原管理工作区的整站暂停，不宣称设备调试已经按位隔离。只读运行正常、设备连接和允许本件供包分别显示。

## 第二阶段待实现清单

1. **现场/专业字段分工**：按现有字段及真实消费者列出归属和执行权限。工作站保留本站/RCS接入、左右相机地址/业务编码、只读物理身份、格口策略及个人偏好；技术通讯、期限、读码、采样、日志/存储参数迁入运维编辑。当前仍复用完整设置页，不能将此目标误写成现状。
2. **运维配置写入**：以受控IPC调用唯一 Application，继续生成同一完整候选；服务端按字段权限及完整修订CAS核验。两端并发冲突保留草稿；保存结果未确认核对原提交，不重做业务保存。偏好按Windows用户独立保存，部分失败仅重试失败项。
3. **显式调试会话**：先选设备和动作，再由 Application 返回真实影响范围与会话身份。申请、动作、结束、授权到期、断连和工具异常退出均沿原责任收口；只在资源及RCS责任证明允许时缩小为按位，否则明确显示整站受影响。默认观察不自动识码、标定、断开相机或发送RCS。
4. **设备调试页面**：相机预览/原图/识读/空盘校准与RCS通讯/真实取格口分开。图像带采集时间和有效性；明确“发送真实请求”，原未决请求不能自动重发。停止按钮只发结束请求，未确认资源释放不能显示恢复生产。
5. **维护中心迁移**：复用现有受保护维护、诊断包、完整备份保管、历史结果、回滚、恢复、清理与卸载。运行中许可动作和必须离线/Windows授权的动作分开；恢复继续沿隔离、原请求、Unknown和编号高水位围栏，复制完成不等于启用生产。不另建账号、维护账或数据库迁移路径。
6. **入口收敛**：上述能力具备且验证后再撤下原管理中心对应入口；保留未迁移能力，清理被替代的代码、文档和专属旧测试。运维最终五页是目标，不显示尚无实现的占位操作。

## 实施与验收约束

协议严格白名单，不建立远程TCP/HTTP管理服务；图片显式请求、有界传输，不增加第二相机消费者。权限在实际执行时核验，按钮禁用不是权限边界。断线不是撤销、超时不是未发送；有副作用操作保留固定身份、真实回执与原目标。

原工位焦点、F2/F3、Esc、键盘/PDA来源判定、同轮原子提交和当前图片/原请求归属继续生效。原型不能新增人工条码弹窗、猜测字段、RCS远端查询或临时放行守卫。

沿现有测试验证真实实现，仅在设备和网络边界使用可控替身。分别列出静态检查、Windows编译、真实HWND/SendInput、跨进程/令牌/句柄、受保护安装及隔离身份、厂商SDK/真实相机、客户RCS、长稳和现场结果。100%/125%/150%实际系统DPI、1366×768及低高度窗口、中文长消息、复制/滚动/格口和焦点按风险验证；后台大画布不是物理显示证据。

未验证的真实硬件、客户RCS、目标工控机及现场长稳仍单列。第一阶段完成、自动验证通过或PR合并均不等同完整双程序已达到生产交付标准。
