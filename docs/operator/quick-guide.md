# 供包员作业卡

适用：SM当前托盘放置流程及IE01候选。打印稿与本文同源，正式现场交付须绑定实际安装版本；实体打印与新人旅程另行验收。

1. **打开软件，看本位状态。** 软件自动检查并启动，首次配置保存后也会自动启动；条件不满足时显示具体原因。左右位分别判断；“待配置”或“不能受理”时交给管理人员处理。供包员不负责填写设备地址或管理密码。
2. **条码朝上放入托盘。** 等待本位当前包裹的有效格口。同一包裹一直留在托盘上时，相机仍识别，但不持续请求新格口。本位可用且托盘无包裹时显示“等待投包”；有包裹读不到时调整标签，或使用允许的扫码枪/键盘补录。补录前点击该位相机区域，或按 F2（左位）/ F3（右位）选择输入位置。
3. **只按本位、本件、当前有效格口操作。** 看不到有效格口时先读提示，不凭上一件结果投递。成功结果首次显示起保留3秒展示机会；新车已到且下一件尚未开始时，会同时显示“上一件格口·仅供查看”、原条码/任务号和当前是否可以扫码。放入下一件后立即切换，不按上一件格口投递。可靠相机仍确认包裹在位时，补录成功也保留本件格口直到真实移出。纯手动或视觉不可靠时，有效格口显示约3秒后撤下，已接单仍等待下一车；这不表示包裹已经移出。明确拒绝时如有“已取下包裹”按钮，请先取件，再确认。
4. **结果未确认，先保留包裹与记录。** 取下暂放一旁，进入“记录”查看本次作业并交给维护人员核对，不反复上件。当前内置RCS没有权威结果查询能力，查看记录不等于重新向RCS查询。

软件暂停时，按作业页提示检查现场并使用“恢复供包”。设备危险按现场安全流程处理，软件暂停不能代替安全急停。相机离线影响该相机来源；人工补录是否可用由当前RCS、容量及原责任检查决定。

故障解释见[故障目录](fault-codes.md)，实施操作见[实施手册](implementation-guide.md)。本版本隐藏帮助按钮和菜单，F1 不打开帮助；请使用交付的离线手册。需要诊断时请管理人员进入“设备与诊断 → 维护工具”导出诊断包。文件只保存在本机，交给支持前需取得分享授权；诊断包只包含部分白名单摘要，不能替代原记录或完整备份。

自动识读默认1秒快速窗口；同件持续可靠在位时继续降频识读，否则可原位PDA补录。无码、非法码和多码异常取下后，可信空盘自动结束本件；视觉不可靠才点击本轮“已取下包裹”。未发请求且安全时，同车直接继续投下一件，无须启停。已接单显示“等待下一车”；结果未确认或拒绝副作用不明显示“请求待核对”，请联系维护，不能启停或重扫解锁。空盘至少3帧且800ms，换车可独立建立边界；3秒显示结束不证明物理离位。

开工时由管理人员在本位没有当前包裹、画面确实为空托盘时，进入“设备与诊断”执行“确认空托盘并校准”。重连、重启、画面尺寸变化后需要重新校准；未完成或失效时按人工降级处理，不能当作全自动分轮。光照、遮挡或包裹外观导致相机不能可靠判断时，按提示补录及确认取下，不用换条码代替移出。
