# 实施人员部署卡

适用 SM 1.0.0。备妥可信完整安装包及 SHA256、可用 D 盘、Windows 管理员权限、本站与仓/生产线编号、真实 RCS 地址、左右相机 IP 及唯一 RCS 相机编码。

1. **安装或更新。** 关闭供包台和运维工具，核对介质、部署和数据目录，按向导完成 Windows 授权。同格式覆盖安装保留原配置、业务数据和请求。安装结果待确认时核对原操作。开机自启默认关闭，按需选用，仅管理当前 Windows 用户的本站工作站快捷方式。
2. **完成首配。** 填写本站与 RCS、左右相机、识读规则，最后检查并保存。新站默认海康原生识码，核对完整介质包含匹配的原生运行库。可填写 IP 或扫描局域网相机并设为本位；保存前按 IP 核验序列号。空 RCS 地址表示待配置。首配保存后自动检查并启动。
3. **分别校准空托盘。** 验证管理密码，在运维“设备调试 → 查看相机画面”选择启用、在线且无包裹及未结请求执行责任的一侧。确认画面为空，点“确认空托盘并校准”，保持至少 3 帧、连续 800 ms；另一侧可继续供包。重启、重连或尺寸变化后重新校准。
4. **核对首件。** 分别验证设备身份、实际采图、识码、RCS 心跳与本件格口。运行空盘默认至少 3 帧、连续 300 ms。结果未确认时保留包裹与原记录，核对原请求，不重扫。记录所用构建、真实设备及客户回包。
5. **维护或卸载。** 需要恢复时使用经核验的完整备份。非当前格式保留原件，禁止换空目录绕过原责任。卸载默认保留本站数据，明确选择“同时删除本站数据”才执行不可撤销的本站清理。

忘记密码时由 Windows 管理员核验后重置本站管理密码；结果未确认先核对上次重置。[实施与维护手册](implementation-guide.md) · [供包员作业卡](quick-guide.md)
