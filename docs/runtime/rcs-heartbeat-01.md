# RCS 心跳、到位与启停

本位 bcrCode 同时用于取格口和心跳，按左右独立控制调度；车号是当前相机下已到位车辆。心跳包含该位继续派车，移除后停止派车并调走在位车。未获本位请求且未停用的小车一直等待。RCS先绑定当时位置上的小车再放车，心跳成功响应前已应用成员集合。两位已停用发送 `data: []` 持续探活，不把停用当离线。

启用位保留成员。停用立即拒绝输入；本轮已尝试调用、执行和回执未收口时暂保留成员，收口后移除并释放相机。未尝试请求不得外呼；不等空盘或Unknown转成功。启停不能取消远端已收请求。旧心跳超时后改变集合可能发生迟到生效，须保留原成员责任并按位限制不安全恢复，不假定新确认已撤销旧请求。

自动、手动及成员变化共用单在途，变化合并刷新，取得许可后读取最新成员与版本；不堆积旧报文。默认周期1000ms，范围100～3600000ms；HTTP连接、发送和完整正文共用独立3000ms预算，不新增现场配置。真实响应时间更新有效期，本地健康读取不续期。

报文沿原端点，source=BAR、locale=zh_CN、version=1、数值requestId和UTC Unix毫秒timestamp。requestId仅匹配本次报文，不是到位编号。响应核对完整结构、编号、各项index/command/success及stationCode/bcrCode；合法空result与无效回包分别处理。HTTP响应、协议确认、成员已同步和有效车号分别留证；旧配置、成员和启停版本响应不开放本位。

可信agvNo相邻变化推进本位到位代次；同车重复仅更新有效确认。缺失、失败、过期或身份不符时撤下可投包提示，不把无码、空盘或失联当换车。IDLE/TASKING文字提示不代替身份；同车尚未提交可恢复首次提交，已提交继续抑制。具体一次提交、相机边界及远端责任恢复见[到位设计](../design/sm-vehicle-arrival-rounds.md)。

原请求保持冻结目标、编号及报文，不重发；历史Unknown不重新占当前目标位。真实SDK、客户RCS和现场验收分别计证，模拟HTTP不能替代。

完整备份前在现有周期账持久登记冻结成员租约，备份期间按该租约继续实际心跳，不修改正在复制的业务快照、不应用换车。收口时保留失败及尚在途心跳；恢复集中的未收口租约视为可能仍有远端成员效果。备份不是撤销远端请求的证据。
