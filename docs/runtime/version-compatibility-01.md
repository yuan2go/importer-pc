# 当前格式与版本规则

SM 业务版本固定为 1.0.0；测试包以来源提交和独立输出目录区分。同版允许覆盖安装，安装授权、介质完整性、路径权限、安装事务和应用所有权释放仍须核验，不能把历史作业未结当成安装准入条件。

当前仅支持配置 schema3 和 DB13；不提供 DB12 到 DB13 的迁移或离线接续。开发更新按卸载清理后重新安装处理，非当前格式在写入前拒绝，原 DB/WAL、配置、原请求、回执和永久编号在未明确选择删除前保持原件，不手改格式号或哈希。

SM 使用内置 MVS 软件识别或 MVIDCodeReader 原生识码及内置 RCS。新站默认原生识码，已保存选择不变。没有外置资格、整份配置指纹或有效期业务门禁。安装授权、实际配置和设备身份仍在所属边界核验。外部 RCS 协议 version1、SDK 原生签名和当前响应字段合同独立于自有业务版本。

正式 Application 发布仍使用 application-release.json schema2，核验实际 BusinessAssembly、BusinessVersion、CompatibilitySha256、文件字节与依赖。源码开发允许无发布 manifest；正式发布必须携带真实程序集。签名、可信来源、运行验证和现场验收各自独立，不能由同版号或其他提交的 PASS 推断。

共享基座的完整备份、隔离恢复、原始回执核验、机器身份和源退役围栏继续保留。已冻结原请求保留原编号、合同、目标及字节，Unknown 不自动重发或伪造查询；非当前输入拒绝不意味着可删除这些事实。暂停开发的其他 Application 保留各自现行格式和实现，本任务不增加兼容或迁移能力。

验证取舍见 [当前代码与验证边界](current-contract-cleanup-01.md)，安装见 [实施与维护手册](../operator/implementation-guide.md)。历史基线对照和工作包只对其原来源提交负责，不用于约束当前表、索引或内部类型必须保持历史形状。
