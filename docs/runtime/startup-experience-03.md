# 安装与首次配置：精简操作及 TCP 相机

首次设置管理密码时可能需要一次Windows维护授权；批准只允许首次设置，随后仍验证管理密码才能进入配置。取消Windows授权会返回设密入口，旧配置和数据保留。已有密码验证不重复要求首次安装批准；如仍看到旧版重复批准错误，请关闭旧窗口后使用同一完整新包更新，不能混用新旧客户端和helper。详见[本轮修复及验证边界](installer-first-run-ui-02-bootstrap-layout.md)。

UI02结果待确认增量：无法取得可信安装终态时显示“安装结果待确认”，请先打开安装记录目录核对，确认前勿重复安装。旧授权提示只在历史详情中供核对，不代表当前仍在等待授权；记录目录不存在会明确提示。关闭不发出取消指令，并保留可能仍在使用的准备介质和加密请求；未知结果退出码3不代表已确认失败或成功。没有自动重试、回滚或结果刷新；在确认后台结束后再受控清理保留文件。此前五位密码和隐藏使用范围的纠偏继续有效，真实安装/超时关闭仍须实际验证。

2026-10-21，SM 1.8.2，继续PR85；最新main仍为3b883fe，依赖PR83/82，PR84不改动。取代[上一轮说明](startup-experience-02.md)中高级安装分组、配置工具菜单及首步顶部导入的当前操作。原证据身份不变。[本轮裁决](../design/startup-experience-03.md)。

安装前自动检查Windows/CPU兼容性和介质完整性，兼容时不展示只读报告。按UI02后续用户纠偏，安装页和确认页隐藏“使用范围”，仅保留安装/数据目录和独立快捷方式；删除账号文本、用途/内部标识、原配置/修复、离线信任/扩展选择和退役清理。新装沿用所有Windows用户共用同一供包台的默认范围，数据目录在已配置机器存储根下；升级保留原部署范围及数据目录，共用机器级租约。共用范围的授权主体是Windows Users，排除服务账户、deny-only成员和日常提权运行；不是Everyone。安装/维护仍须Windows授权，普通用户不能修改程序、机器政策、签名信任或部署登记。

已有部署升级保留原账户范围、数据根、站和用途，不自动扩大权限或移动用户目录。旧单账户/模拟部署转为共享生产须通过完整备份恢复与受控部署处理，不能用升级指向新空库绕过原责任。本轮没有宣称两账户真实Windows安装已验证。

新装建立Production待配置草稿，左右TCP客户端驱动和已有RCS实现随核心发布（TCP 1.0.0 / RCS 1.3.1）；旧1.3.0签名包及请求保留原身份，新声明要求1.3.1，不重新标记旧包；旧解包config仍保留显式Simulation参考夹具身份。安装不连设备，不生成生产资格或真实认证。TCP与RCS参数初始为空，不注入现场IP、端口、协议编码或编号范围。未知配置在首配填写；严格保存校验、生产资格、认证、原责任守卫继续拒绝缺失能力，不能自动回退模拟成功。

TCP合同由用户本轮确认：供包台主动连接相机，LF换行结束每条条码，也接受CRLF；严格UTF-8，单行最多4096字节；支持拆包、多行粘包。断线、非法编码、空/控制字符、超长行、未完成行EOF、应用拒绝均使连接失败，不截断为有效码、不自动重连重放。默认仅观察；启用每行一个包裹须由现场确认并取得生产资格，同码不同的两行保留不同实体，不按条码合并。连接Epoch由Application注册，停止排空读/存活任务，物理IP/端口沿机器级资源租约独占。TCP不提供图像或SDK能力。

首配保留五步及同一完整候选。底部是上一步、下一步或保存并启动、导入配置文件、保存草稿并退出；可用草稿在来源/基线一致时继续，来源已变化不自动覆盖。删除配置工具、分层预览、单独保存/启动、备份接管/程序修复等首配入口；这些恢复机制仍属于独立维护任务。首配不再列出维护认证、未绑定可选组件、安装版本/实例/技术身份。维护认证继续是修改设置和恢复业务所需的授权机制，不能通过隐藏页面撤销守卫。

相机显示IP和端口，组件目录显示RCS服务名称。参数导入先预览，仅映射已知可编辑字段；保留站/用途/设备身份及左右拓扑，TCP连接值可导入，不导入数据库或历史请求。完成页只显示成功及下一步说明，“完成后打开供包台”位于底部完成按钮旁。

旧模拟配置继续显示“本地模拟（旧配置）”，可明确选择随包提供的TCP/IP相机与RCS服务连接，再填写现场参数；不再误报“RCS组件未安装”。此选择只修改连接候选，仍保留原站、用途和历史数据，不自动将Simulation转换为Production。

作业左右相机在线状态下方增加共享RCS状态：模拟、未配置、等待连接确认、在线、离线、未知。在线来自有效运行快照中已有RCS心跳HTTP送达证据，本地就绪不能代替在线；过期/读取失败显示未知。在线不代表业务接受，原请求结果仍以匹配回执为准；未增加业务POST探测或第二个心跳发送器。更多菜单删除辅助窗口，标准/紧凑布局保留。
