## 实际环境与已知限制

最终导出为本地无头Chromium、中文locale、1600×900逻辑视口/2倍PNG；补1366×768、1280×720、800×420及799×419保护。渲染脚本拦截HTTP(S)，原型CSP禁止连接。所有条码、RCS回应、连接恢复、维护资格、配置保存、重启、备份和导出都是显式模拟。

前一阶段长条码定向检查中，1280×720正常与长值场景的左右格口文字起始位置均为418逻辑像素；这个数值只属于该版本布局测量，没有外推为性能或现场可读距离。最小图800×420保留当前结果与必要动作；799×419显示暂停与空间保护。紧凑原型控件不能自动视为Windows原生44 DIP命中区验收。

原生浏览器日期控件在中文locale下仍可能显示月/日/年或AM/PM；相关图无观察到截断。正式WPF使用一致中文日期/24小时格式，并验证键盘输入、原生弹出器和时区呈现。
