# 供包台字体与排版 · TYPOGRAPHY-01

适用于 SM 及其共享 WPF 基座、参数、查询、管理、安装与首次配置。字体只用随软件交付的 Noto Sans CJK SC Regular / Medium；历史原型、截图和验证保留原身份，不作为当前字体规则。

## 字体及交付

采用 Noto Sans SC 对应的官方简体中文桌面静态 OTF：Noto Sans CJK SC 2.004，Regular 400 / Medium 500。只使用这两个实际字重，不用大面积粗体或合成半粗体。字体来自 [Noto 官方仓库](https://github.com/notofonts/noto-cjk/tree/Sans2.004/Sans/OTF/SimplifiedChinese)，固定 Sans2.004 提交；保留原字节与 SIL OFL 1.1，来源/版本/覆盖/哈希随字体清单记录。不是设计 WOFF 子集，不依赖在线下载或全局安装。桌面、安装和首配使用同一资源。

界面正文、条码、任务标识及技术原文统一使用同一随包字体，不主动指定系统字体或等宽字体。条码和任务标识保留原字符、可选择复制；不通过字体转换改写业务值。使用 WPF pack 资源和实际家族名。外部原文出现字库未覆盖字符时，WPF 仍可能按系统机制替补缺字，这不代表软件已交付该字形；常用现场文字和标识须核验实际字形来源。

本轮用户授权官方 OFL 字体进入仓库及离线交付，只限定替代“生产只用系统字体/不交付字体”。客户原稿、私链、生产数据、凭据、未获许可字体/SDK仍禁止上传；OFL不授予项目或其他资产许可。

## 语义尺度（DIP）

| 信息角色 | 尺寸 | 字重与布局 |
|---|---:|---|
| 正文、输入、导航、普通按钮、记录正文 | 16 | Regular；单行输入至少40，关键动作至少44 |
| 标签、说明、表头 | 14 | Regular；分组/选中项可用Medium |
| 低频技术元数据 | 12–14 | 按需展开；不承担当前结果 |
| 分组标题 / 作业位名称 / 页面标题 | 16 / 18 / ≤20 | Medium；查询标题保持16 |
| 正常状态 / 等待占位 / 异常主句 | 16 / 18 / 20 | 正常与占位Regular，异常Medium |
| 当前真实条码，标准 / 紧凑 | 28 / 24 | Regular；长内容换行、滚动、可选择复制 |
| 当前有效短格口，标准 / 紧凑 | 72 / 56 | Medium；7～16 字符用44 / 36，更长用28 / 24；放在只缩小的缩放框内，空间不足时按比例缩小、不裁切，可完整查看复制 |
| 作业页波次、任务号、商品编码、返回数量 | 标签16 / 值22 | 两行单独保留至少104 DIP，绿色格口区域让出高度；低高度窗口两行至少72 DIP、每项限34 DIP并可滚动。标识使用随包字体，可选择复制；长值换行、局部滚动 |
| 日志原文 | 14起 | Regular，详情可放大 |

有效格口或需要处理的异常最高，其次为当前条码。固定标题、正常设备和辅助信息降低强调。Unknown、Rejected、Conflict、失效和未准入的现行区别不变，只有当前有效结果使用大号格口。隐藏的空任务字段不恢复。低高度以局部滚动和重排保留完整结果行、查询范围、操作回执及原请求责任；不通过缩小全局字号或清空草稿解决空间不足。

## 实现与验证边界

共享语义资源同时供 XAML 和动态 C# 控件引用，覆盖模板与 SizeChanged；保持虚拟化、焦点、选区和滚动。不提供字体配置平台，不变更协议、设备或业务架构。必要原生证据记录源码、客户区DIP、系统DPI、实际字体URI/字重和截图；模拟窗口、实际系统缩放、真实设备与现场分别记录。验证与运行命令见[工作包](../archive/work-packages/WP-IPC-TYPOGRAPHY-01.md)。

实际共享实现为 `src/Ipc.Presentation.Wpf/{UiTypography,TypographyScale}.cs`，两套宿主及安装/首配均引用此程序集。已核验每个字重65,535字形、44,810条Unicode映射、静态字库、fsType=0；完整覆盖清单不代表任意外部日志都只含这些字符，缺字由 WPF 系统机制处理；不主动配置其他字体。版本以官方name表2.004为准，WPF的GlyphTypeface.Version在这组OTF上返回0，不作为版本来源。实际字体URI、资源哈希与原生对照见[实现证据](../runtime/typography-01.md)。
