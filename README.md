# importer-pc

Windows 供包工作站资料基线。当前不含生产业务代码，也没有已核验的构建命令。

**WP-IPC-DESIGN-BASELINE-01：公开部分基线，不是完整资料入库。** 仓库核验为 public；客户原始资料、依赖这些资料的完整设计及带标识的图片没有明确公开许可，未提交到 Git 历史。它们已整理为单独的非公开交付包，但不在 main 中。

从 [docs/INDEX.md](docs/INDEX.md) 开始阅读；[资料清单](docs/manifest.json) 记录实际入库文件和SHA-256；[公开范围](docs/baseline/PUBLICATION.md) 与[缺失清单](docs/baseline/MISSING.md) 明确剩余限制。

当前入库的既有成果是完整17项技术问题表和通用 design tokens。它们不是原始PRD或详细设计正文的替代品。归档不代表问题已修复、设计已批准或现场可上线。
