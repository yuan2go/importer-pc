# 管理模式 · 当前操作与实现

历史实施、版本和验收原件见归档；原PASS只属于原SourceCommit。当前支持新安装及同版覆盖安装，保留原账户、配置与业务数据；运行仅接受当前格式，非当前输入在写入前拒绝并保留原件，正常运行不提供旧格式运行路径；已核验的显式离线接续按当前格式规则执行。

普通导航保留“作业、记录”和底部“管理中心”。每次打开独立管理窗口都验证一次管理密码；同窗切页不重复验证。管理中心包含设备与诊断、设置、调试、日志，共用原 Application 实例。打开成功后暂停自动供包及识码，保留相机连接与预览；调试明确读取、明确发送，不建立旧全站调试隔离。关闭窗口结束授权并恢复原启用和暂停状态。

15分钟授权到期时锁定管理页面，保留未保存草稿及可关闭窗口，不自动恢复供包。授权服务短暂通信未确认时禁止管理命令，恢复读取后继续尚未到期的原授权；按钮状态不能代替执行时复权。最新授权应用完成后入口才返回，取消密码窗口不进入。

首次设密、修复和忘记密码均使用安装登记的同版受保护维护程序。忘记密码由 Windows 管理员核验后做本站一次性重置，不设各站通用固定口令。重置撤销旧授权，未确认结果先核对原操作；服务或受保护凭据损坏不能通过删文件变成首次设置。

到期维护采用请求绑定的一次性入场与持续授权：入场票据仍最多两分钟且不可重放；已核销操作在每次权限检查时重新核对原会话、凭据及请求，最长只到原会话到期和操作预算。它不会把15分钟管理会话自动延长为两小时，也不会借新会话沿用旧委托。退出、到期、改密码或重新登录均撤销旧持续授权；维护按原持久回执保留已提交事实并安全中断。

管理模式中可修改管理密码，确认新密码后撤销所有原授权；重新进入后继续。按 UI02 后续用户纠偏，密码最低5个字符、最多256个字符，允许纯数字和重复字符，继续拒绝控制字符。安全存储强哈希和随机盐；连续5次失败锁定5分钟。受保护服务中保存密码和授权，不在共享可写业务目录中开放权限账，不接受Windows运行资格替代管理密码。新格式损坏、已配置密码缺失或服务不可用均拒绝受限操作。

参数继续四类、同一完整候选和统一保存。读取、编辑、导入、恢复、草稿、快捷跳转及保存均在服务层要求管理模式；写入继续核对版本并发和真实执行/回执/资源责任；SM按实际差异热生效或保留Pending，不把全部保存解释为必须暂停和重启。退出/到期保护未保存输入，重新进入才能查看和继续。管理授权使用独立会话证据，业务记录中的原操作员身份保持。

日志继续读取真实软件轮转文件，支持关键词/显式正则、时间/级别/来源、有界分页、原始相邻上下文和完整栈、全部匹配或时间范围导出。查询、上下文、导出绑定模式授权；退出、到期和改密码取消受限任务并清理部分导出，不占用供包关键锁，不放宽日志来源或凭据遮盖。

复用现有受保护System宿主和D盘根，既有SCM/目录标识继续承担当前安装归属；不是另一套账号体系。本版隐藏帮助入口，离线内容及页面实现保留，业务审计、独立诊断与备份恢复按原职责保留。真实SDK/RCS、设备、目标IPC和现场验收分别记录。

管理凭据schema2、管道v2；UI、辅助进程和受保护宿主必须整套同源发布。业务及公共契约版本以项目文件和发布清单为准，不混用DLL或凭据协议。首次安装设置管理密码，没有旧账号转换入口。

管理密码修改只从当前管理窗口的统一管理菜单进入，不在同状态重复提供按钮。设备设置按目标设备进入原完整草稿；定向重连保留执行时守卫，名称不把全站操作写成单设备。仅隐藏管理窗口且草稿仍在时不新增放弃确认；真正关闭仍保护输入、结束本窗调试、退出授权并释放窗口责任，失败保留原窗供重试，到期也能关闭。

连续试扫开始时冻结本窗所选相机身份，由Application只向该来源注册采集；另一相机保持管理暂停下的预览，不识码、不保存到本批次。采样中的选择变化不改变原批次归属；无效或未配置的来源在建立会话前拒绝，不扩大成全部相机。停止只取消本窗当前批次的等待，随后结束原Application会话；采样中仍可停止。自然完成、超时、失败及关闭走同一收尾，未确认保留原会话和结束命令核对/重试；不创建新会话掩盖未结束责任，不声称已发RCS请求被撤销。

关闭先取消本窗读取并等待调用真实终结。已经结束的本窗读取取消不视为资源释放失败；原调用方继续处理其结果。真实服务异常、未结束的调用、释放失败和等待超时仍保留窗口及原所有权，后续工作区释放另行核验，不能据本地取消推断原请求未发送。
