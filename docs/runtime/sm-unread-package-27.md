## 无码和旧格口

驱动按原设备/epoch/帧号发布有码、无码或拒收帧的临时事实。Application核对已登记源、epoch、帧顺序和单调时钟，并保存每位一个最新水位；同类无码事实不向界面无限排队。空画面不代表检测到包裹，连续空帧不创建输入账、作业、图片或RCS请求。

无码或拒收帧使本位之前的条码、当前格口、波次/任务/SKU/数量和图片入口退出当前呈现，提示调整标签或扫码枪/键盘补录。原接受事实仍在历史；旧响应只更新原作业，不恢复当前格口。快照、主动推送和新窗口共享同一水位，另一投递位不受影响。健康重连也不能凭旧周期作业恢复格口，须取得新周期有效读码。

键盘/PDA是独立来源，相机空画面不清退其当前结果；下一次有效相机读码仍可建立独立新观察。Unknown、拒绝及原请求核对责任不被无码清偿；无码提示不能伪装成RCS成功。每次独立有效识别仍分别请求，`loadCode`保持原码、`quantity=1`，业务去重和计件合同继续由RCS/现场核实。
