# MVS 采图与软件识别

SM 每台相机可选择 MVS 采图加进程内 ZXing-C++ 识别或[海康原生识码](../design/mvid-native-reader.md)。新站默认海康原生识码，已有配置不自动修改，不回退或同时占用同一相机。软件路线保留码制和反色设置；人工键盘/PDA 独立准入，不依赖相机。

采集与软件解码分线程，单个最新待解码槽可以替换未识别视频；已识别的输入逐笔保全。放稳默认200ms，持续不稳约1.5秒仍识别一次。原图在处理前保留，按观察/作业身份后台保存。完整候选交 Application 筛选，同次放置重复观察不创建新请求；两处真实同码执行多码拒绝。画面未变的漏读保留原结果；连续3帧且不少于800ms的空托盘或不同新码才进入下一次放置。重连同码保持原放置；重启不恢复上一班次结果卡片，未决原请求责任保留。

断线自动重连。StopGrabbing/Close 报错记录后继续 DestroyHandle/Finalize，真正销毁成功才释放物理占用；销毁或 SDK 释放失败保留占用并停止自动重连。未交付输入、身份及原请求守卫继续有效。RCS 离线或管理中心打开时暂停自动识码，保持预览；明确调试读取和发送分别授权，关闭窗口恢复原状态。

MVS 原生依赖沿用受保护目录、ACL、哈希和进程生命周期加载策略，ZXing 依赖按嵌入清单核验。MVID 使用独立运行库，不等同 MvCodeReaderCtrl。配置使用真实 IP、序列号和唯一编码，连接参数在守卫满足时只重连改动相机。

当前性能、统计及验证入口见[双相机性能](../design/sm-dual-camera-performance.md)。`--mvs-network-reconnect` 使用合成 SDK、真实驱动/ZXing/SQLite/回环 RCS，不能代替真实拔插和目标机验收。

## 历史验证（2026-10-28，非当前行为合同）

本机实际相机3072×2048 Mono8，原生MVS＋.NET软件识别＋Application/SQLite＋Python环回RCS：20秒51笔独立请求全部SlotResolved、0 Unknown，服务账本51个不同请求ID、1个模拟分配；另用受保护的随包原生目录及默认驱动工厂10秒21笔全部SlotResolved。真实图像、条码、IP、序列号、账本仅在D盘Git外。以上运行使用独立Simulation夹具及既有测试身份前置接口，不改正式权限守卫。

当时合成实际ZXing引擎验证同码三帧三份作业/HTTP请求（该行为已退出当前合同）、空白不建作业、原请求不改写、借帧归还和有序停止；既有驱动资源、原生参数和RCS恢复检查分别记录。本机Explorer继承提升权限的问题已补同用户普通令牌启动入口，并通过实际Windows子进程及原身份检查；原安装客户端同令牌启动成功，新冻结介质仍单独核验。正式模式要求受保护安装完整性、SDK字节/ABI/物理身份、明确配置和普通运行账号；内置SM不要求外置扩展目录、信任或按配置签署的扩展资格。安装器生成、介质依赖检查、Windows启动冒烟与实际现场RCS验收分别记录，不能用上述联调结果替代。
