适用于生命周期优化候选 Sportmaster1.13.0、DirectPlc/WcsToPlc1.7.0、Contracts1.19.0、DB9。开工 main `3a5b1d13`；实际冻结源码/版本/库存以本包ASSEMBLY.json、BUILD-INFO.json和SHA256SUMS为准；形成过程和验证边界见[验证报告](validation/lifecycle-ux-optimization-01.md)。[实现记录](lifecycle-ux-implementation-01.md)和[问题总账](../reviews/lifecycle-ux-reconciliation-01.md)保留每项来源。版本号不替代 SourceCommit/哈希，也不表示现场已升级。

本机先前 SM1.12.3 EXE 固定源 `3a5b1d13`，238735051 bytes，原 SHA256 `3ed576d6fa078da0234d06a44a9f07a7a46cbe43c34bd57662c90a64dfb92608`；安装未运行。这是历史介质，不能验证本批实现。[公开 SM1.10.2 发行](https://github.com/yuan2go/importer-pc/releases/tag/installer-sm-v1.10.2-c9e482a30d2d)仍保留原身份。现场版本本批未核验。

仅使用可信同源完整介质，核对回执、SourceCommit、库存及哈希。普通安装自包含.NET；相机SDK/驱动按真实接口要求另备，不能用模拟provider补生产能力。不关闭安全功能，不以链接绕过受保护根。程序、数据、缓存均用D盘；受保护根沿管理员配置的HKLM政策。生产材料交接/导出遵守授权，不发送凭据、完整库或未获许可附件。

## 安装与原操作恢复

1. 双击可信同源EXE，自动准备、校验；准备阶段可取消。选项页核对程序/数据目录、开始菜单及桌面入口，再审阅并明确安装。普通向导不提供运行账户、Simulation或信任包选择器。
2. 安装提交时沿既有Windows授权，固定本次请求和原操作记录。提交后关窗不代表取消或完成；连接/回执中断显示“结果待确认”，不提供重复安装。
3. 选择“只读核对本次安装”，核对原请求指纹、受保护登记和原日志。仍持锁/事实不足继续待确认。原登记已经提交但系统入口未完成，仅“修复原系统入口”；只有明确未提交/失败才重新审阅新动作。核对不启动设备。
4. 从正常非提权入口启动。维护和业务身份分开；首次管理设密沿既有批准通道，不提供默认密码。

高级逐站计划继续使用 `--deployment-plan <原计划> --receipt <新回执> --preflight`；每次核验保留同一 OperationId 和 PlanSha256，回执必须换新文件。重新预检会重读介质、配置/信任/组件哈希及原登记 CAS，完整比较请求；输入或原登记改变则拒绝，不能手改 ID/散列绕过。新建显式审阅才生成新 ID。合法固定 GUID 可以数字开头，不重抽 ID。

原安装记录一旦存在，本计划不得重新提交（`OriginalOperationNeedsInspection`，退出10）；Prepared、Unknown、失败、残缺记录均保留。授权维护者保留原计划，用其中 Deployment 调用既有 `ParcelStartupServices.InspectInstallation` 只读核对原终态；权限不足继续沿原授权通道。只有确认 Failed/NotCommitted 后才可显式重新审阅新动作，禁止以新 ID 掩盖 Unknown。

Schema1 旧计划没有 OperationId 时，原序列化/PlanSha256 保持不变，允许只读预检；若唯一受保护登记已完整匹配原计划，继续只读返回 AlreadyInstalled。未提交旧计划执行返回 `LegacyPlanNeedsReview`（退出2），须显式重新审阅，不自动补 ID。PreflightPassed/AlreadyInstalled 均不代表本次执行了安装或获得现场资格。提交后丢回执先核对原登记和原记录；不能覆盖 Reviewing 或其他旧回执。

卸载从Windows产品安装项进入维护。读取原部署/责任，选择完整备份目录，检查计划后确认；目录变化立即废弃旧计划与固定文件名，必须重新读取。执行前再次核对唯一登记、授权、账和备份目标；不删除业务数据、永久身份、扩展、共享驱动和清单外文件。

结果分别显示正常保留、异常残件、需重启、已退役但清理未完及原回执/完整剩余清单。“已退役”不是所有文件清理完成。退役结果页不依赖已移除服务再次认证。Unknown仅核对原操作；仍在执行时不能续办。使用**同SourceCommit完整介质**进入原维护，续办原固定清单；不接受新路径/新清单，不手动递归删除原目录。真实UAC/系统登记往返/重启须独立授权验收。

## 首配、身份和日常

新站进入独立首配，不进入日常导航；显示阶段、叶页和当前类别进度。四类页面编辑同一完整候选，保留逐页校验和原字段归属。仓ID、生产线ID、单供包台编号统一用于新取格口/心跳；左右相机编码保留真实用途，新请求quantity=1。新站日志及已结历史默认7天，既有显式值和旧请求不覆盖。相机/RCS可明确延后配置；相关业务继续拒绝。当前Windows用户的本机窗口模式不改变业务配置。

普通导航为作业、作业记录；左右相机固定，无每包确认。新输入未准入/失效/未知不能沿用旧格口。软件暂停不是安全急停。右上独立显示管理模式和“操作员/免登录”；业务登录要求沿真实组合。进入管理模式不自动暂停；15分钟到期、退出、改密码撤权，服务不可用也不能授权。

到期立即隐藏受限页、请求取消受限任务并显示解释，原页/原输入保留。重新输入现有管理密码后回到原页；任务完成事实仍以实际回执为准。服务层重复鉴权，不能靠隐藏控件获得参数/日志权限。忘记密码时阅读现有政策说明并交付授权决策（G02）；没有删账重新首设、默认密码或Windows权限替代。

## 保存、稍后应用和停止

沿V3校验、差异审阅、原因、暂停/排空和原Revision/CAS保存。Esc返回编辑；回车只定位所选差异，不默认保存。保存读回仅表示Pending；当前连接仍用原Effective，受控重连不应用新配置。

审阅结果可稍后应用，或“检查并停止、重新打开”。后者先检查管理授权、草稿、运行/未知责任，显示真实停止影响；保存草稿/返回由现有保护处理。仅完全停止并释放原owner后打开唯一启动入口，沿原激活/回退和确认机制读回；新实例保持暂停，由操作者核对配置后明确恢复。停止失败保留原owner，不启动第二实例。未知原请求仍固定原目标、报文和合同；流程不清偿责任、不自动重发。

默认/经典主窗退出均保护原编辑草稿；辅助窗口只关闭视图。实际未决/不可见责任和Pending在退出影响中分别说明，不把可见行数当作总责任数。

## 作业记录与原请求交接

编辑筛选后立即显示“条件已变化、尚未应用”，旧结果仍标明自己的已应用条件、带时区起止和固定上界。业务位按真实名称选择，查询/导出固定稳定ID；历史停用位仍可选择，精确ID输入保留。查询可取消；失败/取消保留旧范围，不把旧结果标成新条件。

首页、上一页、下一页使用同一次查询的固定上界、条件和游标；翻页不改原详情/目标。要纳入新记录明确重新查询。条件未应用时禁止导出旧结果冒充新条件；导出按显示的固定已应用范围，而非当前草稿。

详情“原请求交接”只读展示原实体/准入/作业/请求、已知和未知事实、发送尝试与原合同/实现身份。普通视图不提供敏感配置/目标散列；管理模式才可复制额外受限投影，秘密仍脱敏。复制不调用外部服务、不清偿责任。冻结RCS v1没有权威Query（G01），界面明确原因，不造查询/重发/人工成功。其余产品按自己的真实合同分别核对。

## 软件日志

管理模式进入日志，使用原生日期/时间控件或今天/24小时/7天快捷范围；显示明确时区。选级别、来源、普通关键词或显式正则后查询。已应用范围与草稿分开；条件变更使旧选择失效，须重新查询。

分页、上下文和导出固定原日志来源/选择；上下文为原文件相邻真实记录，不能从聚合结果补造。来源变化、限额、正则超时、撤权和取消给出真实结果。退出/撤权/更换选择释放原文件句柄；失败查询也释放尚未交付选择。

分别确认“全部匹配”和“整个时间范围”：后者包含该范围内不匹配关键词的记录。只写新文件，先临时写入再原子提交；取消、失权、失败或已有目标不算导出成功。回执显示真实路径，可定位导出文件。敏感内容脱敏，技术原文可查但不伪造来源。

## 备份与已结历史到期维护

参数页正式显示备份策略、下次计划/等待原因/最近结果及最近**成功**恢复集路径和时间。后续失败、到限或计划关闭不覆盖既有成功事实；达到份数上限停止新增、不自动删除旧恢复集。成功意味着数据库与同名 `.recovery` 完整恢复目录一起保留；验证范围不扩张到异机可恢复性。

保存保留天数不执行在线清理。选择“停止并打开到期维护”，先通过与配置应用相同的owner、草稿、授权和停止守卫；或完全退出后从独立启动修复的配置工具进入“已结历史到期维护”。独立页可重新验证现有管理模式，过期不产生授权后门。

选择新的完整备份文件→可取消的只读预检→审阅固定原账/目标/保留天数→明确完整备份并清理。唯一owner和有效授权再次核对；账或目标变更需重新预检。沿既有内核先完整备份，再删除到期已结明细，保留未决和永久责任；不改删除算法、预算、索引、不自动VACUUM、不自动恢复作业。

提交后Unknown仅核对原维护回执；原结果、完整备份指纹、原retention run和完整性事实可一致核对才报告完成。备份后中断保留完整恢复集并报告Interrupted；核对不重复清理。恢复继续使用既有完整恢复集预检和原机/换机政策。

到期维护的两分钟委托是一次性入场票据；核销后，同一固定请求在每个授权检查点由服务按原活跃管理会话重新授权。持续授权不超过操作预算及原15分钟会话，退出、改密码、另开会话或到期立即使后续检查失败，不自动延长管理模式。两小时进程预算不是两小时管理权限。失效后保留备份和已提交事实，核对原回执后再显式审阅，不绕过会话续办未知操作。

丢回执核对复用完整恢复集验证：数据库、COMPLETED清单的全部Files内容及完整文件集合都必须一致，包括配置、原回执、图片和维护证据；缺失、损坏、别名/额外文件不报告“完整备份已核验”。核对只读并重新检查授权，不创建恢复目标或再次删除。

当前产品导航、页面、契约和有效随包清单无“帮助与支持”模块或旧支持摘要；独立诊断、真实日志、完整备份和原维护入口保留。历史原件见仓库归档；它们不替代本指南。目标IPC、真实设备/SDK/RCS、UAC/重启和现场验收独立计证。
