# 清理后首次安装目录引导 · INSTALL-BOOTSTRAP-01

2026-10-22用户在清理旧供包台后双击SM1.11.0安装器，启动即显示“安装包不可用”，内容为D盘受保护存储根。清理保留了D盘位置登记而删除部署目录；旧读取路径直接核对不存在目录的ACL，尚未显示安装向导就失败。前轮文件哈希和卸载检查不能作为该状态下安装器启动通过的证据。

本增量保留管理模式、原Application及安装责任守卫，只修复干净目录引导：未安装时读取已登记位置和审阅选项保持只读，校验全部已有祖先和卷根；只有安装维护获得Windows授权后才创建受保护存储根及程序父目录，并在创建前后核对链接、所有权和ACL。已有不安全目录、同名文件、链接、登记损坏和不安全卷根仍拒绝，不回退C盘、不恢复旧账或创建默认密码。

默认D盘程序路径允许其受控父目录尚未创建；任意自选程序目录继续遵守原受保护父目录要求。卸载/清理后的真实旧状态及旧安装包证据保留来源，新安装包采用独立补丁版本、冻结提交和哈希。本机正式安装与首配仍留给用户；必要验证覆盖只读启动、选项审阅、授权后目录创建、已有目录和链接拒绝、安装器完整性及受影响构建。

实现位于`WindowsStoragePaths`、`MachineRuntimeSetup`和`TrustedProgramRoots`。SM补丁版本为1.11.1，Application契约、数据库和配置格式不变。当前工作树实际Windows检查：未创建部署根的只读检查5项通过；授权隔离目录创建/不改已有ACL/同名文件/不安全ACL/链接拒绝8项通过，隔离目录已清理，真实部署根仍不存在。受影响核心、Desktop及原生验证工程构建通过，0警告/0错误；原运行身份守卫测试通过。原生向导和最终单EXE验证在同源包形成后单独记录。

首轮新增验证工具遗漏InvalidDataException的预期拒绝类型，隔离测试在同名文件拒绝处结束，原记录保留；修正测试捕获后完整8项通过。实现没有放宽拒绝断言或以错误视为成功。
