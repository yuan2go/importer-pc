把商业软件质感落实为：
1. 重点清楚：第一眼找到当前包裹、格口和异常。
2. 组织一致：相似操作的位置、名称和反馈相同。
3. 密度合适：作业便于辨认，参数便于填写，不强求相同密度。
4. 细节完整：禁用、处理中、成功、失败、空数据、未保存明确。
5. 操作连贯：刷新不抢焦点，耗时操作不阻塞整个界面。
6. 真实显示可靠：目标工控机分辨率和Windows缩放下，无文字截断、按钮遮挡或关键内容缺失。
