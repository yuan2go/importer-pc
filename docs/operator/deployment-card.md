# 实施人员部署卡

适用：IE01 1.0.0候选，尚未正式签名发布。打印稿与本文同源，实体打印与新人30分钟旅程尚未验收。

**先备妥**：可信同源安装包及SHA256、可用D盘、Windows管理员、真实仓ID/生产线ID/供包台编号、RCS资料；使用相机时另备匹配所选识码路线的合法原生运行库（新站默认海康原生识码，只有MVS不够）、实际 IP 和唯一 RCS 相机编码；序列号在保存前按 IP 自动读取。准备、机器等待和主动操作时间分开记录。

1. **安装或更新。** 使用当前可信完整安装包，确认版本与D盘位置后安装。已有站保留原数据和身份，不换空目录绕过未决请求。显示结果待确认时先核对同一次安装。
2. **完成首配。** 新站相机默认海康原生识码，完整安装包必须包含匹配原生组件；已有配置的识码方式不自动改变。每台相机可在高级设置独立选择MVS采图与软件识别，不填TCP端口，不选外置扩展。填写相机 IP 后自动读取并保存序列号，不使用的相机清空 IP；RCS空地址表示待配置，有地址就完整填写。示例值不能当现场配置。保存后自动检查并启动，条件不满足时显示具体原因。
3. **核对真实能力。** 找到相机、成功采图、识别条码、RCS传输及取得格口是不同事实。缺能力时相应来源拒绝业务；软件能打开不表示可以供包。保存后区分正在使用和待生效的配置。
4. **核对首件。** 按作业卡处理一个合法包裹；模拟/回环与真实设备分别记录。Unknown不重发，先保留包裹、原记录和原目标。
5. **交付或卸载。** 先完全关闭供包台，从Windows应用列表进入卸载，选择“保留本站数据”或“同时删除本站数据”（默认保留），点“卸载”并完成Windows管理员授权。不创建备份，不检查业务请求是否完成；关闭软件不改写请求结果。删除本站数据不可撤销；共享驱动、受保护安装回执和本站以外的备份保留。结果未确认时先查看原结果，不重复提交；文件占用解除后可沿原清单重试。

**忘记管理密码**：从“忘记管理密码？”输入新密码，由Windows管理员确认本站重置。失败先“核对上次重置”；不使用共享恢复口令。没有真实签名、设备或接口验收证据时保留候选身份，不宣布投产。
