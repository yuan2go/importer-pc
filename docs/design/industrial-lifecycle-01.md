# 安装与维护生命周期

本文描述当前 SM 装配契约，验证边界见[当前代码与验证](../runtime/current-contract-cleanup-01.md)。现场步骤见[维护手册](../operator/implementation-guide.md)。历史实施与验证只对应各自来源提交，不作为当前通过证据。

## 权威与资产

WindowsDeploymentSetup 的受保护唯一部署登记决定当前程序、数据根和维护库存；安装、回滚、恢复、卸载及清理的原记录分别保留操作身份、冻结范围和结果。MaintenanceExecution 表达检查、可取消阶段及不可逆提交；UI 不另建状态账。系统入口只是登记的投影。

程序、数据、缓存与临时工作区使用 D 盘。普通运行账户只读程序，机器维护由 Windows 管理员执行；本站管理密码只授权应用维护，不代替机器部署证据。保留数据卸载保留本站凭据；删除数据按 schema2 原冻结清单删除本站凭据。机器安全政策、部署及审计证据不随本站凭据删除。

## 安装和取代

普通安装三步，静默和批量入口使用相同配置准备与事务内核。SM 业务版本固定 1.0.0，来源提交及库存区分构建。同格式覆盖保留账户、配置、业务数据与原请求；旧格式在写入前拒绝，明确选择清理重装才删除原数据，无格式迁移。

安装只核验供包台真正关闭、所有权释放、介质、权限和事务，不以作业完成或暂停状态准入。独占核对原记录：提交前中断可确证收口；登记已提交只修复原系统入口；证据不足保持待核实。取消 UAC 不等于安装失败。

发现、结果核对与执行准入共用取代证明。后续卸载、安装、恢复或回滚的受保护原记录及当前登记必须连成可核验关系，目录日期、业务版本和提交字符串顺序不提供部署先后证明。被取代的原操作只读保管，不伪写失败，不重新启用退役程序。

## 回滚与版本清理

离线恢复与维护提供上一部署回滚、旧版本清理和历史结果查询；卸载页面仅卸载。回滚目标是登记保留、程序和缓存完整且能读当前格式的上一部署。同为 1.0.0 的不同来源允许，只切程序，不还原 DB 或配置账。

版本清理从真实部署关系及库存形成固定计划，展示删除、保留及原因。保留当前和合法回滚候选、有效引用、实际未完成责任、执行中缓存及证据不足项。已确认恢复沿现有交接、确认文件及事务审计核验，永久标记本身不阻断；恢复改变数据根也不抹去历史部署关系。Application 仍核验真实执行、回执、配置、存储及其他业务根责任。

清理有原结果核对、续办和明确保留余项。新登记产生后仍可查看旧结果；续办复核当前引用，仅删除原冻结范围，不能扩到新程序、数据和缓存。安全库存归档是删除审计，不能作为可执行回滚介质。

## 完整备份与恢复

完整备份由数据库、同名 .recovery 目录、COMPLETED.json 及全部哈希组成，一个数据库不是完整集。在线、离线和计划备份共用白名单及验证器。交付复制保持文件名、内容和逻辑身份，最后发布完成标记；中断保留残件和原集，不报完成。删除只处理明确选择并核验的有限清单，未知内容、引用与占用如实保留。

完整集的源围栏位于本机安装策略指定的共享租约区，普通运行与提权维护使用同一位置和路径身份。列举、核验和恢复只要求源可读，不在只读介质或只读共享目录创建租约文件。恢复是否曾启用按本次交接最早的有效确认及后续启用审计核对；再次确认同一交接不重置曾启用事实。

恢复仅同机当前格式；来源材料属于恢复白名单，不打包整个机器安全根，不复活已删除的本站管理密码。复制、接管提交、责任确认、曾经启用及当前暂停分别投影现有记录。确认后仍须明确启用；后来正常暂停不能抹去曾启用事实。Unknown 和外部效果继续按原请求核对，不重发。

## 身份与交互

维护页区分实际运行宿主、当前登记部署及核验目标介质，显示业务版本与完整来源提交，可复制；缺失或冲突如实说明，不新增显示性准入限制。沿用启动页、回滚页、主题与固定底栏，技术详情按需展开，不增加在线更新或隐藏帮助入口。

## 验证边界与延期事项

必要验证使用真实计划、Application 准入和受控文件/网络边界，同时覆盖合法放行与真实风险拒绝。WPF HWND、合成子进程不是实际安装、UAC、SCM 或重启验收；这些组合须在独立可还原 Windows 环境取证。构建、本机、CI、真实 SDK、客户 RCS 及现场分别报告。

MSI/MSIX、供应商离线令牌和正式发布签名资格是独立任务；本次不增加其他 Application 抽象，也不把延期设计当现有功能。
