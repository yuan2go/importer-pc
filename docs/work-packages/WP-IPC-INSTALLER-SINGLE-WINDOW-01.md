# 单窗口安装与一次Windows授权

2026-10-20用户报告前置欢迎/准备和安装选项分成两个窗口，多次权限确认及闪动，要求合并到原安装选项窗口、安装时仅一次授权。基线main `0fe3cbfb31ef57d674c4040d7b3bd52bf469b46a`（PR67已合并）；独立clone的codex/installer-single-window分支实施，不覆盖共享主工作树或用户当前打开的旧安装器。原7c/129 EXE及验证原身份保留。

## 编码前决定

复用StartupSetupWindow作为单EXE唯一可见安装窗口，准备进度直接在同一个窗口自动执行，不再展示前置欢迎页/下一步或启动另一个安装UI进程。Ipc.Installer编译引用本次选定业务的现有Desktop项目，不重建第二套目录/选项界面；所有引用使用同一冻结源码、确定性PathMap和锁定依赖，封装前逐字节核对共享DLL与介质，避免两套安装机制或混版。

安装选项→本地校验摘要→点击安装后一次Windows授权→原责任预检/完整备份/受保护安装→完成。升级预检移入同一个固定、限次的授权安装命令，仍调用原PlanChangeAsync和ExecuteChangeAsync：Allowed、原责任、配置CAS、登记hash、完整备份、字节和身份守卫保持，阻断仍拒绝，不把批处理或维护的旧协议改为自动放行。摘要明确备份目标与安装时检查的边界。回执继续绑定实际完整请求及原受保护部署登记。

提权安装通过同版Desktop的无窗口命令分支执行（WinExe、创建窗口前分发），消除Console helper短暂出现。普通客户端仍非提权，完成后由普通安装窗口启动；不把整个安装UI/业务客户端抬成管理员，不尝试自动确认UAC。CLI及其他维护权限协议保留。

## 验证与公开边界

原型HTML/CSS/JS及完整交接、现行原生窗口/用户截图为视觉依据；Impeccable Operate和独立WPF查询仅开发辅助，不使用CDP验原生。必要覆盖真实首屏/单一安装HWND、无前置下一步、输入/返回保留、摘要前零UAC、安装一次授权和无控制台窗口、备份和防丢数据、构建记录、两个快捷方式与完成后普通权限启动。补充拒绝/取消、不匹配字节及原Unknown/计划变化守卫相关测试，不删旧断言换PASS。
