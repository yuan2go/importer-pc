# 管理模式 · 当前操作与实现

2026-10-22按用户纠偏：管理模式是防止操作员误改参数的临时权限状态，不是账号或人员角色。普通作业与原扫码流程继续，操作员账号/免登录状态独立。实现与验证逐项见[工作包](../work-packages/WP-IPC-MANAGEMENT-MODE-01.md)，完成前不将SM1.10.2旧证据当成本轮PASS。

普通模式导航为“作业、作业记录”。点击“进入管理模式”，填写站点管理密码即可进入；无用户名。管理模式显示明确状态及到期时间，开放“参数设置、日志查询”及对象相关维护。“退出管理模式”立即撤权；15分钟到期自动退出。首次使用须设置并确认管理密码，沿现有安装维护批准通道保护首次设置，无默认密码。设置/进入/退出不修改操作员账号或在途作业冻结身份，不要求暂停。

管理模式中可修改管理密码，确认新密码后撤销所有原授权；重新进入后继续。密码12～256字符、至少5种不同字符，安全存储强哈希和随机盐；连续5次失败锁定5分钟。受保护服务中保存密码和授权，不在共享可写业务目录中开放权限账，不接受Windows运行资格替代管理密码。新格式损坏、已配置密码缺失或服务不可用均拒绝受限操作。

旧版1.10.2已有账号的部署不会自动选取某个账号当成模式。仅显示一次性的旧凭据转换：验证原账号和密码后明确设置统一管理密码，保留旧账及历史审计；转换成功后账号列表、增删/启停账号及正常用户名登录不再存在。无旧凭据时不能以“首次设置”覆盖它。旧凭据只供授权转换和受保护历史回退，新格式配置标记存在后丢失新账禁止再次转换掩盖损坏。

参数继续四类、同一完整候选和统一保存。读取、编辑、导入、恢复、草稿、快捷跳转及保存均在服务层要求管理模式；写入继续暂停、排空、版本并发和生效条件。退出/到期保护未保存输入，重新进入才能查看和继续。管理授权使用独立会话证据，业务记录中的原操作员身份保持。

日志继续读取真实软件轮转文件，支持关键词/显式正则、时间/级别/来源、有界分页、原始相邻上下文和完整栈、全部匹配或时间范围导出。查询、上下文、导出绑定模式授权；退出、到期和改密码取消受限任务并清理部分导出，不占用供包关键锁，不放宽日志来源或凭据遮盖。

复用现有受保护System宿主和D盘根，旧SCM/目录标识保留作为安装兼容；不是另一套账号体系。帮助与支持保持删除，业务审计、独立诊断与备份恢复按原职责保留。真实SDK/RCS、设备、目标IPC和现场验收分别记录。

版本兼容：本轮Sportmaster1.11.0、Application.Contracts1.16.0、管理凭据schema2、管道v2。UI、辅助进程与受保护宿主必须整套同源升级，不能混用1.10.2账号版DLL或凭据协议。模式审计记录会话及实际Windows调用者上下文；这不是操作员账号认证，业务操作员身份仍单独记录。
