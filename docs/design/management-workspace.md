# SM 现场设置、调试工作区与自动供包

## 退出供包台

整站退出先显示约580×340 DIP的紧凑确认窗，白底细边框，标题“确认退出供包台？”。本次可见作业、结果未知阶段、状态读取和待生效配置用两列普通文本展示，不使用警告图标、数字卡片或黄色提示条；读取失效明确标注，未披露的待生效状态显示“待确认”。已发送请求及未确认结果继续保留，下一步逐窗处理未保存设置，停止失败保留当前窗口；急停说明单独使用灰色文字。

“取消”默认聚焦并作为默认按钮，Esc、右上角×及关闭确认窗均取消本次退出。右侧“继续退出”使用主题深灰色和44 DIP高的紧凑按钮，确认后沿用原来的草稿保护、停止和实际释放流程；失败可再次确认重试。应用已保存配置时使用同一布局，标题和动作改为“重启”。小工作区只允许正文滚动，底部动作始终可见。原生验证入口为`--station-exit-dialog`，合成状态覆盖未知结果、待生效配置、读取失效、取消和停止失败重试。

## 独立设置窗口

工作站“设置”使用非模态窗口，“返回作业”收起设置窗口，避免Owned窗口始终覆盖主窗；再次点击设置恢复同一窗口、草稿和未到期授权，人工/PDA继续走原工位控件，切窗后按原规则重新选位。默认只读显示当前生效的本站、RCS 主机及相机身份摘要。每次编辑重新验证管理密码，不进入管理工作区，不发暂停或恢复命令。继续使用工作站的同一完整草稿、参数页、统一保存和原配置执行守卫；关闭后输入留在当前工作站，重新验证可继续，退出整站仍保护未保存输入。现场字段与个人偏好留在本窗口，专业字段仅在独立运维工具呈现；两端保存都保留未显示的完整配置字段，沿原修订CAS处理并发。

新授权回执携带实际取得的会话身份，后续观察必须匹配。过期、替换或通信未确认时锁定编辑，保留草稿和未确认保存身份。关闭只结束本窗原会话，不撤销后来取得的授权；结束通信失败保留原令牌和窗口以供重试，不持有状态锁等待远端响应。工作站设置与独立运维工具可同时打开，各自持有窗口授权；配置修订发生变化时不自动覆盖另一端更新。重新打开程序和离线维护仍须先处理未保存设置与实际运行占用。设置中明确应用待生效配置时，先核对本窗权限、原候选和实际责任，沿原退出确认保护草稿，再关闭本窗授权并停止原实例；成功释放后才重新打开。停止失败不创建新实例，保留草稿，重试需重新验证本窗授权。

## 运维设备调试工作区

旧主程序管理中心已移除。运维工具打开、登录、观察和切页均不取得调试工作区。只有明确确认“进入设备调试（暂停整站供包）”后，原Application才按本连接与本次工作区身份暂停普通扫码、人工供包及新自动派发，保留原软件暂停、投递位启停和已发请求。现有隔离范围为整站，未新增按位隔离承诺。

相机连接和预览保留，自动识码暂停，明确触发调试才读码；原生路线在暂停期间只读取原图。RCS仍按现有真实响应和有效期决定生产资格；结束调试不会在RCS离线时恢复识码，不改写原请求或当前放置结果。

窗口正常结束先取消本窗读取、等待真实调用收口，再按原工作区身份核对恢复。断连、异常退出或确认授权撤销由原工作站回收该连接工作区，工具不自行接管SDK。通信失败不等于撤销已确认，实际释放失败保留所有者、暂停原因及重试；成功后保留进入前的软件暂停和投递位状态。实际已发或结果未确认的请求继续按冻结报文、目标和永久防重收口，绝不因页面重开或IPC重连补发。

每次明确进入生成新的工作区身份；过期关闭或旧授权排队回收不能关闭新工作区或撤销其他有效授权。未保存专业草稿在锁定页面保留。工具断连后可关闭自身界面和文件使用权，但不能据此宣称工作站资源已释放。

诊断页保留左右相机、RCS、存储及折叠详情。只读观察不需要进入调试；经授权，可在实时画面独立校准已启用、在线且无当前件或未结执行责任的一侧，另一侧继续供包。重连和相机/人工RCS调试沿本连接原工作区执行，且原Application再次检查设备、配置和实际资源。未配置相机显示待配置，实际释放失败显示待确认。详细权限、租约与离线维护边界见[双程序IPC](sm-readonly-operations.md)。

首次配置的打开方式随首次配置一起保存，跨配置步骤保留选择；首次进入作业窗口即读取已保存方式。全屏时 Esc、F11 和系统还原不返回窗口；右上提供最小化到任务栏及“×”退出软件，最小化恢复时仍为全屏。退出沿用原有停止与释放流程，失败保留窗口、说明原因并可重试。打开方式继续使用同一设置页的统一保存。

首页顶部右侧并排显示本机时间、全屏最小化按钮及退出“×”，不设品牌标识。左侧菜单采用图标在上、文字在下的窄栏，右边缘中部的拉手在展开时向左、收起时向右。供包状态、操作说明、班次统计及 RCS 在同一行；操作反馈单列于下方窄栏，无内容时该行高度为零。

待机、RCS 离线和已停用共用居中的浅灰状态区域，标题依次为深绿色“等待投包”、深红色“暂不能投包”、灰色“已停用”。离线保留输入条码、禁用提交，提示检查 RCS 连接后提交；没有“重新扫描”或“开始”动作。真实拒绝、处理中、未确认请求及有效格口仍显示原结果。收起侧栏为 52 DIP，图标 18 DIP、选中与点击区域至少 44 DIP；边缘拉手视觉为 18×36 DIP，点击范围保持 44×44 DIP。

左右卡片底部将输入提示、操作按钮、设备信息分为三条共享高度行。只有一侧出现提示或提示换行时，另一侧仍为同一提示行让出高度，提交与详情按钮以及相机信息保持对齐；提示清空后共同收回高度。

作业页的软件暂停不遮住本次多码拒绝、业务拒绝或未确认责任。单码已读到但准入受阻时，明确显示尚未受理、未请求格口；当前相机观察按身份保留一张完整原图，每位至多一张，后续观察替换、停止或新班次后释放，不生成作业、请求或持久化图片账。拒绝放置仍沿用原拒绝原图。顶部仅在软件暂停时提供“恢复供包”，沿用 Application 的恢复守卫；不能恢复时提示到运维工具设备调试检查。恢复本身不重放受阻输入，也不重发原请求。
