# 真实旅程与建议路径

阅读方式：每条先给目标/前置状态，再依次还原入口、判断、可见反馈、实际变化、完成和恢复。Sxx见[源码索引](source-evidence.md)，Nxx见[证据记录](evidence-and-field-plan.md)。下面的操作顺序由源码和有限原生走查还原，未执行的安装/维护动作不标为PASS。

## J01 获取、安装与进入软件

目标：实施人员安装正确模块和版本，找到运行入口。前置：同源可信完整介质、D盘受保护程序父目录/独立数据根、Windows授权能力；已有站还需匹配原部署和责任。

|步骤与入口|操作/判断与反馈|实际变化与完成条件|失败或中断后的路径|
|---|---|---|---|
|1 发行回执/单EXE|核对模块、SourceCommit、哈希及系统前提；公开1.10.2不能当最新1.12.3|确认交付对象，尚未安装|对象不明先取得正确介质；不运行旧包试探新库|
|2 双击单EXE → 准备/安装选项|设置程序/数据位置及快捷方式；确认页审阅原部署和备份信息|只预检、准备固定请求；没有启动设备|路径/权限失败保留输入；返回修改；取消未提交准备。旧指南要求的账户/模式等控件已不在当前正常向导（F09）|
|3 确认安装 → UAC/helper|当前阶段文字反馈；授权拒绝、未提交失败与结果未知分开|复制可信程序并提交唯一部署登记；系统项/快捷方式由登记派生|正常失败可按回执修正；Unknown不得重复提交，当前只能打开记录目录（F03）|
|4 安装完成 → 打开/首配|按是否存在配置决定首配或正常启动；错误运行身份不能靠提权绕过|进入正确首配/启动窗口才完成安装到使用的衔接|安装成功但启动失败进入离线维护；不能据“安装完成”认定设备可用|

证据S01/S02/S04/S12；本轮未执行安装或系统快捷方式。当前安装中关闭不会撤销已提交事务，这一限制必要；缺的是关闭后继续核对同一事务的路径。

## J02 首次配置与启动

目标：实施人员把新站配置为可解释、可继续完善的状态。前置：独立新站或合法恢复路径；供包台、仓/生产线、相机与RCS资料按实际交付准备；管理模式初始化/授权独立于操作员。

|步骤与入口|操作/判断与反馈|实际变化与完成条件|失败或中断后的路径|
|---|---|---|---|
|1 安装后的首配窗口|五步独立流程；设备/条码、格口请求、限制、站点/数据/显示及检查等叶页沿实际导航填写|编辑同一候选，不因翻页启动连接；首次配置不加入日常导航|上一页保留输入；错误定位具体字段。相机/RCS未到位可分别明确“稍后配置”|
|2 配置核对|仓ID/生产线ID、同一供包台编号映射、左右相机用途；新默认7天；窗口模式为本机偏好|明确候选与本机偏好的不同作用域；新取格口数量固定1，无需机械录入|不把示例IP/编号当生产默认；取消延后后重新要求连接字段，重新勾选仍保留输入（N01）|
|3 保存配置/保存草稿并退出|最终检查、保存后读回；完成前要求输入仍与保存候选一致|草稿是未完成输入；“已保存待启动检查”仍不是运行成功|退出重入继续同类加密草稿；不可解密或来源变化保留原件并明确诊断；未知保存先核对原提交|
|4 完成 → 正常启动|先分类配置/权限/原责任，再启动真实资源，成功才确认Effective|可进入软件且说明待配置连接；相关业务仍阻断|启动失败回到离线维护；可修正/备份/合法恢复，不创建空库覆盖原责任|

N01验证首配表单/偏好与延后守卫；未完整执行“从安装到首配保存再Production启动”的岗位旅程。明确延后是可用路径，不能写成“缺设备就无法配置软件”。

## J03 日常双位供包、暂停与交接

目标：操作员处理当前实体并正确读取属于该侧/该次的结果。前置：正确站点、业务操作员、资源健康和准入允许；当前模拟证据不授予真实设备资格。

|步骤与入口|操作/判断与反馈|实际变化与完成条件|失败或中断后的路径|
|---|---|---|---|
|1 作业主窗|识别站点、操作员、左/右相机，检查阻断条；已连接不等于允许供包|唯一业务实例；切页/辅助窗不重建连接或发送器|未授权/待配置/旧责任阻断分别处理；禁用恢复旁有原因，必要时维护查看上下文|
|2 一次完整扫描|该侧相机/扫描/任务三组对应；同码独立扫描形成不同作业|观察→准入→作业→固定原请求→一次发送/回执；成功取格口后显示该作业信息|无效新输入隐藏旧可行动格口；另一侧结果不挪用；迟到结果归原作业（N02）|
|3 查看结果|区分取到格口、明确拒绝、未知、冲突；请求回执不等于物理完成|SM只有获准的RCS阶段事实，不伪造PLC或包裹实际完成|Unknown保留实体及原请求交接；不反复扫描/重连/重启试图重发（G01）|
|4 暂停/恢复/交班|暂停新入场的含义明确，软件暂停不是安全急停；恢复再次经过守卫|恢复只解除允许解除的阻断，不补发未知请求；交班应核对未清责任与身份|没有证据证明交班人员能独立完成。待补原实体/原请求交接包；设备危险遵循现场独立安全流程|

N02含合成同码、坏输入、缺字段、拒绝、迟到暂停回执、读取失败和页面切换；48个断言不是48次真实用户任务。

## J04 管理模式、参数编辑、保存与生效

目标：受限操作人员准确修改对象，并确认运行结果。前置：合法进入管理模式；参数写入还受暂停、外呼、Revision等应用守卫。Windows管理员身份不直接代替管理模式。

|步骤与入口|操作/判断与反馈|实际变化与完成条件|失败或中断后的路径|
|---|---|---|---|
|1 顶栏管理模式 → 参数设置|独立授权，保留操作员；系统/业务模块/驱动/组件四类；实例标识和左右用途区分|进入已有编辑会话，运行实例不重建|失败/到期拒绝受限操作；退出/到期使日志撤权、回作业，当前进程内编辑上下文保留；重启前需保存草稿|
|2 编辑/查看更改|固定业务结构与可配字段分开；校验定位、差异审阅、原值/新值|完整候选为唯一提交对象，切页不分别生效|无效字段保留；重读/模板替换需处理已有输入；不要把高级JSON当默认必经步骤|
|3 保存更改|结果区分Pending、Unchanged、Conflict、Unknown、NotSaved；Unknown可核对原保存|Pending入唯一配置账，当前运行不改变，原请求不换目标|冲突重新读取/审阅；未知先核对原提交；会话到期重新授权，不丢候选也不复用过期审阅|
|4 应用与复核|当前只说“等待受控重启”；高级工具可看运行/Pending原文|需正常停止/重新启动，通过启动条件并确认Effective；单纯重连仍用旧运行配置|引导缺口F04；失败保留原Effective/失败证据，不能自动恢复供包。重新读取实际配置与连接资格后才结束任务|

证据S05/S06/S12。离线修复窗口存在“保存并启动”，不能因此声称运行内参数保存已有同样完整入口。

## J05 作业记录、日志和导出

目标：查到正确范围/对象，取得可核验的完整文件。前置：操作员可访问作业记录；软件日志需管理模式。二者都不能作为改写业务事实的入口。

|步骤与入口|操作/判断与反馈|实际变化与完成条件|失败或中断后的路径|
|---|---|---|---|
|1 页面 → 作业记录|完整条码、投递位、状态；更多筛选含请求和带时区时间；查询|生产查询固定筛选与序号上界，结果为快照|输入修改未统一标出“尚未应用”（F05）；投递位用内部字符串（F06）；清空有重新查询提示|
|2 选择记录/下一页|详情固定原作业；当前选择即使不在本页也有说明；下一页续同一范围|不会按同码选中另一实体；旧请求/尝试/接受事实可追溯|仅有下一页，返回旧页要重新查询并向后翻（F07）；筛选变化会阻止续旧范围|
|3 导出表格 → 文件选择|选择新文件；导出期间可取消；完成回执含行数/字节/hash|独立只读会话、固定范围、partial与result.json；完整CSV发布后才完成|不覆盖已有文件；取消不发布部分CSV；失败保留回执。先固定筛选才能导出，不把F05说成已证实错文件|
|4 页面 → 软件日志（授权）|时间/来源/关键词或正则，上一/下一页，详情上下文；可复制和导出|条件变更使选择失效；格式化异步；导出同一选择；日志与业务库事实分开|离页/退出管理模式撤权并清上下文；再入页需重新查。大文件、文件选择/导出实测本轮未覆盖|

证据S07–S10、N03。目标DPI下紧凑页可显示完整结果行，但这不等于长条码、所有详情和多页导航均经过用户验证。

## J06 故障识别与恢复到正常工作

目标：操作员先保护实体，维护定位影响并恢复允许恢复的能力。前置：冻结正确原对象；无真实合同的动作保持禁用。

|步骤与入口|操作/判断与反馈|实际变化与完成条件|失败或中断后的路径|
|---|---|---|---|
|1 主窗阻断条/当前任务/全局回执|区分配置、健康、存储、恢复责任、未知；读取失败使可行动结果失效|不把旧快照成功继续当当前可放货依据|复制原作业信息并进入对应记录/管理诊断；笼统拒绝回执需结合阻断条，不能只看成功色|
|2 断线/超时|受控重连按当前运行配置；对端未返回不等于未接受|重连修复连接，不改原请求或应用Pending|无权威查询则不能自动重发，G01；真实现场需确认何人/何证据接管|
|3 启动/存储异常 → 离线维护|先停止和释放，再读取完整原目录、备份/恢复计划|缺账/库但有原事实拒绝当新站；低空间不靠删除责任记录修复|保存失败保留输入及回执；停止失败显示仍持资源，不能开第二实例抢占|
|4 故障解除后复核|读回配置、连接/健康、原责任与准入，明确人工恢复|所有相关守卫满足且操作员确认后才允许新入场|恢复隔离/未知责任未解除仍暂停；不能将“窗口能打开”当作恢复成功|

证据S06/S11/S12、N02。生产断线、磁盘满、超时现场表现及操作连续性仍待目标机验证。

## J07 退出、重启与再次启动

目标：区分关辅助窗、停止主实例、暂停新入场及安全急停；正确保留输入与原责任。

|步骤与入口|操作/判断与反馈|实际变化与完成条件|失败或中断后的路径|
|---|---|---|---|
|1 暂停按钮或窗口X|暂停只阻止新准入；辅助窗X不拥有根停止；主窗X拥有全组停止|既有作业仍受业务状态机管理；不以窗关闭取消已发请求|主窗没有先行作业停止/未决摘要（F08），不能推断用户知道差别|
|2 关闭检查|等界面任务排空；有未保存编辑提示继续编辑/加密保留/放弃；多窗需各自处理|草稿保留有显式选择；单个运行实例释放|取消保持上下文；5秒等待/停止失败恢复界面并提示持有资源，不吞异常退出|
|3 再次打开正确快捷方式|读取唯一登记、原账/Pending和未清责任，先检查后启动|配置成功激活有事实；恢复不自动重投原请求|不能启动则进入离线维护；新软件读未来/不兼容库被拒绝，不能换旧EXE试读|

S06/S12。N03只证明合成无草稿窗口可关闭；夹具没有实际部署StopOwner，不能把这次关闭写成正式客户端退出/资源释放验收。

## J08 升级、修复、备份与恢复

目标：实施维护在停机条件下保全责任，再迁移/修复。前置：可信精确版本与完整恢复集、有效管理授权，相关操作还需UAC。不同权限不可互换。

|步骤与入口|操作/判断与反馈|实际变化与完成条件|失败或中断后的路径|
|---|---|---|---|
|1 完整介质安装/修复，或离线维护 → 恢复与维护|读取原部署/账/DB/原责任，选择完整备份位置，计划与执行再次核验|同一owner内备份并并排部署，最后切唯一登记；系统项可从登记修复|程序损坏用完整介质，不能删登记装成新站；Unknown走F03|
|2 创建完整备份/读取校验备份列表|显示时间、大小、完整性，保留无效项；.db与同名.recovery须一起保管|整集完整性核验成功才是可用备份；配置模板只含白名单，不是备份|磁盘/权限失败保留诊断；计划备份需要维护条件，不自动暂停生产或随意删旧份|
|3 选择完整备份 → 检查计划 → 恢复新目录|选择文件和新的隔离根，确认版本/哈希/空间及原件|复制并核验，原根保留，新根仍隔离|残缺集/不兼容/被占用拒绝；恢复成功不等于允许供包|
|4 接管已恢复原机目录 → 启动后核对交接|明确原根退役/登记切换影响；核对原请求、设备、外部编号和事实|先持久退役围栏再切登记；确认交接后仍受准入守卫|备份后原根变化须重新停机备份；换机缺退役/秘密/资格证据保持隔离，不做自动接管|

S02/S04/S12。正常机制存在但信息密集、文件/目录选择和多层权限的真实完成率未知。不能为减少点击移除预检、完整备份、原根围栏或外部事实核对。

## J09 卸载、保留数据与重装

目标：明确移除和保留范围，处理占用/中断，再按原身份重装。前置：可访问原部署/同源介质、原责任允许、完整备份、管理模式和必要UAC。

|步骤与入口|操作/判断与反馈|实际变化与完成条件|失败或中断后的路径|
|---|---|---|---|
|1 Windows已安装应用 → 修改/卸载|实际登记指向同一EXE `--product-maintenance`；读取安装与原责任|独立维护窗不启动设备；不是日常参数里的“卸载组件”|原程序损坏从可信完整介质处理；系统项损坏可按登记修复|
|2 完整备份并卸载程序 → 确认|确认程序/快捷方式/系统项移除，原数据/身份/扩展/共享驱动保留|复核计划/备份；先退役再按精确清单删除；不递归删用户目录|取消不执行；占用文件登记Windows重启清理；清理错误可能发生在退役之后|
|3 结果与中断重入|当前终态不再错误要求卸载后的管理授权，这是PR107已修复点|完整回执有Status/Remaining/Restart，但窗口仅消费Restart（F01）|退役重入只有关闭、要求按回执清理；缺固定清单继续入口（F02）；不能人工猜目录删除|
|4 重装|新安装读取原数据/登记/身份/责任，检查版本与完整性|保留数据意味着继续原站，不是清空重置；应用新版本仍需正常启动检查|Unknown/恢复隔离继续有效；共享驱动/凭据保留需在说明中明确，清除账号/数据另需授权任务|

S02–S04；本轮未卸载、重启或重装。F01/F02是源码路径证据，不虚构真实安装故障。

## 关键改进路径与保留步骤

|流程|当前路径|建议路径|保留/合并/自动完成的理由|
|---|---|---|---|
|安装未知|Unknown → 打开目录 → 人工解释记录|Unknown → 自动定位原操作 → 只读刷新/复制支持摘要 → 明确已完成/仍进行/失败/仍未知 → 对应下一步|自动承担查文件/匹配身份的机械劳动；不自动重发安装；UAC和实际提交回执保留|
