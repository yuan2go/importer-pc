# Sportmaster 原生 Windows 后验清单

当前运行与已执行范围见[本轮交付](../sportmaster-visual-productization-01.md)。本清单替代classic缺省、蓝紫双栏的旧当前指令；旧清单原字节及来源main f3059d4见[归档](../../archive/pre-sportmaster-visual-01/README.md)。原SHA、批准、历史失败和D/RV保持。

1. 从同一冻结源码产生的新win-x64介质核SHA256SUMS与application-release.json；安装到新程序目录，保留原数据根、身份和请求。以指定Windows账户非提权启动。Sportmaster省略UI参数进入supply-station，显式--ui classic进入兼容页；--view/--layout继续有效。DirectPlc/WcsToPlc省略UI参数保持原入口，拒绝supply-station；不开发DirectPlc UI。
2. Windows本轮合成原生验证复用 `scripts/verify-commercial-wpf.ps1 -Media <新目录> -Output <新证据目录> -Dotnet <10.0.402路径> -VisualProductization`。它固定介质SourceCommit对应夹具、校验验证前后库存；内部合成身份/端口只属于测试，不是客户端运行绕过参数。加-Interactive可用同一窗口进行鼠标键盘后验。
3. 观察正常/等待、左处理中右已取得、拒绝、Unknown、失效、长码/长格口。本次观察、当前作业、旧未决请求分别核对；格口只在本件有效接受事实下展示。Unknown查询原请求，不增加发送或改目标；格口取得不表示物理完成。
4. 反复刷新和来件，选择条码与完整原件文本，编辑本位检查说明和维护草稿，展开/滚动诊断、切页、切布局和切历史选择。迟到快照或查询不恢复旧选择；相同显示值不应重置焦点、选择、展开、滚动或草稿。主/辅助窗口继续共享一个Application，主窗停止失败仍保留资源责任。
5. 在真实有效客户区1440×900、1100×600、911×512、800×420 DIP检查层级、完整字段、固定动作和长内容局部滚动。800×420以下进入保护并请求软件Pause；恢复空间仍须确认视图和显式恢复，不自动Resume。紧凑来源诊断/操作员登录从展示设置进入，不能因诊断折叠丢失认证入口。
6. 历史用日期、时间和UTC偏移查询；开始含、结束不含。试+05:30/+08:00/Z、日期边界、夏令时地区、非法时间与清除范围。非法编辑不可静默沿用旧条件；高级精确原文和完整JSON可选可复制，列表偏移不截断。筛选冻结/分页/导出仍沿原账与预算。
7. 首配按目录与工位→设备与服务→运行策略→检查与启动，另有恢复维护页；切步骤保留未保存输入。模板、备份恢复和支持低频展开；检查不启动设备，不创建业务库；Production缺能力仍拒绝生效/作业。帮助与支持窗口共用原Application，摘要只在本地预览/导出。
8. 原1920×1080、1366×768各100/125/150%、混合DPI多屏、触控/手套、HID、读屏、现场视距和长时间连续来件矩阵不缩减。本机125%与实际可用窗口仅覆盖其记录尺寸；其他场景逐项NOT_RUN。真实SDK/WCS/设备/实体/现场仍BLOCKED，原生局部PASS不构成商用放行。
