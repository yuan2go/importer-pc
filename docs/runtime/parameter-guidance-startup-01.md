# 参数与首次启动的当前规则

历史实施、版本和验收原件见[归档](../archive/pre-fresh-baseline-current-guides-01/README.md)；原PASS只属于原SourceCommit。当前仅支持从零安装、当前格式建库；非当前输入保留原件并拒绝，请使用全新数据目录。

四类参数编辑同一个完整候选；使用管理模式、原Revision/CAS、保存核对和受控重启。原请求固定原配置、目标及报文字节。字段布局遵守参数V3，作业界面遵守V2。

| 项目 | 当前规则 |
|---|---|
| 用途说明 | 参数名称、说明、单位和合法范围可见；悬浮说明与辅助技术使用同一来源。无效输入留在草稿，不能替换Effective。 |
| 业务标识 | zone-id为仓ID，project-id为生产线ID；同一候选的供包台编号明确统一至左右取格口与心跳，左右相机编码仍各守实际用途。 |
| 保留期 | 新站日志和已结历史默认7天；当前候选的可选空值和显式天数按各自策略处理，维护逐笔核对责任，不能静默删除未结数据。 |
| 打开方式 | 窗口或最大化为当前Windows用户展示偏好，下次打开工作窗生效；F11切换，Esc返回窗口，不改变业务和设备状态。 |
| 延后配置 | 相机/RCS可明确稍后配置；DeferredConnections保留未完成输入，待配置端口只报告不可用，不创建对应socket/SDK，不模拟成功。Application拒绝受影响的准入和发送。完成候选、保存并受控重启后重新检查结构、SDK和生产资格；重连不能启用Pending。 |
| 扫码与数量 | Sportmaster左右TCP相机每条完整LF报文对应一次扫码观察，新请求quantity固定1。同码的独立扫描保持独立；暂停、未就绪、原结果未知时仍按业务守卫拒绝。冻结原报文保持原字节和数量，不能改写后重发。 |

DeferredConnections只接受当前Sportmaster左右读码设备ID及RCS实例，未知或重复身份拒绝。精确包、签名、拓扑及活动模块依赖闭包继续核验。通用TCP驱动的仅观察模式供其他明确用途使用，不代表实体准入。

个人偏好位于HKLM注册的D盘存储根的UserData下。Users只可创建自己的子目录，CREATOR OWNER继承写权限；机级配置和程序目录保持只读。非当前用户所有的目录和路径链接拒绝使用，不能重写既有ACL绕过保护。

正式卸载入口仅在登记为Installed时申请管理模式并生成计划；取消或授权失败不卸载。已退役或完成卸载后只显示结果、重启提示、保留数据位置和关闭，不再请求管理授权或保留操作表单。同格式修复和卸载归属机制保留。

验证使用当前源码及同源介质，在全新隔离目录运行parameter-guidance-startup、parameter-refactor、dual-camera-communication与对应WPF专项。先执行`. ./scripts/project-environment.ps1`。实际结果以本次CI为准；历史验收不扩展至当前提交。目标IPC、真实SDK/RCS、现场网络和设备资格须分别验收。
