## 失败历史与修正

`failures/`保留代表性原始失败，不删除断言或吞异常换PASS：

- 初始合成斜码出现短伪ITF及同图重复候选。通过原图连续扫描线和图案位置证据修复；合法短ITF仍有正向测试，没有加入商品长度或默认业务正则。
- 统一提高全部码制的确认线数曾使私有较重模糊Code128漏读。最终保留必需校验码的原确认线数，对ITF等无必需校验码增加原生/物理线支持。
- 原生等待态测试最初断言不可见的原因控件，后改为核验实际等待指令的可见性、完整行高和禁止借用旧格口的文案。
- 原生键盘首次因前台HWND不是测试窗口而拒绝注入；保持守卫，显式激活同一合成测试窗口后，冻结源独立重跑20项且进程退出0，原始失败保留。
