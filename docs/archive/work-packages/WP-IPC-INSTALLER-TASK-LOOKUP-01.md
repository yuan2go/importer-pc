# INSTALLER-TASK-LOOKUP-01

2026-10-26，基线 main `e70b8ece`。用户在本机首次安装后遇到“系统找不到指定的文件。0x80070002”，只读核对确认原登记已提交，系统入口修复再次失败，要求修复。原安装记录、用户截图、注册表/账户及配置数据只保留在D盘，不加入Git。

范围：修复 `DesktopRecoveryInstallation` 查询不存在的计划任务时的.NET异常映射；修复安装向导在原结果未知/已提交时，将后续修复失败错误降级为可重新安装的状态。继续复用原受保护部署登记、独占租约、完整介质检查和管理员修复契约，不重新安装、不重置管理密码、不启动业务或设备。

缺陷：恢复默认关闭，新装会幂等移除本产品旧计划任务。实际.NET 10 COM动态调用把缺失任务的 `0x80070002` 映射为 `FileNotFoundException`，原处理只捕获 `COMException`，导致已提交登记后的系统投影中断。修复只接受GetTask边界内的明确缺失；权限、服务、目录、具名缺失文件及其他IO异常保持失败。现有任务身份、归属检查、注册/移除逻辑、恢复默认值和公共协议不变。

安装结果未知只由可信原操作核对解除；系统入口修复失败仍保留原请求、准备文件、只读核对和修复入口，不提供新安装提交。新增委托仅为既有原生夹具注入同一修复契约，生产仍走原管理员通道。

验证及边界见[实施记录](../runtime/installer-task-lookup-01.md)。Windows只读计划任务复现、原生合成安装回归、本机原登记修复与新安装包测试分别记录，不将任何历史PASS扩张为新源或现场验收。既有D/RV、管理模式、Unknown原请求、DB9和真实SDK/RCS资格保持。
