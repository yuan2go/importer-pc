# 参数与操作清单：截图证据及重设计迁移建议

## 证据范围

已逐张实际查看 14 张维护与首次配置截图。以下包含 58 条字段/状态和 39 条操作，明确区分原图事实和新设计建议。未读取源码，未运行生产软件。附件所述冻结版本：`0e79e73bdb6d7a1702373963295b192a803f28e7`；合成数据。

## 最重要的设计判断

1. 把“创建实例 → 配置连接/参数 → 绑定左或右投递位”拆为可连续完成的三个明确任务；用户看到的是左位相机或WCS服务，内部ID默认放详情。
2. 把已安装组件、已启用实例、业务绑定、连接健康分开显示；不能靠一个下拉框代表四种不同状态。
3. 常用配置用对象列表＋详情；首次安装可用向导。旧schema、JSON、原账与原机接管放按需维护任务，不维持9个横向技术页签。
4. 每个对象页固定显示编辑基线、已保存修订与实际运行修订；保存和应用分开。失败时不能把“最后确认”的配置无条件描述为正在运行。
5. 所有运行参数范围/默认值依驱动、Application或服务描述；本清单不把样例值当默认。
