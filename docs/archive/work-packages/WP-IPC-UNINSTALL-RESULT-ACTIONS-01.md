# UNINSTALL-RESULT-ACTIONS-01

2026-10-28，用户反馈卸载结果页的核对、继续清理、关闭三个按钮无用。基线 `d506f77c`，独立 D 盘工作树 `codex/uninstall-result-buttons`；不覆盖原工作区，未整合并行 PR133～137。

## 当前修正

本包承接 LIFECYCLE-UX-OPTIMIZATION-01 的 U01/U02。只读核对必须重新观察原程序目录，不能将卸载时保存的 Remaining 当作当前磁盘结果；原受保护登记、固定清单及卸载回执仍是责任依据，核对不得写回或重新删除。未取得清理终态的 Prepared 仍报告待确认，不能仅凭目录消失推定维护已完成。

继续清理保留原 SourceCommit、完整介质、登记 CAS、固定清单和 Windows 授权检查。界面提前说明来源不匹配，禁用不能执行的继续按钮，展示原版与当前包的源码身份及下一步；服务仍独立复核。关闭使用独立窗口动作，不作为维护任务执行；检查/清理进行时继续防止重入和误退出。

## 验证范围

- 内核：旧残留在解锁/模拟重启清理后消失、清单外文件保留、Prepared、目录替换/链接、预算及无写入。
- 原生 WPF：实际按钮事件、检查反馈、来源不匹配不调用清理、同源续办、失败后可检查/关闭、Unknown 禁止续办、模态返回与关闭。
- 构建与发布启动冒烟按本次实际源码记录；使用合成目录与回执，不执行本机真实卸载，不删除用户残件、不自动重启、不触碰设备。

实施与实际结果见 [运行及验证](../runtime/uninstall-result-actions-01.md)。历史卸载证据、RV、D 和发布身份不改写；Windows 受保护安装往返、真实 UAC/重启和现场仍独立验收。
