# SM RCS 参数生效与原请求

供包台编码只保存在完整配置的 `StationCode` 中，首配和日常设置均只有这一个输入。心跳读取当前生效配置，新取格口请求从原作业配置冻结相同字段，左右仅区分 `bcrCode`。不存在左右站点编码参数或旧字段自动迁移；旧配置在写入前拒绝，原冻结报文保留原件。

条码规则、已配置相机参数和 RCS 连接参数可以即时生效，仅替换改动的连接。配置账审核完整候选，设备身份变化、待配置转为已配置、混入其他设置或已有待生效修订时走受控重启。重连只使用当前生效配置。

热生效和启动激活共用当前业务责任边界。未离位的未决作业、实际在途、未提交回执、资源释放和身份冲突仍有守卫。确认离位且执行与回执责任收口后，Unknown 进入历史保管。它仍受磁盘容量和原请求防重保护，在“记录”按需查看。维护和调试读取期间保留待生效设置，处理当前责任后重新打开。

内置 SM 校验真实安装授权、候选参数、能力合同和设备身份。组件实现指纹用于核验执行和冻结请求身份。旧请求固定原报文、目标、配置和编号。按现行规则清理不兼容的旧内置取格口请求，范围见 [AGENTS.md](../../AGENTS.md)。

RCS 请求超时和心跳间隔均属于连接参数。保存成功以回执为准，设备连接状态在“设备与诊断”确认。参数说明由内置 RCS 参数资源提供，保存在配置账的是参数值与能力绑定。改动嵌入资源会改变新构建的组件字节，安装更新使用完整介质。

取格口请求默认1000ms，合法范围100～30000ms。有效期限随新请求冻结，连接、发送及完整响应读取只启动一次计时；读取分块不续期，修改配置不改变在途原请求。发送资源等待在最终轮次核验和持久首次尝试之前，内部输入交付预算独立于本期限。超时、取消、部分响应、确证未送达和业务拒绝各留实际证据；超时不自动重发，不提示直接重扫。晚到结果只归原请求。自动识读期限是另一项轮次设置，不与RCS计时混用。
