# 管理模式 · 当前操作与实现

历史实施、版本和验收原件见[归档](../archive/pre-fresh-baseline-current-guides-01/README.md)；原PASS只属于原SourceCommit。当前仅支持从零安装、当前格式建库；非当前输入保留原件并拒绝，请使用全新数据目录。

普通模式导航为“作业、作业记录”。点击“进入管理模式”，填写站点管理密码即可进入；无用户名。管理模式显示明确状态及到期时间，开放“参数设置、日志查询”及对象相关维护。“退出管理模式”立即撤权；15分钟到期自动退出。首次使用须设置并确认管理密码，沿现有安装维护批准通道保护首次设置，无默认密码。设置/进入/退出不修改操作员账号或在途作业冻结身份，不要求暂停。

到期维护采用请求绑定的一次性入场与持续授权：入场票据仍最多两分钟且不可重放；已核销操作在每次权限检查时重新核对原会话、凭据及请求，最长只到原会话到期和操作预算。它不会把15分钟管理会话自动延长为两小时，也不会借新会话沿用旧委托。退出、到期、改密码或重新登录均撤销旧持续授权；维护按原持久回执保留已提交事实并安全中断。

管理模式中可修改管理密码，确认新密码后撤销所有原授权；重新进入后继续。按 UI02 后续用户纠偏，密码最低5个字符、最多256个字符，允许纯数字和重复字符，继续拒绝控制字符。安全存储强哈希和随机盐；连续5次失败锁定5分钟。受保护服务中保存密码和授权，不在共享可写业务目录中开放权限账，不接受Windows运行资格替代管理密码。新格式损坏、已配置密码缺失或服务不可用均拒绝受限操作。

参数继续四类、同一完整候选和统一保存。读取、编辑、导入、恢复、草稿、快捷跳转及保存均在服务层要求管理模式；写入继续暂停、排空、版本并发和生效条件。退出/到期保护未保存输入，重新进入才能查看和继续。管理授权使用独立会话证据，业务记录中的原操作员身份保持。

日志继续读取真实软件轮转文件，支持关键词/显式正则、时间/级别/来源、有界分页、原始相邻上下文和完整栈、全部匹配或时间范围导出。查询、上下文、导出绑定模式授权；退出、到期和改密码取消受限任务并清理部分导出，不占用供包关键锁，不放宽日志来源或凭据遮盖。

复用现有受保护System宿主和D盘根，既有SCM/目录标识继续承担当前安装归属；不是另一套账号体系。帮助与支持保持删除，业务审计、独立诊断与备份恢复按原职责保留。真实SDK/RCS、设备、目标IPC和现场验收分别记录。

管理凭据schema2、管道v2；UI、辅助进程和受保护宿主必须整套同源发布。业务及公共契约版本以项目文件和发布清单为准，不混用DLL或凭据协议。首次安装设置管理密码，没有旧账号转换入口。
