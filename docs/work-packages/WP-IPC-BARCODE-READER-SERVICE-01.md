# BARCODE-READER-SERVICE-01 · 独立读码服务

目标：固定工业相机由MVS取图、VisionMaster固定方案解码，作为独立x64生产者按[现行行协议](../protocols/barcode-producer-v1.md)向单个供包台客户端输出完整触发事件。服务不得以条码或时间窗口定义实体，不重放跨断连事件。

唯一内部设计为[服务设计](../design/barcode-reader-service-01.md)，实际可运行部分和未完成项见[运行说明](../runtime/barcode-reader-service-01.md)。本包没有完成交付；租约/心跳要求与既定协议的冲突待裁决，实际VM方案SDK路径待提供。

验收仍需完成：共享采集和有界池、实际VM适配及方案接口、触发归并/选择规则、严格服务端、完整就绪及授权门控、监督与有序停止、独立回放工具、共享黄金样例和假相机至供包台真实解析端到端。现有核心测试不能替代这些剩余项。真实相机/SDK/方案/授权/24小时验证另行计证。

范围外：方案搭建/调参、读码平台现场配置、生产资格与签名。供包台侧修改须先解决明确的协议边界冲突；原请求和历史D/RV不改。
