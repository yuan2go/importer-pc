# 实施与维护手册

适用 SM 1.0.0。打印稿与本文同源，附完整故障目录。

## 准备

取得获准分发的同源完整介质、版本/源身份/哈希、D盘容量和Windows管理权限；明确目标OS、网络、相机 IP/编码（序列号按 IP 自动读取）、仓ID/生产线ID/供包台编号及RCS合同。全部开发缓存和测试数据使用D盘。新机无机器存储登记时使用内置 D:\ImporterPc 受保护根，读取和预检不写机器状态，授权安装时创建目录和权限。已有登记严格按原位置核验，不静默迁移，不以链接或新空目录绕权。

当前SM新站默认[海康原生识码](../design/mvid-native-reader.md)及内置RCS，无PLC。每台相机仍可在高级设置选择MVS采图加软件识别；海康原生识码需要完整安装包包含匹配的原生组件，仅安装MVS不够；不需要另开读码程序。不要准备TCP读码端口或外置扩展信任。现场SDK字节、ABI、物理设备及分发许可仍须核验。各次托盘放置仅发一次RCS请求；识别/保存/请求接受/物理完成分别记录。

## 安装与更新

1. 完全停止原软件，保留当前记录及未决包裹；核对安装介质来源与目标版本。
2. 打开安装器，核对程序/数据目录和操作种类。新SM默认程序`D:\CainiaoSupplyStation`、数据`D:\ProgramData\ImporterPc\data`；已有站保留原登记路径。
3. 明确安装并完成Windows授权，等待真实阶段和完成回执。资源未释放时先关闭供包台。
4. 以普通用户打开，软件自动检查并启动；首次配置保存后自动启动，条件不满足时显示具体原因。安装完成不等于相机/RCS就绪。
5. 结果待确认时只核对该次安装，已提交但入口失败只修复原系统入口，不创建新操作覆盖。

同版完整介质允许覆盖安装并保留本站数据。安装可完成与业务数据可打开是两个检查：当前正常运行只接受 DB13 的真实基线和结构。DB12 不自动迁移；已有[显式离线接续](../design/sm-db12-continuation.md)须在管理授权及实际停机后单独核验，不提供旧格式运行路径。其他非当前格式在写入前拒绝。安装结果未确认时沿原事务核对，勿手动修改其状态。旧联调记录保留原提交和结论，原 DB/WAL、配置、请求、回执及永久编号账一并保全，不复制活动库或新建空目录绕过责任。真实 RCS 使用原永久编号账继续分配，不能因程序更新从头编号。

静默参数为候选功能，必须在已提权的部署上下文执行；不弹产品窗口、不自动启动设备、不自动重启。示例路径需由实施人员检查权限和归属：

```text
Ipc.Installer.exe /quiet /norestart /log="D:\deploy\station-01.log" /dataRoot="D:\ProgramData\ImporterPc\data" /operationId=<本工单的32位GUID>
Ipc.Installer.exe /quiet /repair /norestart /log="D:\deploy\repair-01.log" /operationId=<另一工单的32位GUID>
```

首次日志只写新文件，不覆盖已有文件。`/log`为可读文本；独立JSON回执写到同一路径加`.receipt.json`，含相同操作ID、退出码及文本日志SHA256。启动日志不代表完成，只有结束回执核对后才按退出码处理；回执发布失败时保留原事务与暂存证据，不覆盖或伪报成功。

自动化为同一工单保存同一个非空32位GUID；重放时须保留原参数、日志位置和同字节介质。重放只核对原事务，明确已完成且当前登记一致才返回原成功码；不会重新安装、备份或覆盖原日志/JSON回执。日志缺失/被外部改动另行标记，不把它当成部署权威。Unknown/进行中保持1627，不能换ID绕过；未提交的准备物和备份保留。

全部SM程序、数据和机器政策根须使用管理员批准的D盘位置；无登记时授权安装自动准备 D:\ImporterPc，不要求预先改注册表；已有登记缺失或不可用时如实报错，不落到C盘。日志父目录也须由管理员保护：缺失的目录按明确ACL创建，已有可被普通用户改写的目录拒绝，不自动放宽权限。已有存储位置的迁移仍须独立核对，不自动修改HKLM。高级逐站计划仍使用原`--deployment-plan`协议及其原退出码；不能与简化EXE退出码混用。静默安装/真实系统往返尚未完成隔离VM验收。

## 首配与日常设置

1. 沿独立五步首配填写真实站点字段，不将示例值、模拟响应或另一站身份复制进生产默认。按实际 IP 判断是否配置相机，保存前自动读取序列号，不提供来源选择步骤；新站默认海康原生识码，已有配置不自动修改。
2. 每台相机填写实际 IP 和唯一的 RCS 相机编码；序列号按 IP 自动读取并随设置保存，取格口与心跳共用编码。未使用相机时清空 IP。识码方式在相机高级设置，已有配置保持不变。
3. RCS空地址为待配置，有地址必须完整；缺RCS不能取格口。人工键盘/PDA是独立来源，不要求相机已配置，但仍受RCS、容量及原责任守卫。
4. 核对保存结果；条码规则、相机参数和RCS连接参数在符合条件时立即生效，只重连改动设备，另一位继续供包。尚未离位的未决作业、在途调用、待提交回执及设备维护等会阻止即时生效。先按提示处理当前责任，再重新打开以激活待生效设置。已离位并收口的历史未确认记录可在“记录”查看。新相机 IP 先成功读取序列号才允许保存；保存后重连失败会显示离线，配置生效不等于已连通。
5. 按[作业卡](quick-guide.md)核对首件，真实采图、识别、RCS传输、业务结果分层记录。

格口默认由 RCS 分配；需要指定格口时，在左右位共用设置中明确选择并填写完整格口编码，实际结果仍以 RCS 回包为准。冻结原请求保持原参数。

两侧分别执行空盘校准：确认本位没有当前轮次、真实画面为空，打开管理中心“设备与诊断”的本相机详情，明确点击“确认空托盘并校准”，等待多帧稳定结果。管理中心打开期间暂停自动供包及识码，保留连接和预览；关闭后按当前 RCS、启停和暂停状态恢复。重启、重连及尺寸变化使参考失效，需要重新校准，不能把新会话第一帧当作空盘。校准失败、曝光异常、连续性不足或包裹视觉差异不足时按人工降级；超时可原位 PDA 补录，人工/PDA失败先取下再点击本轮“已取下包裹”。可靠视觉仍在位时补录成功不触发3秒结束；纯手动或视觉不可靠时才适用成功3秒恢复，持续原包自动读码仍被抑制。用真实小件、同色、透明反光、遮挡和连续无空盘间隙样本验收，降级可用不等于全自动合格。

完成页“各来源情况”逐项列出左右相机、RCS 和人工输入是否已填写、下一步处理什么，不会显示“可以开始供包”。“检查网络连接”只检查网络能否到达相机地址（ping）和 RCS 地址（建立连接），每项最多10秒，不连接相机、不发送取格口请求；相机不回应ping不一定离线。改动地址后旧结果作废。相机身份、采图和RCS心跳在保存并启动后确认；真实试单走调试页的明确“发送”。四类参数仍编辑同一完整候选；发生并发修改时重新核对，不覆盖其他窗口。

## 管理模式与忘记密码

管理模式与操作员身份、Windows安装权限分别管理。普通模式仅作业/记录，管理模式开放设置/日志/调试。会话15分钟，最后两分钟可从菜单续用15分钟；到期、退出、改密或重置撤销原授权，未保存草稿保留但受限。

忘记管理密码：打开“忘记管理密码？”→输入并确认新密码→Windows管理员授权→核对本站标识并确认重置→使用新密码重新进入。没有共享根密码，也不把Windows管理员身份当成日常管理模式。服务缺失/损坏先修复同源安装，不能删除凭据文件当作首次设置。

重置报错后先“核对上次重置”；如果尚未完成且确认仍有效，等待后再核对。只有服务确认旧请求已完成或旧确认已失效，才能结束原次处理或重新发起。重置不改操作员、相机配置或原请求责任。

## 卸载

1. 关闭供包台的全部窗口，从 Windows“已安装的应用”进入卸载。
2. 选择“保留本站数据”或“同时删除本站数据”，默认保留。删除会移除本站配置、记录、图片和日志，不可撤销。
3. 点击“卸载”，完成 Windows 管理员授权，等待结果。两种方式都不备份、不检查业务请求状态，不需要业务密码或输入确认文字。供包台未完全关闭时提示先关闭，不执行卸载。
4. 完成后关闭窗口。有文件被占用时，关闭占用程序并“重试卸载”；原清单自动继续，不需要原安装包。旧卸载已登记的重启清理仍按原回执提示处理。

卸载使用安装时的受保护文件清单，程序目录已删除仍能完成核对。新版完整安装包也可清理旧安装余项。卸载自身结果未确认时先“查看结果”，不能重复提交；能证明尚未提交的原卸载会在下一次执行时自动处理。

关闭供包台不会把请求记录改写为已完成。选择保留数据时原样保留，选择删除时按本站目录清单删除；共享驱动、安装回执和本站以外的备份保留。卸载窗口不提供恢复、版本回退或版本清理。

## 完整备份与恢复

备份包含数据库及同名`.recovery`配套恢复目录，以`COMPLETED.json`及完整文件集合/哈希为准。单个数据库文件不是完整恢复集；不得复制正在使用的db、删WAL或改格式号。

计划辅助状态损坏或写回失败时停止该计划并明确告警，供包与其他维护在业务存储正常时继续。维护人员先保全备份计划状态文件（backup-schedule.json）和该次写入残件，核对最近成功恢复集，在软件完全关闭后移走故障辅助文件，再打开重新建立计划；不要手动改成功状态。未启用计划不读取残留辅助文件。只有 BackupCreated 表示完整集已创建；拒绝、取消、失败和结果未确认均保留原原因及上次成功信息。

备份目标写入或副本核验失败仅表示本次备份失败，保留回执和残件，不生成完成标记或更新最近成功；先检查目标空间、介质和权限。确证源业务库或源文件损坏仍执行原存储保护；来源无法确定时保留原错误供维护核查，不能凭异常名称判断源账已坏，也不通过清库绕过。

恢复使用现有维护入口和新隔离目录，核对原机退役、机器身份、RCS范围及实体交接后才按原政策启用。备份不能撤销已发送的外部效果。程序回退不能把旧数据库覆盖到当前根；数据不兼容时保留原件并联系实施人员。

新站日志/已结历史默认7天；保存保留策略不等于已执行清理。只处理符合条件的已结历史，历史未确认请求及永久请求身份仍保留。当前作业容量只用于正在处理或尚有当前责任的作业，磁盘保留空间仍独立核验。

## 故障与交接

按[故障目录](fault-codes.md)处理；主句说明发生什么，下一步必须说明包裹怎样安置。记录版本、带时区时间、本位、原作业/操作ID、已知及未知事实，按现场批准渠道交接。当前RCS没有权威结果查询，不用替代POST假装查询，不盲重发。

日志需管理模式，查询/导出范围固定。管理模式下可从“设备与诊断 → 维护工具”导出诊断包；取消按钮仅在导出期间显示。本版本隐藏帮助按钮和菜单，F1 不打开帮助；离线手册由实施人员交付。选择D盘上程序/配置/数据目录之外的新ZIP路径，导出后核对文件。诊断包仅含白名单摘要，不是备份，不包含原始日志正文、业务库、条码、图片、凭据或原报文；当前包的manifest标为Partial，界面也提示“含未收集项”，说明24小时日志覆盖不能证明完整。安装项包含登记摘要，以及安装、静默部署、卸载、回退、旧版本清理、永久删除每类最近一次回执的状态、时间、动作和退出码，不含路径、账户、哈希或文件清单。技术支持按清单缺项继续核查，不能把“没有摘要”当作“没有异常”。取消、失权或校验失败不发布完成文件。离线帮助内容及页面实现保留，但不作为当前可见入口；实际版本与验证边界按本次交付分别记录。

## 验收与支持

构建、合成端口、Windows原生、系统安装、真实SDK/客户RCS、目标IPC及现场分别记证。正式发布者/证书、系统矩阵和真实设备/接口材料不足时保留未完成状态。支持联系人由实际获准资料提供，本手册不填虚构电话或邮箱。
