# 供包员作业卡

开工先看要使用的左位或右位。两侧独立显示车号、扫码资格和本件结果。

1. **看到“等待投包”再放件。** 把包裹条码朝上放入本位托盘。看不到有效车号、RCS 离线或本位停用时，按本位提示处理。设备危险时按现场安全流程操作，软件暂停不能代替安全急停。
2. **读不到码时先调整朝向。** 本位允许补录时，点击对应相机区域，或按 F2 选左位、F3 选右位，再用扫码枪或键盘输入。相机离线时也按本位提示判断是否可补录。
3. **只看本位、本件的有效格口。** “上一件格口·仅供查看”只供回看。约三秒后格口撤下，仍须确认包裹实际取下或小车已经更换。原请求已确认且本位允许扫码时，同车也可继续下一件。
4. **被拒绝或读到多码时，按提示取件。** 托盘可靠判空后自动结束本件。若画面无法判断且出现“已取下包裹”，先取下，再点本轮确认。
5. **看到“请求待核对”，保留包裹和记录。** 取下暂放一旁，打开“记录”找到本次作业，请维护人员核对原请求。不要重扫、启停或换车尝试再次发送。

相机提示“未校空盘”时，异常件取下后按本位提示确认。请管理人员停用该位，在独立运维工具查看实时画面，确认相机在线、无当前轮次且托盘确实为空，点击“确认空托盘并校准”，校准完成后重新启用该位。另一侧可继续供包。运行判空须至少 3 帧、默认连续 300 ms，校准须至少 3 帧、连续 800 ms。

故障处置见[故障目录](fault-codes.md)，设备设置和恢复步骤见[实施手册](implementation-guide.md)。
