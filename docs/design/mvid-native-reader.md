# SM 海康原生识码

每台相机在“设置 → 左右相机 → 识码方式”选择软件识别或海康原生识码。已有配置默认软件识别；两台相机可以分别选择。保存沿用完整配置草稿、版本防覆盖和原有即时生效守卫，只重连修改的相机；未确认请求等条件下仍要求保存后重启。不自动回退，也不让两套 SDK 同时打开同一相机。

## 数据与业务责任

原生路线为相机 → `MVIDCodeReader.dll` → 同帧原图、条码及四角位置 → C# 码制筛选 → Application 条码规则、放置判定和 RCS 请求。参考旧供包台使用的 `MVID_CR_*` 接口，固定版本 `1.1.4.0_3.6.0_2.2.2`，不是仓库旧驱动的 `MV_CODEREADER_*` 接口。当前只接入 Windows x64、GigE、连续采集和紧密 Mono8 原图。

原生输出的图片属于 SDK，下一次采集前复制；条码、框和图片使用同一次输出。应用不释放 SDK 私有图像指针，销毁句柄成功才释放相机占用。停止采集失败继续尝试销毁，销毁失败保留占用，不伪报停止或自动重开。

原生库已经完成识别，结果在采集线程按顺序处理，不经过可覆盖的“待软件解码帧”槽。等待原图容量时停止，也保留已识别输入的身份与原像素，阻止该源重新启动；释放 SDK 不代表输入已经交付。放稳时间只控制结果进入业务的时机，放置过程仍更新预览；持续不稳时保留约 1.5 秒一次的接收机会。该路线不会降低原生库内部的识别频率。

不按条码文字去重，不丢弃 SDK 标记已过滤的候选。两处真实同码仍保留两个框、进入多码拒绝。码制选择是在原生结果返回后筛选，不会缩短 SDK 内部识别时间；反色搜索选项只适用于软件识别。列表饱和、非法长度/编码/位置等拒收整帧，不截成一个可提交条码。有效原图仍用于预览及漏读画面比对。

同一次放置只请求一次，静止包裹的漏读与识别失败保持原作业卡；相机会话改变后必须重新读到码，才能恢复同一次放置的原结果。空托盘、换码、重连、人工输入及 Unknown 原请求继续由同一个 Application 实例处理。

## 安装依赖

仅安装 MVS 不足以启用这条原生路线。实施人员需要包含匹配 MVIDCodeReader 组件的完整安装包、匹配的 x64 VC++ 2008/2010 运行环境及相机传输驱动。操作员不需要启动额外的读码程序。缺少组件时相机明确报错，软件不会自行寻找旧客户端目录或换用另一识码方式。

打包入口 `scripts/package-application.py --mvid-runtime <已获授权的本地运行库目录>`，也可设置进程环境变量 `IPC_MVID_RUNTIME`；这是现有 MVS 构建输入之外的可选输入。目录必须有固定清单中五个 DLL 及原厂告知文件 `SDK-NOTICE.txt`。脚本逐项校验长度、SHA256 和 AMD64，全部成功后写入 `app/desktop` 的 `vendor/hikrobot-mvid`。仓库只保存清单、接口和自行编写的配置，不包含厂商二进制或客户资料。

配置文件由项目提供，关闭 SDK 工作目录日志。SDK 及工作目录配置仍须通过现有受保护安装目录和文件完整性检查。运行库不可在进程中更换版本；更新用完整安装包及正常停止/重启流程。未提供原生构建输入的包保留软件识别能力，不能用于原生路线的现场验收。

诊断中的原生识别时间来自 `GetOneFrameTimeout` 调用耗时，包含等待图像，不能与 ZXing 纯解码耗时直接比较。

## 调试

现有 RCS 调试继续使用生效配置，明确点击发送才增加独立请求。相机调试复用当前 MVID 会话的原图、条码及四角位置；锁定调试图不停止正常供包，也不换成后续帧。开始/结束采集沿用 Application 权限和同源守卫。原生 ABI 没有软件路线的清缓存接口，适配器通过有界的零超时读取确认队列已空；无法确认则明确失败，不假定切换成功。这项原生队列行为仍需真实相机验证。

## 验证边界与入口

- `--mvid-reader`：合成原生帧端口，真实 Application、SQLite、环回 RCS；验证两处同码、放稳、漏读保持、防重、重连、空托盘释放及销毁失败。
- `--hikrobot-sdk-editing`：配置模型和 Windows WPF 设置页验证，包含两台相机独立选择及完整草稿保存。
- `python -m unittest discover -s scripts -p test_mvid_runtime.py`：用合成 PE 验证打包清单与失败边界，不含真实 SDK。
- `--mvid-runtime-probe`：在受保护安装目录中验证真实 DLL 版本与两个独立句柄，不绑定相机。开发目录运行会被安装权限检查拒绝，不能据此跳过权限检查。

本机直接 ABI 探针已验证旧项目运行库的版本、两个句柄创建和销毁、设备枚举（发现 0 台）；受保护应用加载探针在开发目录被 ACL 拒绝。真实相机绑定、采图、原生识别效果、拔线重连、安装交付、客户 RCS 与现场连续运行尚未验收。模拟通过不代表这些项目通过。
