# 参数与首次启动的当前规则

SM只运行当前schema3配置和DB14。覆盖安装与数据可打开性分别核对，保留原配置、DB/WAL、原请求、回执与永久编号；本阶段不增加旧格式运行或迁移。历史证据只属于其原来源提交，当前字段归属和保存契约见[参数归属](parameter-inheritance-02.md)。

首配按“本站与RCS → 左右相机 → 识读规则 → 检查与完成”组织，维护及本机显示采用明确默认、按需展开；草稿可保留，保存前核对全部有效字段。日常沿同一完整草稿编辑，按常用、相机、维护与高级分组。字段共用名称、单位、范围、说明和错误定位；高级字段报错时展开并定位，不能出现无法修正的隐藏错误。

新站默认MVID原生识码，保留明确选择的MVS＋ZXing，不回退。相机分别填写实际IP与唯一RCS编码；保存前只枚举该IP并读取只读序列号，失败保留草稿。管理中心打开暂停自动供包和识码、保留预览。开工前确认本位无当前轮次且托盘为空，明确校准；重连、重启和尺寸变化后重新校准。未校准或未知图像不证明空盘，人工降级不算全自动验收。

自动识读默认1000ms、100～60000ms，放稳时间消耗期限，不续期；超时可原位PDA补录。RCS取格口独立默认1000ms、100～30000ms，连接/发送/正文共用一次冻结期限。排除码不证明空盘；超时不自动重发，不要求直接重扫。原轮次、在途请求及晚到结果仍按[轮次契约](../design/sm-parcel-rounds.md)处理。

业务配置保存核对管理授权、完整候选和原修订CAS，按实际差异热生效或待重启；失败保留草稿，结果未知核对原次保存。效率显示、窗口方式与提示音按当前Windows用户独立保存，共用未保存状态、底部保存与关闭保护，试听不保存。分项失败如实报告，重试不再次提交已成功的业务配置。

维护设置集中呈现归档阈值、日志最长保留时间、已结记录清理期限、自动清理开关/执行状态及备份上限。关闭不宣称已自动清理；备份达到上限停止新增，不自动删除旧份。保留手动清理及所有原责任、完整备份和存储守卫。存储根沿安装登记，用户偏好只写所属用户目录，不修改全机ACL。

验证必须绑定本次提交，分开记录编译、完整回归、实际分支采集、原生Windows/DPI、真实SDK、客户RCS及现场验收。未采集/不可覆盖文件和分支明确列出原因；局部行覆盖、合成设备和截图不替代全分支或现场结论。

启动修复与首配是不同任务：首配仍按四步完成配置并由启动流程继续；离线修复按“目录与工位、设备与参数、检查与启动、恢复与维护”直接导航，不设独立说明页，不用无动作的维护按钮。检查页明确保存/启动或核对原保存结果；恢复页按预检、执行、核对原结果及换机接管呈现，不再提供向前/倒退式“下一步”。恢复完成不自动启动。

整窗动作固定在右对齐底栏，字段及预览独立滚动。取消、Esc和×共用实际草稿保护；偏好/业务部分保存继续分项核对，重试不重提成功项。界面仅隐藏且原草稿仍保留时不提示放弃。首配导入预览与修改查看有明确Owner、默认取消和执行条件；输入错误定位仍回到原字段。

首配最终完成及重试启动先等待本窗维护服务真正释放，再返回确认结果；释放失败保留同窗、原服务和已保存候选，重试不重复提交已成功的业务配置。恢复计划检查和按原计划执行是恢复页的固定底部动作；路径修改立即撤销原计划，未检查或检查失败不能执行。检查是只读动作，恢复和换机接管不设为默认回车动作。
