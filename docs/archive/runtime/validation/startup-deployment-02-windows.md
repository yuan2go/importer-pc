2026-10-20 新候选及定向核验见[main cfe6c0e 交付](../unified-release-main-20261020.md)。Windows 主机编译、媒体/架构、只读门禁和隔离夹具已单列；下表完整原生安装/UAC/ACL/账户/升级与人工桌面场景未验，仍 NOT_RUN。下文 Darwin 是原任务的形成环境，不是新构建主机身份。

状态：NOT_RUN。本机为 Darwin arm64；交叉构建/静态媒介核验不代替下列原生结果。用新冻结候选及独立合成数据留存 OS/SKU/build、账户 SID/令牌、SourceCommit、ZIP SHA、操作回执与截图；不采集凭据/生产数据。真实 SDK/设备/Production 资格另验，不用参考模拟关闭现场 RV。

|场景|必须观察的结果|
|---|---|
|干净机普通用户，双击 Setup.cmd / 首次 application.cmd|四步向导显示正确 Application/来源；不要求 PowerShell、手工策略、目录、JSON 或 hash|
|当前用户为 UAC deny-only 管理员|安装提升一次，正常运行未提升；程序可执行、政策只读、数据可写|
|标准用户通过另一管理员凭据授权|策略及新目录仍绑定所选运行 SID；提升进程不启动业务；原用户能通过开始菜单运行|
|选择另一已有账户且无既有数据|摘要清晰显示共享数据位置；安装成功后提示登录指定账户，不用安装管理员运行设备|
|取消 UAC、错误账户、坏政策及存在租约但政策缺失|明确原因、可以重试；旧政策/租约/数据保留，不自动换 SID 或删除材料|
|损坏/缺失 app 或 desktop 文件、额外 DLL、链接/重解析点、媒介复制中变化|完整性门禁拒绝，不提交新部署登记；旧快捷方式可继续指向旧程序|
|受保护目录的所有者、继承 ACL 与运行账户执行权|程序/策略/信任所有者为 Administrators 或 SYSTEM；运行用户 ReadAndExecute，不能写程序/政策；新数据根可修改|
|安装进行中在复制、种子发布、扩展登记、快捷方式和最后提交前终止|旧登记/原数据不变；新部分输出及操作记录保留，再次安装并排生成新目录；不运行部分安装|
|并发安装与原应用仍占用|安装登记互斥；原应用所有权未释放时拒绝切换，不强杀线程或删锁|
|升级相同/新来源|已有 seed/Effective/Pending/DB 字节不被安装覆盖；开始菜单含新版本入口，桌面/控制台/脚本读取相同部署位置|
|种子损坏后明确选择匹配身份的配置并勾选并排种子修复|新种子独立目录；旧损坏种子保留；数据账不覆盖，模式/站不被默默改变|
|无扩展部署，或库存/信任损坏|内置配置和维护页可读，独立诊断可见；绑定的真实扩展仍拒绝保存/启动，Production 不降级|
|批准的独立信任与签名包，含依赖|自动算 hash、静态签名/合同/依赖校验，不加载模块；失败保留扩展操作登记，安装成功不表示激活|
|Production 选择测试信任或私钥材料|安装拒绝；不生成/重写信任，不复用旧宿主资格|
|配置/能力启动故障|真实阶段/诊断可见；Stop/Dispose 成功后可进入离线维护；失败清理仍占责任，不创建第二实例|
|通过失败页、Maintenance.cmd、开始菜单启动修复|均不要求业务 Start 成功；可选原配置/数据目录、编辑已知参数、校验、原因保存和导出摘要|
|离线保存：原应用占用、旧 hash、无授权、非法身份、DB2～6|分别明确拒绝；不改原配置/DB，旧草稿不覆盖新账；无权限时不创建根|
|离线保存成功，随后同时有其他维护修改|同一配置账 Pending/CAS；精确原字节/审计保存；读回候选与状态匹配，否则显示再次变化；不把保存当生效|
|离线 DB7 检查，包括非空 WAL|仅打开临时 DB+WAL 副本，原 DB/WAL/SHM 的字节及文件集合不变；临时卷容量不足明确失败|
|原账损坏、完整备份缺伴随目录/COMPLETED/hash不符/容量不足|坏原账只读保留；恢复预检拒绝，不创建目标，不换空账|
|完整备份预检及授权恢复|预检无写入；原实例必须释放所有权，固定 DB+COMPLETED 后再次校验；恢复新目录，不覆盖原根；界面自动读取新根|
|恢复后重试、Pending 激活中故障、停止未完成|隔离恢复/原请求/旧报文/数字范围及 Production 守卫保留；不会自动 Resume/重发；停止责任完成前不能重试新实例|
|不同 cwd、带空格/中文路径、DPI 100/150/200%、键盘导航|入口定位同一配置/数据；错误及固定操作区可读，滚动内容不遮动作，敏感参数不直接回显|

程序移除仍只允许明确选定的已停用版本/快捷方式，按原交付指南保留全部数据、政策、租约、信任、Store 和备份；本包没有自动清除业务资料的卸载动作。
