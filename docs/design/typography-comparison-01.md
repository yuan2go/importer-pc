## 三组与验收条件

- 基线：前置 PR97 `a43ecb8` 的实际生产程序集与原排版。
- 候选 A：本包语义尺度及必要布局，界面恢复 Microsoft YaHei UI / Segoe UI 系统回退，标识保留 Consolas。仅测试夹具替换 family，明确标记测试覆盖来源；不新增生产设置。
- 候选 B：相同尺度/布局，正式应用内 Noto 400/500，标识仍 Consolas；不覆盖生产字体属性。

基线→A 用于识别尺度/布局整体效果；A→B 控制尺度、字重请求和布局以比较字体。它不能把字号与布局再各自拆成独立因果，也不能凭截图证明人类辨认速度。固定合成内容、不使用客户原稿和现场数据。实际有效客户区、系统缩放、控件 Text、字体来源/实际字重、GlyphRun 和几何随每次采集保存。代码/夹具来源分别记录。

预先验收：预设关键文本逐字一致；字形不含 .notdef；Regular/Medium 真正解析到指定文件；有效格口优先且非有效结果不呈现可执行格口；关键条码首行与操作可达；长文本可选择复制/滚动；参数焦点/草稿和查询虚拟化保留；展开后至少一完整结果行。拒绝靠缩小全局字号或隐藏原请求责任换取 PASS。
