# 桌面名称与过期测试资源清理

2026-10-20用户要求卸载已安装测试应用、清理过期测试资源，随后明确桌面只显示“菜鸟供包台”。继承单窗口安装分支9abc6cb与最新main12d20b2，不覆盖共享工作树或并行UI设计。完整源码追溯保留在BUILD-INFO、部署登记与版本专用开始菜单维护入口。

本包只调整桌面快捷方式命名及对应升级/卸载机制，不修改WPF页面或移植UIR设计。桌面固定菜鸟供包台.lnk；新登记提交后才能切换稳定入口。仅允许替换同一应用/账户/数据根的已核验旧部署入口，用户改指向的链接保留。历史长名称仍按精确旧target/arguments清理，旧版本卸载不能删新版稳定入口。必要验证为实际隔离Windows COM的名称/更新/冲突/旧卸载保护、构建及最终冻结包准备冒烟；未执行项如实记录。

清理只针对有原部署/本机合成测试证据的测试程序、精确目标快捷方式及本轮过期构建缓存；逐项检查绝对路径边界、重解析点、清单和在用进程。保留用户工程、最终交付、Git/原始验收证据、配置与数据/备份，不把宽泛目录匹配当删除授权。机器程序残留须Windows授权；不代替用户确认UAC。真实设备/生产数据/现场资格及旧D/RV不变。
