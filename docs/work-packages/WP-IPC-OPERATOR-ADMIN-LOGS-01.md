日志仅来自既有软件轮转文件，流式、有界、后台查询，显式正则与超时，不执行shell。分页不限制全量导出。稳定源定位核对原行及前后原始记录，轮转/清理明确缺失；原始异常栈保持，敏感值统一遮盖。导出临时文件提交、取消/失败删除部分文件，权限撤销停止。
