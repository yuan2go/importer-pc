# QUERY-FILTER-UX-01

2026-10-27 用户针对作业记录与日志查询提出：条件排列混乱、时间内容难懂、日期/时间框异常。本包接续 PR129，main 基线仍为 d0a06313；PR127 版本、PR128 驱动/日志保护保持独立。

本轮覆盖旧视觉方案中“显式 UTC 偏移默认可编辑”、默认长 ISO 摘要及过矮时间筛选滚动区的呈现条款。普通查询以本机日期时间呈现，起止端点含义用一句话说明，精确带时区时间按需展开；原时间值、查询冻结/分页/导出、管理权限、失效输入拒绝和已选原作业责任保持。历史指南与证据保留原适用范围。

实施：共用 DateTimeInput、HistoryPage、SoftwareLogControl；不另建查询服务。验证需覆盖非本地偏移/毫秒保真、非法日期/时间、日期纠正、夏令时歧义拒绝、快捷范围、已应用与待查询区别、导出失效、标准/最小原生尺寸、焦点与草稿。用户截图不上传，真实现场与触控仍待验。
