# 安装、启动、配置与卸载

适用：当前 SM 1.0.0。操作规则见 [AGENTS.md](../../AGENTS.md)，现场步骤见[实施与维护手册](../operator/implementation-guide.md)。历史介质及验证记录位于归档，不作为当前操作步骤或本次验收证据。

## 安装与普通启动

1. 使用可信同源完整安装包，核对版本、来源提交和哈希；程序、数据及缓存使用 D 盘。已有站沿原安装登记，不换空目录绕过原责任。
2. 安装采用三步主流程，核对选项、点击安装并完成 Windows 管理员授权，等待实际回执。路径及技术过程在详情中；安装完成不代表设备或 RCS 已就绪。
3. 打开软件后自动检查并启动。首次配置保存后自动启动，无需另点“启动”；首次配置未保存就关闭则退出。条件不满足时显示具体原因、重试和修复入口。
4. 启动失败页和维护结束页的标题栏关闭与退出按钮执行同一停止流程。资源真正释放后退出；停止失败显示原因并允许再次关闭。

安装或维护结果未确认时保留原操作，先查看原结果，不换操作编号重复提交。首次设密、密码重置、修复及离线维护使用安装器登记的同版受保护维护程序。普通启动不要求 Windows 管理员权限；管理模式是临时授权，每次执行受限动作仍核对权限。

## 安装续办与上一部署回滚

重新打开完整安装器或“安装/修复”时，先从受保护原记录发现尚待办理的安装，展示原来源提交、目录和阶段。未开始可重新操作；已证实未提交先结束原次再重新审阅；已提交但系统入口未完成只修复原登记；已完成查看原结果；缺失或冲突保持待核实，不生成新编号掩盖原责任。当前登记已被后续卸载或重装替代时，原操作只读显示已取代，不能重新启用退役目录。关闭、异常退出或重启不改变这些判断，取消授权和实际失败分别说明。续办仍核验停机、权限、介质及所有权，不读写业务库或要求业务清场。

原次未提交的收口与已提交的入口修复均使用受保护原请求，替代介质必须是完整且同来源的当前介质；不依赖上一次解压目录仍存在。已完成再打开默认只看结果，不自动启动；再安装须明确返回重新审阅。证据冲突不能靠换操作编号重做。

离线“恢复与维护”提供上一部署回滚的预检、明确执行、原结果核对及系统入口修复。目标仅为登记的上一部署，展示当前和目标的1.0.0版本及完整来源提交；同版本不同来源允许，目标程序或维护库存已被卸载清理、缺失、不完整或不能读当前格式时拒绝并说明原因。完整备份和原责任按既有围栏核验；历史保管 Unknown 不因未知结果单独阻止，实际执行、待提交回执、身份冲突、存储保护和未释放资源仍阻止。只切程序，不恢复旧库或配置，不重发请求；结果待确认沿原次核对，不重复提交。

## 首配与日常设置

按真实站点填写仓 ID、生产线 ID、供包台编号和左右 RCS 相机编码。每台相机填写实际 IP，保存检查前按所选识码方式只枚举该 IP 并读取唯一物理序列号；序列号只读，不手填。未找到、身份冲突或 SDK 释放失败时保留草稿并拒绝保存。不用的相机清空 IP 及对应序列号。新站及首配默认海康原生识码，已有配置不自动修改；软件识别仍可在相机高级设置中明确选择，两种方式不同时占用同一相机，不自动回退。

SM 只使用内置 RCS。地址留空表示待配置，填写后必须完整校验；默认由 RCS 分配格口，也可选择指定格口并填写完整编码，以实际返回为准。请求编号由软件持久分配，重启不复用，不配置编号范围、本地模拟或连接方式。人工键盘/PDA 是独立来源，不要求相机在线，但仍受 RCS、共享存储及原请求守卫。

系统、业务、驱动和组件共用一份完整草稿及配置账，按版本号防并发覆盖。条码规则、相机参数和 RCS 连接参数保存后在条件允许时立即生效，仅重连改动设备，另一位继续供包；有尚未离位的未决作业、在途调用、待提交回执或设备维护时，可保存为待生效；处理当前责任后重新打开。已离位且收口的历史未确认请求可在“记录”查看。其他设置及混合修改保存后重启生效，失败保留原配置。新地址先取得有效序列号；此后重连失败可保留已生效配置，该位显示暂未连接并自动恢复。

管理中心打开时暂停自动供包及识码，保留相机连接和预览；明确触发调试才识读，明确点击发送才新增调试请求。关闭后按原启用、暂停及当前 RCS 状态恢复；到期锁定管理页并保留暂停和草稿。忘记管理密码时由 Windows 管理员核验本站一次性重置，不删除凭据文件、不使用通用验证码。

自动物理分轮前，管理人员确认本位没有当前轮次且托盘为空，明确执行空盘校准，等待稳定多帧通过。重连、重启和尺寸变化后重新校准。首帧、无码和条码变化都不证明空盘；未校准或视觉未知时按人工降级处理，成功后3秒恢复显示不证明物理离位。可靠视觉建立的轮次经 PDA 补录成功后仍等待可信移出；人工/PDA失败按本轮“已取下包裹”确认，不用视觉代替点击。

## 日常作业、记录与诊断

普通导航为“作业、记录”；管理导航为“设备与诊断、设置、调试、日志”。本版本隐藏“异常处理”“统计与班次”和帮助入口，F1 不打开帮助；离线帮助内容和页面实现保留。不要求操作员登录的站点不显示登录标签。

打开软件到正常关闭为一个班次。作业卡只显示托盘上这一件，软件重启不恢复上次读码或未提交条码。一次放置只请求一次，断线重连后同码仍沿原结果，不盲目重发。结果未确认的作业保留原请求、报文及目标；查看提交结果不等于重新向 RCS 查询，当前内置 RCS 不具备权威结果查询能力。

记录页点击状态打开详情，点击详情外或按 Esc 收回。详情内复制、滚动和维护操作不收回；不提供交接文本或复制交接信息。技术原文保留在日志、技术详情和诊断证据中，操作员提示说明状态、原因和下一步。软件暂停不是安全急停。

设备状态自动刷新，相机断线自动重连，切页不重建设备或作业。诊断页只设“技术详情”和“维护工具”两个折叠区；管理人员从维护工具导出诊断包，取消按钮只在导出期间显示。包是白名单摘要，不是完整备份；未收集项如实记录，文件只保存在本机。

日志默认关键事件。快捷范围“最近1小时 / 今天 / 最近24小时”每次查询更新到当前时刻；手工范围保持不变。查询、翻页、详情和导出沿同次已应用条件，取消或失败不把旧结果冒充新结果。原文在详情及导出中保留。

## 卸载

1. 完全关闭供包台，确认资源所有权已释放，从 Windows“已安装的应用”进入卸载。
2. 只选择“保留本站数据 / 同时删除本站数据”，默认保留。删除将移除本站配置、记录、图片和日志，不可撤销。
3. 点击一次“卸载”并完成 Windows 授权。卸载不创建备份，不检查业务请求是否完成，不提供恢复、版本回退、版本清理或额外输入确认。
4. 卸载自身结果未确认时先查看原结果，不能重复提交。可核验的未提交卸载及原清单余项自动处理；文件占用解除后沿原清单重试，程序或数据目录已删除不影响重试。

关闭软件不改写业务请求结果。软件内离线维护的卸载入口先核验并启动当前安装绑定的独立维护缓存，再退出原宿主，避免宿主占用待删除 DLL；启动失败保留原窗口供重试。程序余项未清完时，不宣称数据已删除，关闭占用程序后沿原清单重试。按受保护原清单处理本站配置与数据目录；共享驱动、管理安全锚、当前 Windows 用户显示偏好、受保护安装回执和本站以外的备份保留，不手工递归删除未知目录。独立维护缓存沿当前安装记录、清单和受保护权限核验，不要求操作员批准目录或调整权限。

历史程序与维护缓存使用单独的受保护清理回执：逐份核验安装库存、程序描述、路径边界及实际待删字节；删除前在机器安全回执目录保管原库存。清理后即使缓存已不存在，也能核对原范围和重试，禁止换清单扩大删除。本站数据已删除并不代表历史程序与缓存已清完，结果页分别说明；未知文件、不可核验库存及其他安装引用均保留并列出，不静默跳过。

从完整安装包执行时，维护宿主不在缓存内，可直接删除可核验缓存。从缓存运行时保留当前宿主全部文件，仅对冻结缓存清单登记 Windows 重启清理；不自动重启、不把排入队列算成已删除，实际路径消失后才算完成。队列按文件、深层空目录、根目录顺序登记；[Windows 只会在目录为空时删除它](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-movefileexw)。共享系统运行库、管理安全信息、个人偏好、安全回执和站外备份保留。

## 备份、恢复与验证边界

恢复入口可直接读取完整备份中的原站点、模式和配置身份，不要求先完成首配或创建空业务库。恢复准备、隔离副本完成、已接管和结果待核实由原恢复标记、受保护部署登记与交接证据重建，关闭重开后继续原次；不覆盖未知目录、不把复制完成当成投产。运行中备份在正常停机后允许有可核验的班次关闭等生命周期差异，必须逐项核对，不忽略新增业务、原请求及回执变化。

清理卸载后的重装可凭完整备份、本站退役/数据清理回执及机器安全身份接管，无须找回已删除原目录。保留备份全部请求、Unknown、防重和已分配编号，并核对可证明的编号高水位，不自动重发或重编号。接管后仍保持隔离及暂停，明确核对原实物与RCS外部效果后启用，不自动开始作业。本站数据 Purged 与资产清理分开：旧缓存待重启不阻止独立新部署；不得把新程序、缓存或恢复数据加入旧清单，也不能用新部署继续旧卸载。

独立卸载入口按原宿主的进程号与启动时间等待其实际退出，最长15秒，不能仅凭创建子进程或业务资源停止判断 DLL 已释放。等待或缓存核验失败只提供卸载重试和关闭，不进入业务启动或另建数据目录。

卸载之外的完整备份与恢复由管理维护流程处理。完整恢复集包含数据库、同名恢复目录及完成清单和全部文件哈希；单个数据库不是完整备份。不复制运行中的数据库、不删 WAL、不改格式号。正常运行只接受 DB13；同版本覆盖安装不代表旧数据可由新版直接打开，不提供旧格式迁移或离线接续，见[当前格式规则](version-compatibility-01.md)。旧联调记录保留原来源，客户真实 RCS 启用前核对永久编号账与远端范围，不能从空库重新编号。恢复不能撤销已经发送的外部效果，启用前仍须核对原机、机器身份、RCS 范围和实物责任。

编译、本机测试、CI、Windows 实机、真实 SDK、客户 RCS、现场验收分别记录；历史通过不代表当前源码或当前安装包通过。

## 窗口动作与收尾

启动修复使用明确任务和动作身份，取消空说明/空维护按钮，不从中文标题或按钮序号推导权限、可见性和导航。目录、参数、检查/启动及恢复/维护直接可达；恢复末页不再向前循环。原参数读取失败仍保留原件，非当前格式不提供编辑或保存入口。

整窗动作采用固定右对齐底栏，内容单独滚动，低高度仍能看见当前主动作和取消/关闭。Owner、默认焦点、Tab/Enter/Esc及×按实际语义设置；退出默认取消和既有按钮顺序保持。启动失败/维护结束的×与退出继续共用真正停止流程，停止失败不能伪报关闭成功。完整备份是一个统一流程，入口名称与实际操作一致，取消保留原回执/残件，不把未知当成未发生。
