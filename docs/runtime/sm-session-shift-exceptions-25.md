## 运行和查询

成功打开一个业务实例建立持久班次，开始时间覆盖本次启动准备；完全停止、排空读取和发送并释放驱动后才正常结束。页面、布局、管理模式及多个共享窗口不切班；受控配置重启新建班次。停止超时仍持有资源，不记录虚假关闭。进程被终止后，下次取得原数据根独占时把上班标为Interrupted，保存发现时刻，不编造正常结束时间。上一班按数据库递增序号选择，系统时钟回拨不改变顺序。

正常班次时长采用单调时钟，包含软件暂停；未知终点不显示均速。UTC与单调时钟偏差超过5秒标记时钟变化，近10分钟速度不可用。今天及近7天采用已生效站点时区和完整分钟边界；均速只在范围内运行区间可证明时显示，不含关闭间隙。旧固定时刻配置原字节保留以兼容历史，SM保存契约拒绝修改固定时刻，不再用它决定当前班。

观察和请求是两类事实。一次送达应用的非调试相机有码观察算一次识别，人工输入不假造相机识别；同码独立观察不合并。连续空场帧不能推断包裹漏读。请求首次T1准备时固定班次，首次登记发送尝试计一个请求；重试/迟到结果只差量更新原请求所属班。Accepted且有格口才计取得格口；Rejected、Unknown/Conflict单列。所有次数均不代表物理完成件数。

P07默认普通模式可读。格口未确认每页最多100件，可逐页查看全部；另列保留明细中的最近50件RCS拒绝与最近50次识别/准入异常。计数与列表在同一SQLite只读事务读取，单次5秒/8MiB预算，页面2秒刷新不覆盖所选原身份，切页取消并释放计时器和订阅。宽屏详情在右侧，窄屏在列表下方。只读交接可复制，详情重新按原作业号读取。恢复入口要求管理模式并复用原请求守卫；没有原作业的观察不能执行作业命令。内置RCS没有Query合同，不伪造查询或重发接口；确认连接拒绝且未送达与未知送达严格区分。

P08本班、上一班、今天、近7天提供七项软件指标，按小时分别展示左右位取得格口，完整数值可在原生表格选择复制。图表最多显示最近24个有记录小时；明细/CSV最多31天和10万行，整班总数不裁剪，范围限制明确提示。识别/准入原因与RCS原因分别计数。页面不累加计数，主作业页也使用同一运行班次。目标只复用本机显示偏好，不控制供包；时区及自动清理复用完整候选/CAS/待重启生效，原历史保留和备份机制不变。

## 持久与导出

Parcel12新增运行班、不可变归属事实、分钟/班次/原因汇总。原事实变更与投影在一个SQLite事务提交；结果变化采用差量。清理删除事实明细而保留已计汇总，不重复累加。启动校验班归属、汇总与分钟一致及活动事实覆盖；异常保留原件并拒绝业务，不从已裁剪历史猜测重建。

普通运行只读核验当前格式及严格结构后才可打开写入。已知10/11必须走既有离线所有权、管理权限、完整备份/DB+WAL哈希、原身份和CAS检查，再事务升级至12；其他格式拒绝且保全原件。升级前统计及尚存原件归属显式legacy范围，不补造历史班次；原请求报文、数字请求号、原始回包、配置和历史审计不改。升级后保持暂停，按原流程显式核对恢复。旧程序不得读12；回退须使用经核验的升级前完整恢复集，不能只改版本号。

CSV仅传服务器签发的快照ID，缓存最多8个/16MiB/10分钟（单调期限）；返回数组被修改也不会改变所导原快照。保留原八个CSV标题；文件与JSON回执记录范围、班次、明细窗口、来源版本及文件哈希。导出不覆盖文件，配置和业务数据根内禁止导出，支持取消，临时文件失败清理。快照过期需刷新；普通只读导出不提升管理权限。
