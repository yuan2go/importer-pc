# 安装与首次配置入口 UI 02

当前九页版本见 [2026-10-22新增结果待确认页](result-unconfirmed-20261022/README.md)。它替代原未知结果的失败标题/颜色、默认展开的详情及关闭清理约定；下述八页原输入和原验收保持历史身份。两版涉及密码和使用范围的旧示例仍服从后续用户纠偏。

2026-10-22，本包以 [UI-SPEC](UI-SPEC.md) 与 [页面预览](Preview.html) 统一原生安装器及管理密码入口。两份输入从本地未跟踪交接文件逐字节复制，原文件保留；仅为截图设计参考，不证明安装、鉴权、设备能力。预览中的演示工具栏不进入产品。

本包仅替代旧 INSTALLER-SINGLE-WINDOW-01、V2 和 MANAGEMENT-MODE-01 中冲突的安装布局、首配授权呈现；沿用其事务、五步首配、单一配置账和管理服务权限机制。参数内页、业务流程、协议及历史证据不变。
