# 当前框架与职责边界

## 结构和选择时机

F-01/F-02采用C#、.NET10、WPF、SQLite、Windows x64的模块化单体。优先继承已获授权实现，不并行重建第二套框架。Product及Ipc.Assembly是显式装配根，构建时选业务和依赖闭包；基座不解释Supply、左右位或具体外部协议。不是运行时任意热插业务，也不先建设微服务、事件总线或传图平台。

| 层 | 所有权 | 不承担 |
|---|---|---|
| Platform/Runtime | 宿主、身份、租约、配置CAS、诊断、持久化和维护机制 | 业务状态、实体规则和客户批准 |
| Business/Application | 状态机、实体准入、业务账、命令守卫、资源生命周期 | 由UI替其裁决或替其重试 |
| Presentation | 版本快照投影、页面/布局、本窗编辑与焦点 | 设备连接、发送器、第二份配置权威 |
| Drivers/Adapters | 设备事实、健康、资源所有权、外部协议与结果证据 | 用协议成功代替业务接受或实体完成 |

公共契约不依赖DB、UI或根容器。一个业务实例服务多个页面/布局，切页不重建业务连接或取消原请求。业务拥有单一串行状态所有者；UI异步结果按代次发布，命令带Id和ExpectedRevision，执行时再次验证守卫和权限。

## 当前主流程

Sportmaster、DirectPlc、WcsToPlc分别拥有独立主流程；Supply及Inspection是独立参考装配。不能以SM不用为由删除其他业务的设备、协议或通用扩展。

SM使用内置MVS采图＋进程内软件识别和内置RCS，无PLC。每台相机配置真实IP/序列号及唯一编码，取格口与心跳共用编码，默认连续识别，各独立识别交RCS去重。TCP/MvCodeReader不在SM生产选装集合。显式Simulation测试可用人工输入或loopback夹具，但不能形成Production资格。

SM不加载外置扩展，也不要求其目录、独立信任或配置资格签名。内置代码仍验证安装完整性、实际SDK字节/ABI/物理身份及设备独占。外置扩展机制继续服务其他允许的业务：静态精确依赖/签名/独立信任检查先于加载，安装和激活分开，不扫描可写libs，不在提权安装阶段执行扩展；ALC不是安全沙箱。

完整SM配置可启用；相机未发现或失联只使本位离线并拒绝供包，RCS独立保持。重连复用原租约和新epoch，迟到回调不得越界；未交付输入、资源清理失败和普通连接失败分别处理。停止等待真实SDK调用和回调退出，超时不能伪报释放。

## 实体、请求与持久事实

观察不等于实体准入，同码不等于同实体。实体、作业、请求、尝试、原始接收发生、接受事实及物理完成分开。输入先建立持久责任；过载明确拒收，不能静默丢弃或凭同码去重。

T1冻结原请求、合同、目标、实现和报文字节；真正Execute/Query前持久预登记。原始回包先保全，T3与该次接收提交证明同事务；其他接收发生不能替它清责。Unknown不盲重发、不假造Query；当前目标、当前包和查询结果不能替代原始回包。接口无查询能力时保持阻断并要求合法人工核对，不宣称端到端恰好一次。

新请求准入、原请求恢复与维护清责使用各自明确守卫。管理操作记录主体、原因、原Revision及被处理责任；解除阻断不等于重发。可用性由真实守卫投影，已经发生的接受事实不因当前离线而改写。软件暂停不是安全急停。

当前SQLite格式在空目录一次建基线，已有数据先只读身份检查，非当前输入拒绝且不改原件。保留驻留/归档原请求、分配下限、完整性、独立接收责任及未知状态；不保留自有旧格式升级执行器。日志不是业务账，在线备份使用一致性边界，不能直接复制活动db文件。历史查询有可取消会话、受控并发和资源所有权，关闭/取消不能提前释放仍在运行的原生资源。

## 配置、权限与维护

系统、业务模块、驱动、组件四类参数编辑同一完整候选。schema、拓扑、参数、部署身份和资源验证共用Application；草稿、Pending、Effective与失败回执分开，保存按CAS，启动成功才确认Effective，失败保留原账并可受控回退。不用配置或数据库回滚撤销已发请求。

SM保存由Application临时阻断新准入并有界等待在途，不要求操作员手动暂停；到期保留原配置。未使用相机IP/序列号均为空，RCS空地址为待配置，部分配置拒绝。连接只读取Effective，候选不能成为第二份生效权威。

管理能力是临时管理模式，操作员身份独立，授权在真正执行时检查。机器运行身份在配置读取和持久资源前验证；日常运行、独立安装/修复/卸载及离线维护各有权限入口，不能用日常门禁阻断合法恢复，也不能让维护绕过原责任。

备份/恢复只接受当前格式完整集合；恢复目标新建且隔离，原根退役、机器身份、RCS范围与实体核对满足后方可启用。跨目录责任、租约、归档引用及未清输入不能通过新建空根逃避。程序修复/卸载保留运行数据及既有责任，受保护根只从管理员配置读取。
