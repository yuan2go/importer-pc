## 可执行原生烟测

先按仓库现行部署指南由维护者配置受保护机器策略/租约目录，并使用指定运行账户；不跳过MachineRuntimePolicy或ACL守卫。本分支烟测须覆盖standard及至少800×420 DIP的真实compact重排（例如1920×1080、100%缩放后逐步调整），再缩小到最低区以下验证保护；旧1280×680候选阈值不再限制本分支显示矩阵。具备 .NET SDK10.0.402 及Windows Desktop运行时后，从源码根执行：

```powershell
dotnet run --project tests/Ipc.Desktop.UiVerification/Ipc.Desktop.UiVerification.csproj -- .
```

此工程使用真实SportmasterApplication/ParcelCapabilityFactory和真实WPF资源，检查两套窗口创建/主题资源、历史与维护导航、辅助窗口共享Application/独立VM、关闭辅助窗不停止业务、主子重叠关闭、主窗停止失败保持窗口、重试只成功停止一次且不重启已关闭子窗计时器；另检查50条合成责任及长原因的局部滚动、固定动作可见，以及小客户区调用已有Pause、空间恢复不自动Resume。通过后输出 `.artifacts/WINDOWS-WPF-EVIDENCE.txt` 指向临时证据根，其中有实际WPF截图及 `WINDOWS-WPF.log`。Mac交叉编译与实际Windows执行必须分别绑定本次SHA/候选；Windows实际执行NOT_RUN，不能据源代码把此节记PASS。截图仅在Windows实际运行后生成。

## 候选交互验收

1. 校验候选 `SHA256SUMS` 和 `application-release.json`；在受保护安装/运行账户边界内启动，按既有部署说明配套执行，不修改发布目录绕过保护。
2. 省略UI参数与 `--ui classic` 均显示原工作台；`--ui supply-station` 显示蓝紫双位卡片。非法/重复/缺值参数必须启动失败；DirectPlc/WcsToPlc拒绝 supply-station。
3. 两个投递位用相同带前导零条码、不同实体身份入场：两侧显示自己的reader、Operation、原请求与结果；重复参考输入不能增加执行。参考输入只在Simulation显示。
4. 在作业记录、维护、工作台间切换：草稿/焦点不被轮询重建；后台处理继续。辅助窗口继承UI/布局，所有窗RuntimeId一致；关闭辅助窗不影响业务。
5. 注入参考WCS丢回执/拒绝：未知和拒绝区别显示，不继承上一件格口；核对只查询原请求。其他位仍按应用投影保持独立，公共故障/暂停影响范围与应用一致。
6. 模拟命令后的读取失败、Pause首次读取失败、配置确认读取失败以及慢/失败轮询：任一路径读取失败立即标旧，超过3秒也应失效、操作禁用，最后成功读取时间始终可见；新读取成功后恢复；旧失败不能使较新的命令刷新失效。特别覆盖“A轮询开始→B暂停/确认读取开始→A先成功→B后失败”，B失败必须标旧；有更新读取仍挂起不能视为已成功，新于失败的已挂起读取成功则可恢复。关闭遇卡住快照时5秒后提示失败并保留窗口/资源，故障恢复后允许重试。
7. 校验1920×1080、1440×980、1366×768、125%/150%缩放及混合DPI：主操作固定，长条码/原因完整可读可复制，字段局部滚动，维护表单/密码焦点正常。记录实际客户区，验证800×420 DIP紧凑重排保留两位reader/状态/原码/格口/固定操作；小于800×420 DIP进入保护并请求软件暂停；确认暂停结果，恢复空间后必须人工确认视图，业务仍暂停。不得用整屏缩小掩盖可读性问题。50条责任、长原因/长读取错误不能挤走主操作或最后成功读取时间；诊断原文可完整滚动。
8. 子窗带着挂起刷新或保护Pause先开始关闭，再关闭主窗，先释放子窗挂起任务再注入主窗停止失败：子窗关闭后计时器保持停止，主窗保留并可重试。子窗失败而主窗仍在排空时，不得提前恢复子窗轮询。关闭主窗口：所有刷新停下、已开始请求由runtime排空；停止失败显示“仍持有资源”并可重试，不声称停止完成。日志、退出码和未决原件分别保留。
