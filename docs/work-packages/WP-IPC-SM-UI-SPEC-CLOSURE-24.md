## 当前决定

- P07 异常处理、P08 统计与班次的页面改造延期；保留已有页面和合同。本轮作业效率及诊断只复用统计事实，不引入实体件数或本地同码去重。
- 相机调试仍使用全局持久隔离，两位生产受理均暂停。只读预览不建立隔离。分位隔离未获独立设计，不以提示文字伪造另一位可继续生产。
- 只有完整候选仅修改条码规则、没有 Pending 且 Application 屏障排空时可热生效；混合修改全部待重启。保存审阅显示本次完整候选实际生效方式；原因仍必填，可选预设并填写补充说明。
- 识别按独立观察时间，请求及结果按原请求准备时间归属；按软件处理次数，不代表实体完成。计数只读取事务统计，不由 UI 回调累计。连续空帧不解释为漏读包裹。
- 当前内置 RCS 没有远程结果查询能力；Unknown/Conflict 查看原证据并交接，不生成替代 POST。无送达的可重扫提示与原请求不会重发分别说明。
- 参数按任务导航但保留系统/业务/驱动/组件字段所有权、唯一候选、原 CAS/Pending/Effective 和请求身份。编号区间为包含两端的 X..Y；base=X-1、count=Y-X+1，不重用历史区间。
- 真实连接/额外心跳、曝光增益、删除业务数据、工牌认证及交接外部流程没有新合同依据；不发送试探业务请求、不更改硬件参数、不添加删除数据入口。首配检查明确只检查草稿，实际试读在启动后既有隔离调试完成。
