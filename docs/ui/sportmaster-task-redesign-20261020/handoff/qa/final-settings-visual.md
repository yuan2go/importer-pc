## 紧凑校验交互的补充证据

在 1366×768 逻辑视口打开本地原型，载入左位相机未修改状态，将连接端口输入为 `abc`，点击“校验”并等待模拟校验结束。结果为：

- 焦点位于 `f-left-port`，工作区自动滚动 48 px。
- 错误文字位于视口 y=615.02–633.02；固定保存栏从 y=666.50 开始，二者不重叠。
- 地址、设备名称等其他输入保留；“撤销本次编辑”“校验”“保存为待生效修订”均在视口中。
- 相关 CSS 目前未设置 `scroll-margin`；本次实际校验路径仍通过。正式 WPF 实现应将首个错误字段及错误说明作为一个整体带入可见区域，并在窗口缩放、长错误文案和系统字体缩放时复验。

记录文件：`compact-validation-geometry.json`；实际校验后截图：`compact-invalid-after-validation.png`。最终紧凑 PNG 已另外重新打开复核。
