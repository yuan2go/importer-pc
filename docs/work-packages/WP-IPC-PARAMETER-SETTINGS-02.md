# WP-IPC-PARAMETER-SETTINGS-02

## 目标与读取顺序

完成用户对实际参数页面的美学与可用性纠偏，替代重复导航、步骤化保存按钮和“维护与迁移”总入口。先读 [PARAM-UX-02](../design/parameter-settings-experience-02.md)、[V3交付](../ui/parameter-settings-v3-20261020/README.md)、[交接](../ui/parameter-settings-v3-20261020/HANDOFF.md)及最新代码。先清理冲突的当前指引再编码；PR74三组作业、首配、字段合同和PR76会话修复复用，不重复重建。

## 工作包

| 包 | 完成内容 | 验收对象 |
|---|---|---|
| PS-00 | 实际截图、最新代码和商业桌面参考核对，撤出旧参数主定义 | 当前入口唯一，历史证据原身份保持 |
| PS-01 | 同窗专注设置工作区、四分类直接对象目录、搜索与自适应表单 | 修改指定实例不串对象；左右参数独立；没有常驻首配标签 |
| PS-02 | 自动字段/候选校验，一次保存审阅，真实差异与保存/运行区分 | 无效文本保留；审阅不过期提交；原CAS/Stage/Inspect和Unknown防重 |
| PS-03 | 具体命名的模板、备份、加密草稿、安装、旧设置与恢复任务 | 必要能力不丢失，不要求普通改参先理解迁移/账本 |
| PS-04 | 可编辑离线原型、逐张高清PNG、字段去向和统一视觉规格 | 模拟数据清楚；主要成功/失败/未保存/缺能力状态可走查 |
| PS-05 | 受影响构建与必要风险验证、Windows原生收口、提交与证据 | 交叉编译、浏览器、Windows和现场分开；未执行不写PASS |

六项商业质量为完成条件：重点清楚、组织一致、密度合适、细节完整、操作连贯、真实显示可靠。以完整工业任务闭环实现，不选择最小演示实现，不另造通用配置/部署平台。

## 限定与必要验证

四分类仍编辑一个完整候选；参数所有权沿原映射。真实安装决定字段和组件，Application决定实例与角色。保存运行参数显式审阅，显示偏好沿独立本机偏好。无安全连接测试契约时保留诊断和明确未验证；不能抢占海康设备或发业务POST充当测试。

必要场景：左右连续处理；指定相机修改；错误定位/其他输入保留；保存与运行版本；RCS共享异常与适用恢复；返回作业留稿及实际关闭选择。补查本轮直接涉及的JSON来源、保存未知后撤销、会话字段适用性和窄窗输入。只做受影响测试与必须门禁；原生图像和Windows缩放实测不得由HTML替代。
