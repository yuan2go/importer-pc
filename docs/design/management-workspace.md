# SM 管理中心与自动供包

管理中心每次打开验证一次管理密码。窗口打开后，Application 按原窗口身份暂停普通扫码、人工供包和新的自动派发；保留原暂停状态、左右投递位启用状态和已发请求。离线或未配置相机不阻止管理中心打开；重连和配置替换后的相机仍遵循窗口的暂停状态。相机连接及预览保留，软件自动识码暂停，明确触发调试才读码；海康原生采图调用内已经完成的识码结果不交给普通业务。

管理窗口切页不重新验证密码。授权到期锁定管理页面并保留草稿，自动供包保持暂停。关闭原窗口无需仍有效的管理授权：结束未发送的调试轮次、恢复采集路径后，再撤下自动供包围栏。失败时保留围栏和原窗口以供重试。软件本来已暂停或投递位本来已停用的，不因关闭管理窗口而自动启用。

授权服务短暂通信失败时，当前读取不能授权命令，但不把通信失败当作撤销回执，不丢弃原令牌。后续确认恢复且原授权尚未到期时继续使用该授权；旧令牌的迟到状态不得撤销新授权。服务明确拒绝当前令牌时仍立即撤销。

诊断页按左相机、右相机、RCS、存储排成两列两行，详情保留折叠。管理入口使用齿轮图标。未配置相机始终显示待配置，独立于投递位启停状态；已配置相机的实际释放失败仍显示待确认。

调试页面不把过期的界面连接确认直接说成相机离线，也不据此封死触发入口。已配置且未停用的相机允许重新核对；实际触发由 Application 使用当前连接、配置和会话守卫判断，失效状态不能绕过守卫。

投递位停用期间读到完全不同的新条码，是原次放置结束的证据。只结束原放置，不接纳新条码或占用新放置；原请求确认后完成停用。无码仍须连续三帧且不少于 800ms，原请求结果未确认时仍不能直接停用。

首次配置的打开方式随首次配置一起保存，跨配置步骤保留选择；首次进入作业窗口即读取已保存方式。全屏时 Esc、F11 和系统还原不返回窗口；右上提供最小化到任务栏，恢复时仍为全屏。打开方式仍由管理中心的保存设置控制。
