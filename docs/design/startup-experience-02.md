# 安装与首次配置体验增量

2026-10-21 用户针对安装、首配及关闭配置后的恢复页提出14项纠偏，并补充首次启动恢复页问题。本决定覆盖这些页面的旧当前指引；V2五步分类、V3共用编辑器、唯一配置账、权限、CAS、保存未知核对及原请求责任继续保留。原设计和历史证据不改写。

普通安装只需安装/数据目录、快捷方式；版本按实际介质显示“版本: SM V… Windows 64位”。高级选项按账户、供包台身份、配置来源、扩展与修复分组，说明必需和条件适用；环境报告只读、默认账户自动取当前账户，不要求用户理解SID或源码提交。无人值守计划退出交互安装界面，既有命令接口保留。模拟与生产隔离保留，使用中文且解释作用；安装不连接设备。

首配仍为业务模块、系统、驱动、组件、检查与完成五步，采用紧凑标题及一份完整候选。条码规则选填；空值不筛选，但多候选仍须唯一，不能默认选首码。继承PR83条码排除实现，本轮补齐空允许规则及首配继续；复用同一有界筛选器。新增明确的配置文件导入入口：同版安全模板或当前格式业务配置，预览后只改草稿；保留本供包台/模式/拓扑身份，拒绝不兼容提供者。未知旧格式不猜测转换。

首配末步“保存并启动”依次执行现有检查、受控保存、权威读回核对和启动；任一步失败保留输入，不以失败为成功、不盲目重提Unknown。草稿、帮助、模板和备份恢复放进具体工具菜单，普通底栏只呈现当前步骤主要动作。正常首次关闭配置不伪装启动故障，明确说明未完成并可继续配置；真实启动失败继续有诊断与安全停止入口。

实现和本轮验证见[运行记录](../runtime/startup-experience-02.md)。本轮新代码基于main 3b883fe及PR83 0fea1b5（含PR82），依赖尚未合并，PR84工作区保持原样。Windows合成原生、已安装介质生命周期、真实SDK/RCS和现场各自记录，不复用旧PASS。
