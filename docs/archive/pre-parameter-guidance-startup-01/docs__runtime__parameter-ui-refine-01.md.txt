## 实际操作

首次配置和日常参数使用同一个 WPF 编辑器及完整候选。左侧四类为业务模块、系统、驱动、组件；首次配置另有“检查与完成”。首次配置不再叠加顶部步骤标签，导入放在固定页头，草稿和继续/返回/保存放在固定页脚，正文只有一个页面滚动区；目录可独立滚动。较窄窗口中标签改为输入上方，路径可换行、选择和复制。日常维护仍保留既有审阅、变更原因、待重启与受控应用流程。

首次配置：填写或导入 → 检查完整候选 → 保存配置 → 回读确认 → 完成。保存与完成均不创建运行时或作业；返回“配置已保存 · 尚未启动”，明确点击“启动供包台”后才进入原受控启动及恢复检查。保存结果不明时禁止再次保存，提供真实的重新读取配置入口，仍先保护未保存输入，不虚构成功、重试或回滚。

当前页只显示一条问题数量摘要，可定位首项；字段显示中文问题，完整检查目录集中定位跨页错误。相同类别、实例、字段和规则去重，左右相机分别保留。已经触发校验的输入修改后刷新当前错误，真实保存仍执行完整 Application 校验。无法确认字段归属的异常留在完整候选诊断，不猜测左右实例；原始技术消息经保护后放入默认折叠的诊断详情。

右上管理模式是原生中性菜单，展示真实状态及“将于 HH:mm 自动退出”，退出与重新验证在菜单内。操作员身份单独显示；没有新增管理账号或续期能力。首次配置未授权/到期时按既有敏感信息保护机制返回明确授权入口，隐藏受保护字段与写入按钮；同一候选仅保留在进程内，重新验证恢复原输入。服务层仍独立拒绝失权后的草稿持久化、正式保存和修复。管理密码继续使用既有 5～256 字符策略，可用 `11111`，不要求五类字符，不记录明文。
