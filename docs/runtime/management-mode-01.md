# 管理模式 · 当前操作与实现

历史实施、版本和验收原件见归档；原PASS只属于原SourceCommit。当前支持新安装及同版覆盖安装，保留原账户、配置与业务数据；运行仅接受当前格式，非当前输入在写入前拒绝并保留原件，不提供旧格式运行、迁移或离线接续路径，同格式覆盖更新保留原件；非当前格式的开发更新按明确选择卸载清理后重新安装处理。

SM工作站只提供作业、记录、现场设置；独立运维工具提供运行总览、日志中心、设备调试、专业参数、维护中心。功能归属见[双程序设计](../design/sm-dual-desktop-operator-operations-proposal.md)，安装身份、受控命令和离线边界见[IPC设计](../design/sm-readonly-operations.md)。原主程序管理中心及重复技术入口已撤下。

现场设置为非模态窗口，默认只读摘要，编辑重新验证本窗密码；返回作业收起同一窗口并保留草稿/有效授权，重新选位后主窗人工/PDA正常使用。关闭只结束原会话；旧窗口和已排队操作不能借用或撤销新授权。运维登录只取得本控制连接会话，不创建调试工作区。打开、查看、登录、切页、编辑本身均不暂停供包。

现场与专业参数使用原字段和同一完整候选、校验、变更记录、修订CAS及Pending/Effective。现场负责地址/编号、格口处理和个人偏好；运维负责读码、时序、心跳、超时、日志存储及维护策略。保存保留本端未显示字段，另一端已保存导致版本冲突时保留草稿并重新读取核对，不自动合并旧候选。生效沿原放置、在途调用、回执、设备身份和释放守卫。

设备调试须明确进入原整站工作区，暂停自动供包、读码和人工提交，保留连接、预览及原请求；明确触发读取、明确发送RCS。结束、断连、确认授权撤销及进程异常时，工作站只按原会话释放原资源/暂停范围并核对恢复；已有软件暂停、启停及未确认请求责任保持。授权服务短暂通信未确认禁止管理命令，不能据此虚报撤销或恢复。释放失败保留原所有者和原因，关闭/重试不创建替代对象。未实现按位隔离，不将整站操作称为单工位。

管理会话仍为15分钟，每次执行重新检查所属会话，按钮不能代替权限。到期锁定草稿；实际调试范围由原工作站会话回收，未确认状态须沿原身份核对。正常退出先取消本窗读取、等待调用结束、释放原工作区，最后结束本窗授权；不会取消或重发已发原请求。

首次设密、修复和忘记密码均使用安装登记的同版受保护维护程序。忘记密码由 Windows 管理员核验后做本站一次性重置，不设各站通用固定口令。重置撤销旧授权，未确认结果先核对原操作；服务或受保护凭据损坏不能通过删文件变成首次设置。

到期维护采用请求绑定的一次性入场与持续授权：入场票据仍最多两分钟且不可重放；已核销操作在每次权限检查时重新核对原会话、凭据及请求，最长只到原会话到期和操作预算。它不会把15分钟管理会话自动延长为两小时，也不会借新会话沿用旧委托。退出、到期、改密码或重新登录均撤销旧持续授权；维护按原持久回执保留已提交事实并安全中断。

管理模式中可修改管理密码，确认新密码后撤销所有原授权；重新进入后继续。按 UI02 后续用户纠偏，密码最低5个字符、最多256个字符，允许纯数字和重复字符，继续拒绝控制字符。安全存储强哈希和随机盐；连续5次失败锁定5分钟。受保护服务中保存密码和授权，不在共享可写业务目录中开放权限账，不接受Windows运行资格替代管理密码。新格式损坏、已配置密码缺失或服务不可用均拒绝受限操作。

两端参数继续使用同一完整候选和统一保存。读取、编辑、导入、恢复、草稿、快捷跳转及保存均在服务层要求管理模式；写入继续核对版本并发和真实执行/回执/资源责任；SM按实际差异热生效或保留Pending，不把全部保存解释为必须暂停和重启。退出/到期保护未保存输入，重新进入才能查看和继续。管理授权使用独立会话证据，业务记录中的原操作员身份保持。

运维日志中心的完整在线模式继续读取真实软件轮转文件，支持关键词/显式正则、时间/级别/来源、有界分页、原始相邻上下文和完整栈、全部匹配或时间范围导出。查询、上下文、导出绑定模式授权；退出、到期和改密码取消受限任务并清理部分导出，不占用供包关键锁，不放宽日志来源或凭据遮盖。

复用现有受保护System宿主和D盘根，既有SCM/目录标识继续承担当前安装归属；不是另一套账号体系。本版隐藏帮助入口，离线内容及页面实现保留，业务审计、独立诊断与备份恢复按原职责保留。真实SDK/RCS、设备、目标IPC和现场验收分别记录。

管理凭据schema2、管道v3；UI、辅助进程和受保护宿主必须整套同源发布。业务及公共契约版本以项目文件和发布清单为准，不混用DLL或凭据协议。首次安装设置管理密码，没有旧账号转换入口。

管理密码修改只从运维工具的管理密码入口进入，不在同状态重复提供按钮。诊断卡片及详情的“专业参数”定位到所选相机的识码方式或 RCS 心跳间隔，“数据与记录设置”定位到已结记录清理期限。打开时检查本窗授权，沿用已有完整草稿，首次使用才读取配置。授权失效、读取中断或目标字段不可用时在诊断页显示原因，保留输入；恢复连接和授权后可在同一窗口重试。定向重连仍由独立操作执行。仅隐藏管理窗口且草稿仍在时不新增放弃确认；真正关闭仍保护输入、结束本窗调试、退出授权并释放窗口责任，失败保留原窗供重试，到期也能关闭。

连续试扫开始时冻结本窗所选相机身份，由Application只向该来源注册采集；另一相机保持管理暂停下的预览，不识码、不保存到本批次。采样中的选择变化不改变原批次归属；无效或未配置的来源在建立会话前拒绝，不扩大成全部相机。停止只取消本窗当前批次的等待，随后结束原Application会话；采样中仍可停止。自然完成、超时、失败及关闭走同一收尾，未确认保留原会话和结束命令核对/重试；不创建新会话掩盖未结束责任，不声称已发RCS请求被撤销。

关闭先取消本窗读取并等待调用真实终结。已经结束的本窗读取取消不视为资源释放失败；原调用方继续处理其结果。真实服务异常、未结束的调用、释放失败和等待超时仍保留窗口及原所有权，后续工作区释放另行核验，不能据本地取消推断原请求未发送。

卸载选择保留本站数据时保留管理密码；选择同时删除本站数据时，本站数据根对应的受保护管理凭据、已配置标记和授权锚纳入冻结清理清单，同步核验其他安装共用、文件变化及中断重试。删除未完成不得报成功。清理完成后重装创建新密码，不能复用原密码或授权。
