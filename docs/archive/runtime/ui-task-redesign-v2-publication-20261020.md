## 基准与产品决定

最终读取的main基准为 `ba80d0ea90d86b24f9d9eebd20d075da34320972`，根树 `902a3fbfbc51c86b524e5db62c2fc9b8bc6681b6`。旧基准的首次提交尝试未改变main；已读取实际更新、合并全部最新文档后，提交按最新分支头预期值进行非强制更新；若头部变化先重新核对，不覆盖他人变更。

参数分为**系统、业务模块、驱动、组件**。站级业务身份归系统，请求规则与处理预算归业务模块，硬件参数和相机业务编码按左右实例展示，单一RCS组件只维护连接和协议参数。四类界面复用一个Application和配置账，不建立重复写入权威。

首次配置是首次启动独立五步，不是日常标签页。每位框固定设备/扫描/任务三组，格口突出，展示波次、任务、SKU和返回数量；请求与响应数量分开。PARAM-01已有部分原生参数实现；新响应字段、用户要求的归属迁移与完整原生呈现收口属于下一轮实施。新增心跳与条码筛选按最新代码复用，取格口/心跳身份不静默合并。
