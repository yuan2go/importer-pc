# 故障目录

适用IE01候选。当前可见CP编号保留；本目录覆盖运行源码中的5个CP码。界面症状、原因及包裹处置优先，技术编号用于交接。Windows原生错误码和安装退出码是另外的层次，不把退出0当作设备可用。

| 编号 | 现象/原因 | 现场首选动作 | 何时升级 |
|---|---|---|---|
| CP-UNKNOWN | 本件或上一次请求的格口结果尚未确认 | 包裹取下暂放一旁，查看本次记录 | 交维护人员核对原请求；无权威Query合同时不能假造查询或重发 |
| CP-CONFIG | 当前配置还有未完成的生效/确认处理 | 进入设置核对该次保存；无法启动时使用独立启动修复 | 生效失败、配置损坏或结果不明时保留原件 |
| CP-RESTORE | 已从备份恢复，原机/换机交接尚未完成 | 保持隔离，按实施手册核对完整恢复集和接管条件 | 需要原机退役/外部责任证据时交实施负责人 |
| CP-STORAGE | 记录空间或未完成作业容量不足 | 检查D盘、完整备份和到期已结历史维护 | 不删除未完成记录；无法安全释放容量时联系维护人员 |
| CP-HEALTH | 所需设备/服务未就绪或状态证据已过期 | 查看具体来源，检查电源/线缆/网卡与实际地址 | 序列号/SDK不符、反复离线或RCS配置/协议问题交实施人员 |

| 安装/维护结果 | 含义 | 下一步 |
|---|---|---|
| 结果待确认 / 1627 | 不能证明该次动作是否提交 | 核对原操作，勿换操作号重复安装/重置/删除 |
| 740 | 未取得Windows管理员权限 | 交授权Windows管理员或已批准的部署工具 |
| 87 | 参数、目标路径或模式无效 | 修正输入，使用D盘合法目录；不覆盖已有日志 |
| 1618 | 同一安装/数据仍被执行者占用 | 完全关闭原实例，等待真实资源释放后核对原操作 |
| 3010 | 动作已完成且存在明确的重启清理要求 | 安排维护重启，再核对原清单；程序不会自行重启机器 |
| 1603 / 明确失败 | 前置条件或执行失败，详见实际错误分类 | 保留日志和回执，按失败阶段处理；不据异常推断无任何修改 |
| 1602 / 已取消 | 在可取消阶段确认取消 | 已产生的备份/临时物仍按回执处理，不把取消等同回滚 |
| 有残件 | 程序已退役但部分文件未清理 | 继续原库存清理；没有重启删除计划时不一律要求重启 |
| 未知编号/原生错误 | 当前摘要无法细分 | 保留软件版本、时间、原操作ID及错误原文，联系维护人员；不关安全功能换成功 |

本目录没有编造支持电话或联系人。诊断材料仅经现场批准的渠道交接，不包含密码、令牌、原业务库或未授权图片。
