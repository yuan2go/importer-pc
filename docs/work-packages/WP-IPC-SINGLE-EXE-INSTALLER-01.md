# 单 EXE 现场安装交付

2026-10-20 用户进一步明确：参考其提供的普通安装器和截图，向现场实施交付一个可双击安装的 EXE。继承 PR64 的菜鸟供包台名称和图片；最新 main 为 `9e5b6ab5be9cf70284acdbaa84b84994ca2377e9`，工作区干净。并行 PR62/63/65 分别负责工作台、驱动和普通人工安装的文档范围，不覆盖其分支。

采用现有安装机制：新增只负责校验/展开内嵌固定介质并打开已有原生 `--setup` 向导的自包含启动器。外部仅交付 `菜鸟供包台安装程序.exe`；账户、程序/数据目录、配置、批准摘要、UAC、并排部署、开始菜单及卸载登记仍由原部署服务负责。不新增一套安装事务、后台服务、在线下载或无人值守平台。不复制参考软件的图、协议、品牌或程序文件。

准备页沿当前 WPF/菜鸟品牌的 Operate 模式，明确欢迎、下一步、实际文件准备进度、取消和可复制错误。图片沿本会话已获得的公开许可；既有 UI 实物基线和业务守卫不变。内嵌 ZIP 校验固定散列，限制路径和展开大小，拒绝重复/链接条目，逐文件核对库存；工作目录按本次随机身份创建，仅在子向导退出后清理。子向导退出不等于安装完成，启动器不伪造成功页。

先验证准备机制的篡改、路径、防覆盖、取消和清理，再冻结同源码 win-x64 介质和单 EXE。Windows 验证实际单文件从新目录启动、准备进度/取消、转入原向导、退出与临时目录处理，检查名称/图标及库存身份。实际 UAC 安装、升级/卸载和真实设备/SDK/现场若未执行须单列，不以启动向导冒充完整安装通过。原 D/RV 和历史 ZIP 结果保持原身份。

当前“需要现场先解压 ZIP/运行 Setup.cmd”的入口说明在新 EXE 完成时改为历史兼容方式。复跑和精确交付结果统一见[运行记录](../runtime/single-exe-installer-01.md)。
