# 供包员作业卡

适用：SM当前托盘放置流程及IE01候选。打印稿与本文同源，正式现场交付须绑定实际安装版本；实体打印与新人旅程另行验收。

1. **打开软件，看本位状态。** 左右位分别判断；“待配置”或“不能受理”时交给管理人员处理。供包员不负责填写设备地址或管理密码。
2. **条码朝上放入托盘。** 等待本位当前包裹的有效格口。同一包裹一直留在托盘上时，相机仍识别，但不持续请求新格口。空托盘显示“未读到条码”属正常；有包裹读不到时调整标签，或使用允许的扫码枪/键盘补录。
3. **只按本位、本件、当前有效格口操作。** 看不到有效格口时先读提示，不凭上一件结果投递。明确被拒或未送达时按提示取下包裹；允许重新上件也仍须通过当前业务检查。
4. **结果未确认，先保留包裹与记录。** 取下暂放一旁，进入“记录”查看本次作业并交给维护人员核对，不反复上件。当前内置RCS没有权威结果查询能力，查看记录不等于重新向RCS查询。

SM没有日常“暂停/恢复”按钮。设备危险按现场安全流程处理，软件维护状态不能代替安全急停。相机离线影响该相机来源；人工补录是否可用由当前RCS、容量及原责任检查决定。

软件右上角“帮助”（或按 F1）可随时查看本卡和[故障目录](fault-codes.md)，不需要管理模式。需要求助时，在帮助窗口“导出诊断概览”：只含设备就绪数量、版本和本机环境，不含条码、图片、设置和密码。更详细的诊断包由实施人员在管理模式下从维护中心导出。文件都只保存在本机，交给支持前需取得现场同意；诊断材料不能替代原记录或完整备份。实施操作见[实施手册](implementation-guide.md)。
