# MVS 解码层

本页是解码层的唯一设计定义。运行方法见[操作说明](../runtime/hikrobot-reader-01.md)。保留 F-03/05/07/09/10：一个设备所有者、Application 最终准入、原生边界、原请求不重发和唯一配置修订；本实现不批准 D-05/06 或关闭 RV。

| 决策 | 合同与取舍 |
|---|---|
| 端口 | 只读 Mono8 帧视图，包含宽高、行跨度、帧号和设备原始时间戳；候选含文本、码制、位置及可选质量。视图只在调用未完成时有效，解码器不得保留。最多 128 候选、每码 256 字符；结果不完整则拒绝整批。 |
| 内存与线程 | 预分配 POH 固定数组池，大小×载荷上限以 checked 计算，最多 256 MiB/路；单写采集、单读解码、有界 FIFO，无每帧 Task.Run。SDK 借用期间只校验和复制；归还成功才提交队列。清零后归还池，不存图。SDK 内存与隔离子进程各自单独有界。 |
| 过载 | 不等待池或队列、不覆盖旧帧；每次拒绝计数并锁定故障，触发模式阻断业务。观察模式也停止本轮解码，不能自动恢复健康。SDK 帧号缺口与解码队列丢弃分别计数。 |
| 实体 | 显式 trigger 模式、TriggerMode=On、已核对的 TriggerSource/TriggerSelector、规则有效、自检 Ready 才放行。触发计数严格递增；每触发固定 N 帧（1～16），收齐才发一个 Observation。同触发相同结果跨帧归并，不以码或时间定义实体；任一帧多匹配或跨帧冲突均无码/歧义。缺帧期限仅检测不完整，不能推断实体结束；下一触发早到、额外帧、倒退/断档故障。 |
| 身份 | 主宿主从原事务账预留递增运行代次，受控重连再增加本代计数；附随机注册身份防恢复副本碰撞。Observation 固定 DeviceId/Epoch/Sequence/SourceEventId，AdmissionId 来源于设备、代次、触发。停止先封入口；旧注册及迟到结果拒绝，不能重新标记到新代。 |
| 选择 | 配置显式规则版本、长度、前缀、整串正则、码制允许表；正则限时，完整候选先验证。没有有效规则不能业务 Ready；不按质量最高猜码，Application 仍执行原业务筛选及准入。 |
| 原生隔离 | 托管协作端口必须及时返回任务并响应取消。可能阻塞的厂商库使用有界标准流协议的受监督进程适配器；超时杀死本适配器拥有的进程树并等待退出，禁止杀线程/提前归还仍被使用的内存。厂商端入口由受信装配构造，经既有 NativeSdkBoundary/部署资格验证；配置不能指定任意 DLL 或执行文件。离线回放允许显式选择外部解码进程。 |
| 停机 | Stop/Dispose 共用实际排空任务，可重入；先封新结果，取消在途，达到解码期限后终止隔离端，再清空队列/池。协作合同违约或 OS 拒绝终止时明确失败并保有所有权，禁止假称已停。既有 MVS 原生停止失败保有策略不变；本包不声称能够中断不返回的相机 SDK。 |
| 自检与部署 | 内置合成 Code39 图及已知期望结果，启动真实调用同一解码端口。生产默认无解码器、observe-only；不将假解码器注册到生产。自检只证明端口工作，不证明真实面单准确率或部署资格。无新 NuGet、无厂商二进制。 |

状态：Unavailable → SelfTesting → Ready；自检错读/异常/超时 → Faulted；运行超时/过载 → Degraded（仍阻断业务）；协议、完整性和触发错误 → Faulted。Degraded/Faulted 均锁定，只允许 Stop 后受控新代、自检重新验证。停止为 Stopping → Stopped。businessReady = 采集连接健康 ∧ 解码 Ready ∧ 触发已核对 ∧ 规则有效 ∧ 显式 trigger ∧ 本代仍接收；确认源逐项列出条件，只有全部满足才发布带有效期的 Ready。

| 故障 | 可见结果 / 恢复 |
|---|---|
| SDK 丢包、帧号断档、帧布局错误、Free 失败 | 采集 Faulted；原 SDK 资源按既有阶段保有，受控检查后重启 |
| 池/队列耗尽 | 丢弃计数、队列高水位、Degraded、businessReady=false；核对可能漏包后受控恢复 |
| 解码错读自检、异常、非法/超大结果 | Faulted；不向业务发布截断候选，不记录异常原文/条码/序列号 |
| 解码超时/停止 | 单调时钟计时，取消并有界排空；隔离进程终止并实际 wait；不接纳迟到结果 |
| 触发不完整/额外帧/倒退/缺口 | Faulted；不将部分结果补成成功，不按定时器生成实体 |
| 无匹配/歧义 | 单条 NoRead，CandidateIssue 区分原因；不创建可用条码 |
| 下游拒收/异常 | Faulted 并停止本轮交付，不盲重发 |

取帧/解码/无码/丢弃/旧代拒绝/SDK缺口、队列水位与解码耗时均有快照及 Meter；耗时用 Stopwatch，标签不含码或序列号。回放以人工真值为分母，正确、无码、错读和故障分别计数，错读单列；分码制及 P50/P95/P99 使用明确 nearest-rank。仓库仅合成帧，真实样本只在获授权本地目录。真实读码率/错读率、触发计数及 N 帧语义、带宽/长稳、厂商取消/进程退出、Production 资格和现场闭环必须另验。
