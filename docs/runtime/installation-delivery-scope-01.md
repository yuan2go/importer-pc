## 生效范围

当前交付采用已有普通人工安装包及原生向导。现有 win-x64 ZIP 完整解压后双击 `Setup.cmd` 的形式可以沿用，不要求为安装格式更换工具或新增 MSI 外壳。必要说明覆盖：

- 适用 Windows/架构、实际依赖与取得方式、安装权限。
- 程序/数据位置、人工安装、首次配置与正常启动步骤。
- 升级前备份和配置/业务数据保留、卸载保留项、失败处理和日志位置。
- 当前限制；只有实际依赖需要重启时说明重启和人工继续步骤。

无人值守安装/维护、响应文件、逐站部署计划、批量返回码协议、批量编排及相应强制验收退出本次交付范围。以后确有部署数量、频率和收益依据再定义需求，不能因旧计划写过而重新列为必做项。

人工安装仍执行既有权限、文件完整性、版本兼容和原请求/数据保护；升级不能丢配置，安装失败不能清库，软件暂停不是安全急停。CPV-02/03/12/15/16 保留编号，按实际受影响路径验证；不再为 CPV-16 强制新增批量成功/失败站点旅程。
