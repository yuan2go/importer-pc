## 修正记录与验证边界

- 这是对相关修改作定向复验后的合并覆盖，七个任务不是对同一个最终二进制作全套重跑。
- 初次 T03 因 QA 脚本漏点业务模块类别而超时；修正导航后定向通过，不计为产品故障。
- 初次 T06 的“任意未知原件阻断全站”预期不符合实际 schema 3 ParcelGuards，已废弃；仅采信后续按位恢复结果。
- T02 请求数字 token 断言只核对示例请求中的数字类型；不能单凭该断言宣称响应数量协议保真已完成生产验证。
- 本次仅本地离线 HTML/JavaScript 原型；未连接真实 HTTP、相机、RCS、PLC 或 Windows 客户端。
- 目标 Windows 分辨率、缩放比例、键鼠/触摸实际输入、设备链路、安装和性能未验收。

## 脚本与使用

脚本原文为 [ui-v2-core-interactions.cjs](scripts/ui-v2-core-interactions.cjs)，仅允许 V2 路径，拦截所有 HTTP(S) 请求并将输出写到 scratch QA 目录。`UI_V2_QA_ONLY` 可选择必要任务，`UI_V2_QA_RESULT` 可指定不覆盖旧证据的文件名。测试用的冻结 HTML 和失败截图是内部 QA 留痕，不必重复发布为设计页面。

本报告证明可点击原型表达了对应流程，不证明 C# 已实现、真实设备已恢复或商业交付验收已通过。
