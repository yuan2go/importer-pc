# SM 工作站与运维的功能归属

每个安装实例登记一个供包应用 EXE。默认入口是工作站，同一 EXE 的 `--operations` 入口在独立进程打开运维工具。正式版与测试版各自有安装登记和快捷方式。工作站持有唯一业务实例，运维操作交给实际所有者执行。[受控 IPC 与离线边界](sm-readonly-operations.md)

| 人员与入口 | 可见及可执行的内容 | 执行者 |
| --- | --- | --- |
| 供包员 · 工作站作业与记录 | 选位、扫码、补录、取件、查本件及历史结果 | 当前业务实例核对轮次、车号和原请求 |
| 现场设置 · 工作站 | 本站、仓、生产线、RCS 地址、格口策略、左右相机 IP 与编码；窗口、效率、声音及当前用户自启 | 业务设置走完整候选 CAS。个人设置按当前用户保存，自启检查所属快捷方式 |
| 运维 · 总览与日志中心 | 观察当前状态，授权查询业务日志；离线按本机权限读允许的运行日志 | 工作站提供带运行身份的快照及受控日志查询 |
| 运维 · 设备调试 | 预览、独立校准空闲工位；显式进入整站调试后进行试扫、明确发送调试请求 | 原 Application 复核授权、具体设备及实际执行责任 |
| 运维 · 专业参数 | 时序、码制、识码方式、规则、RCS 心跳和请求期限、日志、存储及备份 | 通过受控命令修改完整候选中本端负责的字段 |
| 运维 · 维护中心 | 备份、原请求核对、诊断及停机后的维护入口 | 在线复用工作站的应用服务，离线转交受保护的同版维护缓存 |

工作站和运维编辑的是同一配置修订。两端保留未展示字段的原值，CAS 冲突保留草稿；保存结果不明时按原操作核对。配置的热生效条件由资源和执行责任决定。[参数归属与保存](../runtime/parameter-inheritance-02.md)

查看、登录、切页保留作业状态。单侧校准只在该位启用、在线且没有当前包裹或未结执行责任时执行，校准期间本位暂停自动与人工提交。进入整站调试则暂停两位提交并保留预览，取消、断连或撤权时按原会话收尾。释放失败保留责任和错误。工作站、工具或 IPC 退出均不撤销已发送的 RCS 请求。

桌面只建工作站入口；勾选开始菜单时建立工作站及运维两项。维护切换前核验实际程序文件使用权和业务所有权。完整备份恢复后保持隔离、暂停并核对原责任，确认启用才开放供包。[安装与维护](industrial-lifecycle-01.md)
